# 道の形成後に新しい個体を入れる比較

基準 b777f3e。軽量2D World、seed 20261005。

最初の3個体を30日運転し、全員を退場させる。そのWorldを分岐し、
未学習の新3個体をそれぞれ30日運転する。片方は地面のwearを継承、
もう片方は全cellのwearだけ0にする。後者も新たな踏み固まりと回復は有効。
これは旧3個体に追加して6個体を同時運転する実験ではない。

Worldの物体、資源残量、再生器、危険物の位置・時計、地面の経過時間を継承する。
前任者が所持した食料は本人とともに退場する。新個体の身体・持ち物・
初期位置・固定parameter・初期知識は両条件で同一の既存social_shared設定。
個体のExperience、Sleep、M_B、社会履歴は継承しない。
runtime slot名はnpc_a/b/cを再利用するが、前後のrun_idが異なる新identity。
後半の両分岐は同じrun_idで再現条件を揃える。

World時計は継続し、個体側時計は新cohortの0から始まる。
manifestのworld_offset_usで対応する。資源再生・危険物ログはWorld時計、
command/観測はcohort時計。旧個体を追っていた縄張りactorは帰巣へ切り替える。
地面の過去通行者はrun_id付きで区別。操作台帳は新runで空、旧操作は再実行しない。

地面の局所抵抗と見た目、帯候補認識は既存機構を使用する。
道を追う規則、全体地図入力、食料への経路案内は加えない。
見た目の認識は現在も行動非介入であり、差が出ても「道の意味を学んだ」としない。

監査: 新個体の初期学習記録0、食料保存、重複/重なる身体作用なし、
30日完走。採取・食事・身体状態・初採取日・操作差・最終地図を保存する。
1seedの比較であり、改善・一般化・世代伝達の普遍則を主張しない。

実行: `python -m integrations.lightweight.cohort_path_campaign`
