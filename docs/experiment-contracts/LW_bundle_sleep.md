# 経験束のSleep整理

FINITE IMPLEMENTED / 2026-10-07。既定off、experience_bundleとSleep有効時のみ。

完了したSleepごとに、開始前に形成された本人の束を一回だけ整理する。
未完了Sleep・単なるwaitでは整理しない。局所候補の整理であり、canonical T1採用ではない。

- 適格な照合機会なし：未使用Sleepが3回以上なら休眠。
- 照合されたが最終実行変更なし：未使用Sleepが2回以上なら休眠。
- 寄与集合に含まれ、候補変更が最終操作として実行された：保持し未使用回数を0へ。

回数は連続した未使用Sleep数。理由の種類ごとの連続回数ではない。
使用は成功や因果的有用性を意味しない。複数寄与の個別因果を識別しない。
失敗実行も使用に含む。使用結果による各束H、反証、強化は今回未実装。

休眠は削除ではない。出典・形成時H・operation使用済み台帳を保持する。
探索/帰還時に現在の粗いcontextとphaseが一致し、空きがあれば保存順で再活性化する。
active最大32、active+休眠最大256/個体。満杯時に勝手に削除しない。
再活性化が新規形成枠と競合する場合もあり、常時新規形成できる保証ではない。
Sleepで空いた枠は後の形成で利用可能。同じoperationを新しい支持へ再計数しない。

比較：seed20261005、3個体30日、既存の経験束enabled記録を対照とする。
食料保存・操作一回性・束/出典重複なしを確認する。成果改善は受入条件にしない。
実行：`python -m integrations.lightweight.bundle_sleep_campaign`。
