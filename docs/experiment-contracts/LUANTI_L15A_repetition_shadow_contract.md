# L15A — 目的付き反復の残存・減衰 shadow契約

状態: DESIGN ONLY / IMPLEMENTATION CONTRACT。2026-09-28、基準 `c968d4e`。
実装・受入は未実施。[履歴診断](../experiment-evidence/LUANTI_L15A_history_diagnostic_evidence.md)を受けた次工程。
schema案 `l15a-repetition-shadow-v1`。固定設定1種、行動権限なし。

## 問いと入口

同じ観測対象への接近で、有効な実行結果を伴う反復が認定された場合、
取得時刻に基づく残存量と減衰を再現可能に計算できるか。
この問いは本人の有限履歴内の局所的な評価であり、Core E/Hや負のExperienceではない。

初版は保存済み受理wireの再生から明示呼出しするpure shadow。
run/agent/epoch/clockを固定し、その時点でRuntimeが受け取っていた記録だけを参照する。
診断者が与えた`stagnant=true`、将来のresult、World座標・全軌跡を入力しない。
既存Runtimeで入力・結果を再検証し、診断と適格性を再計算する。外部の認定フラグを信用しない。
command、priority、M_B、学習、sensor/decision cadenceを変えず、新HTTP endpointも作らない。

## 固定した認定範囲

最大9観測とその間の**8操作**、2250000µs以内。同一period・連続取得枠に限定する。
工程1の探索的診断は2〜8操作を表示するが、shadowへの加算は8操作がそろってから。
観測/実行結果の対応・時刻・姿勢・revisionがすべて結び付き、実行済みであること。
必要な観測の欠落・partial・output limit・unavailable rayは未知とする。
blocked/no_surfaceという取得済みの地表情報を、未取得とは混同しない。

本人の実測相対変位とyawだけから、窓先頭の身体基準で局所変位を合成する。
正味距離0.25以下、姿勢差5度以下、既存粗視覚keyとFood外観/1単位丸め距離が再現し、
次のいずれかがある場合を幾何的反復候補とする。

- 実移動距離0.001未満で、実際の連続逆旋回がある。
- 実経路長2以上で戻っている。

粗視覚keyの一致は同じ場所・対象の証明ではない。有限窓内の相対積分であり、一般的な地図ではない。
さらに、窓内で同じ観測Food参照へのapproachが継続し、作用がobserved_materialの移動系であること。
採取が成立した窓、予定された`neighborhood_survey`の往復、目的変更、対象距離が0.25超改善した窓は加算しない。
対象の開始/終了時の観測距離が不足する場合も認定しない。
「採取していない」「同じ所にいる」だけでは反復を認定しない。

## 支持の重複を避ける

履歴窓は診断表示上重なってよいが、反応への寄与には**操作が重ならない窓**だけを使う。
最初の適格窓を受けたら、その最終操作までを消費済みとする。後の窓は全8操作がそれより後であること。
重複観測・操作の再送、同じ窓の再評価は寄与・独立反復数を増やさない。
同IDの内容変更は拒否し、拒否前に部分更新しない。
非加算でも候補、重複窓、未知、目的外、進展ありという理由を残す。

## 残存量の固定値

| 項目 | 初版 |
| --- | --- |
| 初期値 | 0 |
| 独立した認定窓1件の寄与 | 1反応単位 |
| 減衰 | 1秒につき0.25反応単位、下限0 |
| 上限 | 4反応単位 |
| shadow閾値 | 2反応単位以上 |
| 出力 | `would_request_reassessment`。操作許可ではない |

新しい正当な観測のcapture_usで先に減衰し、適格な非重複窓だけ加算してから閾値を検査する。
固定小数の1単位=4000000tickとすれば、減衰は1tick/µsで整数計算できる。
同じ取得系列なら配送の分割や再送で減衰量が変わらないことを検査する。
未知の期間も時間減衰はするが、未知を「反復が終わった」という証拠にしない。

状態は個体ごとの現在approach一つに限定し、目的変更が確認された場合とperiod/run境界で閉じる。
目的が不明になっただけなら新たな加算を止め、時刻による減衰と不明理由を残す。
閉じた反応を別のFoodへ持ち越さず、旧記録・Experienceを削除したことにもしない。
1個体最大1920観測、3個体、既存30periodの上限内とし、新たな永続storeは作らない。

## 受入予定と停止点

- 同一の認定列で2秒間隔なら残存1→1.5→2、6秒間隔なら1→1→1となる合成試験。
- 未知・未実行・目的変更・予定往復・採取進展・重複窓を加算しない。
- 同一payload再送、競合、時刻逆転、個体混線で公開結果を壊さない。
- shadow有無で全command、既存学習、M_B、sensory storeが一致する。
- 保存済みv1の反転は正例材料として使えるが、v2への追加効果とは数えない。
- 保存済みv2で認定0をそのまま再現する。都合よく予定往復を正例へ変更しない。

このshadow検証で一区切りにする。行動を停止するhookはまだ追加しない。
工程3へ進むには、同じv2基盤での非意図的反復の追加検証、正常回避/予定往復の対照、
停止予算・再開条件・既存approach除外との優先順位を別契約で固定する。
v2で正例が得られなければその結果を残し、適用範囲を再検討する。新機構が必要だったとは主張しない。
