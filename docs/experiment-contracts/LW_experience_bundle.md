# 困窮時の経験束と再活性化 v1

目的: 現在の未充足から過去のどの記録をたどり、後の選択へ影響できるかを検査する。
原因の正しさ、効率改善、常識的な学習を受入条件としない。

`experience_bundle_mode=shadow/enabled`。空腹M_Bを必要とする。
5秒の充足比較が新たに閉じ、H>=θとなった際、本人の直近8観測・10秒以内から
実行結果受付済みの記録を束ねる。expired/stale、未来の実行結果、他個体の記録は使わない。
最大32束。満杯はcapacity_reachedとして新規形成を止め、行動や既存束を消去しない。

束にはtrigger、空腹model_ref、比較ID/H、元観測・操作ID、行動・結果、
当時のphaseと方法M_B参照、粗い備蓄、食料/危険の観測状態、身体条件、
社会intent（相手参照を含む場合あり）を保持する。
同じoperationは1束だけに含める。複数経路での参照は経験回数を増やさない。
同じ初期入力と記録なら同じmodel_refを生成する。

これは未検証のGameAI-local経験関係モデル。canonical T1採用でも原因証明でもない。
「困った」という概念名、譲渡が悪いという因果規則、隠れたWorld状態は入力しない。
形成トリガーと候補言語/使用規則は実験者が与えたもので、全ての表現を自律発明したわけではない。

再活性化は後の観測に限る。粗い備蓄、食料coverage/見え方、危険coverage/見え方、
空腹有無、疲労区分、phaseが一致する元記録を参照する。
最大0.75の負寄与を、該当記録内のaction頻度に比例させ、既存候補へ加える。
「この文脈でこの操作をしていたが未充足だった」という相関の利用仮説であり、
移動失敗だけでなく成功した移動や待機も抑制され得る。
method参照や相手は束に保存するが、初版の照合軸はactionと上記contextに限定する。

既存energy/Sleep/身体寄与の後に合成。危険・夜間・方位・保護された提案・
身体不成立を上書きせず、候補を増やさない。shadowは形成と照合のみでscore非介入。
オンライン形成であり、夜間Sleepによる検査・整理はまだ接続しない。
減衰、肯定的経験による改訂、上位の生存性モデル、目的自体の再構成は範囲外。

再実行: `python -m integrations.lightweight.experience_bundle_campaign`
