# 探索と四層身体の接続 v1

2026-10-04。基準3be51fc。軽量Worldの明示opt-in、短い探索場面のみ。

後続: [身体・生活・Sleep統合](LW_body_sleep.md)で長期CLI、帰還荷下ろし、夜間処理へ接続。
以下は初回の短い接続実験の契約・停止境界。

`BodyCampaign → BodyAgent(HarvestAgent) → ExplorationBodyWorld`で、既存の
観測受付・探索判断・command保存・結果検証・inventoryへ接続する。
既存CLIの通常Worldは置換しない。

## 身体と時間

歩行は.5、climbは1（損傷に応じ縮小）、操作は1秒。
2秒刻みで観測し、実行結果は取得時刻+1秒。間の空白時間に回復を加算しない。
期限・phase境界を越える操作はWorldで不実行。通常の探索結果契約は移動1のまま。
専用agentのresult契約のみcommand距離を実測と照合する。
身体waitは1秒のrest、旋回の身体消費は今回未モデル化。

## 追加観測と権限

locomotorは個体・観測ID・取得時刻・姿勢に結び付けた身体stateと、
前方1単位の身体経路上の障害高さ上限（.1刻み）を持つ。
これは専用の有限幾何センサーであり一般視覚認識ではない。
高さ不明はnullで表し、climb権限を与えない。
地面の部分取得はそのまま残し、completeに改変しない。

探索phase、身体対応成立、手持ちなし、完全な食料観測で正面の既知食料があり、
現在の移動/採取候補またはacquisition_incomplete待機の場合だけ、
高さが能力内ならclimb/回復待機を候補として採用する初期規則。
夜間・帰還・警戒優先や別理由の目標待機は越えない。
初回から高さを参照できるため、必ず衝突を経験してから越える規則ではない。

Worldで実高さ・身体余力・着地点・採取距離・間の障害を再検査する。
操作再送は既存receipt、内容変更は拒否、古い姿勢・期限切れは身体消費なし。
食料の視認は眼高1から食料高.2への円柱交差で判定する。

## 停止境界

採取結果は既存Runtime inventoryに届く。新規climbの学習、Sleep採用、
長期生活・帰還配送・複数個体の身体相互作用は未検証。
本Worldは短い接続試験用で、既存の帰還unload処理をまだ移植していない。
長期CLIへ適用する前に、既存WorkScheduler、帰還、危険、Sleepを含む統合が必要。
連続鉛直運動・走行・転倒は今回追加しない。
