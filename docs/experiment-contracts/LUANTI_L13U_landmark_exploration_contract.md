# Luanti L13U — 観測した特徴を小目標にする探索

状態: 実装済み。実行結果は[Evidence](../experiment-evidence/LUANTI_L13U_landmark_exploration_evidence.md)。2026-09-27。
意味基準は[Core参照](../semantic-reference/RDL_Core_T0_T1_reference.md)。
[L13T](LUANTI_L13T_natural_exploration_contract.md)の自然地形と身体、
[L13S](LUANTI_L13S_learned_exploration_contract.md)のExperience・Sleep・独立検査・T1/M_Bを使う。

## 問い

現在見えている粗い特徴を小目標として保持し、移動後の再観測で条件を確かめながら進めるか。
未学習の初手は、観測された候補から一つを選ぶ。岩や木がFoodへ続くという意味は与えない。
人間の歩行一般、物体認識、場所同定、最短経路を再現したという主張ではない。

最初から与える身体・感覚制御は、特徴の角域へ向く、中央なら1node進む、再観測する、
特徴がなければ有限に見回す、という小目標の実行機構。これ自体を学習したとは数えない。
Foodとの関係は本人の取得・実作用列から形成し、別日の検査と採用を経たM_Bだけが後日の経路選択へ使える。
新しい小目標制御と、学習済みFood関係の権限を判断記録で区別する。

## 有限な面観測

専用schema `l13u-landmark-exploration-v1`を明示した入口だけで動く。
旧L13A/R/S/Tの公開条件と保存replayは維持する。

- `l13u-horizontal-surface-fan-v1` / `l13u-landmark-fixed-v1`。
- 現在の身体基準+0.5の眼高から、水平-90〜90度を15度間隔で13本取得する。
- 各rayは0.125node刻み、最大192点・24node。実ノードの最初の非air面まで。取得は通常250ms枠に一度。
- ノードへの丸めはLuantiの`vector.round`を使う。正負とも半整数は0から遠い側へ丸める。
- 草/葉green、土/幹brown、石gray、水blue、既存の赤い岩red。node名や意味分類は個体へ返さない。
- 距離は `near`（3以下）、`mid`（3超12以下）、`far`（12超24以下）の帯だけ。
- 角域はray中心±7.5度、端は±90度へ切る。隣接rayの同色・同距離帯を一つの面特徴へまとめる。
- 最大13特徴。各特徴は観測内のref、粗色、身体相対角域、距離帯のみ。
- 未ロード/未分類の遮蔽物はpartial。完全な空取得、取得不足、対応候補なしを区別する。

13本の離散rayが計画内で完了したことをcoverageと呼ぶ。角域内の全画素/全物体を検査した意味ではない。
隣接rayの統合で別物体が一つになることがあり、同色の別物体が次の対応候補になることもある。
refは毎観測のローカル番号で、同じref文字列を同じ物体の証拠に使わない。
実ノード座標・距離・名前は実験者用auditへ分離し、HTTPの個体観測には入れない。

面観測はpacketの取得時刻・姿勢・run・個体・取得枠に結び付くtyped fieldとして保存する。
新しい汎用SensorFrameチャンネル、OBS v1の機能追加、p5表示の拡張ではない。
局所Food、9方向の下向き面観測、山の共有遠景はL13Tのまま併走する。

## 小目標の選択・保持・終了

1. 取得が完全な現在の特徴のうち、nearではなく角域幅45度以下を候補とする。
2. その候補内で一様抽選する。系列seed・日別seed・選択回数で再生可能にし、World位置、Food位置、refの文字列は使わない。
3. 元観測・元特徴・取得姿勢・時刻を保持し、角域中心が±7.5度を超えれば5度単位・最大45度回転する。中央ならmove1。
4. 次観測で、直前の身体実測resultとafter pose/revisionを確認する。指令だけで移動済みと補わない。
5. 前回角域中心から実測yawを差し引く。同色かつ中心差が回転後15度以内、移動後30度以内の特徴をすべて残す。
6. 一件なら同じ小目標を継続。0件なら`lost`、複数なら`ambiguous`としてwaitする。複数から任意の一件を勝者にしない。

移動後の30度は、粗い外観対応を調べるための局所規則。3D位置復元や一般姿勢変換ではない。
距離帯は接近時に変わるので同一性条件にはしない。継続は「条件を満たす記録が一件ある」であり、同じ物体の追跡保証ではない。

| 終了/保留 | 意味 |
|---|---|
| `near_feature_observed` | 対応候補一件がnear帯になった。物体への到着やFood成功ではない |
| `lost` / `ambiguous` | 対応候補0件 / 複数件。元目標を達成したとはしない |
| `blocked` | 実移動が通行不能。決め打ちの迂回方向は出さない |
| `body_correspondence_unavailable` | 次観測へ結ぶ実行結果・姿勢・時刻が不足 |
| `operation_not_executed` | 期限切れなどで期待したmove/turnが実行されていない |
| `acquisition_incomplete` | 比較に使う取得が不完全。検出0件の負の証拠にしない |
| `operation_budget` / `goal_budget` | 一目標12操作 / 一日8目標を使った |
| `no_candidate_after_scan` | 候補なしの見回し許可を一日4回使った |

終了を記録する枠はwait。次の完全な観測で予算が残っていれば、新しい小目標を選べる。
失敗した特徴を自動的に記憶から除外する規則はないため、同様の特徴を再選択する場合がある。
未訪問の場所への一般探索・障害回避学習・経路の目印列への圧縮は後続。

候補がない場合だけ90度の見回し許可を出し、最大4回で止める。見えない方向への盲目的moveは出さない。
4回は要求した許可の上限で、4回すべての実行や完全な360度取得の保証ではない。
一日16秒/64操作、既存の実行期限・pose/revision・同操作再送の一回実行・3D距離予算を維持する。
観測の再送や受理失敗で抽選・小目標履歴が進まない。状態の更新は観測受理と一緒に公開する。

## Sleep・M_Bとの境界

完全な観測キーへ新しい面観測のmodel/profile・粗色・角域・距離帯を加える。ref、実位置、対象IDは加えない。
初回Food発見までの本人の観測・作用列から、既存L13Sのepisodic Candidateを形成する。
日末Sleep→別日明示Probe→検査→T1/M_B採用→後日の実行という権限は変更しない。
検査Probe/active M_Bが経路を実行する間は、小目標制御を`suspended`として記録する。
経路条件が合わなければその経路は中止し、現在の取得を使う小目標制御へ戻れる。

学習するのは限定された観測/実作用列と終端Food再観測の関係。小目標の継続回数を支持数へ足さない。
未発見日は経験として残り、Sleepを実行しても`no_eligible_discovery_route`となる。成功候補を捏造しない。
失敗の分類が保存されたことと、失敗から選択を改善する一般機構ができたことを分ける。

## 受入

- L13Tと同じ`natural_meadow` / `natural_woodland`、初期seed20260927。各日Worldを復元し、別日3回発見または最大30日。
- 二配置・上限・seedを実行前に固定し、成功するseedや地形へ調整しない。未発見の上限終了も有効な結果。
- 実Luantiで取得→HTTP受理→現在観測からの許可→実回転/移動→再観測を確認し、全wireを再生する。
- 個体への観測と実験者用auditを分離し、実測yaw/位置・ray・結果・目標の出典・保持/終了理由を照合する。
- 完全な空取得・partial・lost・ambiguous・near・blockedを局所試験で分ける。実Worldに出なかったケースを実機結果へ足さない。
- 合成三日試験でSleep/独立検査/M_B接続を維持する。実系列で発見・採用が成立したかは別に報告する。
- 旧地形/平地replayと既存全体試験、共有身体制御の旧実Luanti回帰を確認する。

この試験は単独個体・静的昼間地形・kinematic stepに限定する。歩行の生物学的妥当性、一般物体追跡、
Foodへの必達、多個体競合、夜間、物理Sleep、身体死、地図/方位の学習は今回の到達点に含めない。
