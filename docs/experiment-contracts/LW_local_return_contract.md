## 接近・作業・完了

塔の粗い外観は接近用であり、near分類を到着完了にしない。
局所荷下ろし場所を、前方半球・距離6以内・既存LOS条件で観測する新しいfixture感覚`local-dock-v1`を追加。
個体へ渡すのは可視性、5度刻み相対角、到達範囲内か、取得時刻・個体・姿勢等の出典だけ。拠点のWorld座標を渡さない。
この場所を荷下ろし用途と読み取れることは初期教示に相当する実験設定で、学習成果ではない。

遠方では塔、局所観測後は荷下ろし場所へ有限接近。前方移動は現在の身体方向観測でsampled・段差0.5以内を必要とする。
1日64接近判断まで。到達範囲1.25以内では`wait / return_unload_attempt`を作業要求として使う。
Worldが実行時の位置とwait成功を確認して荷下ろし結果を返し、既存admit_unloadが受理して初めてdelivery_confirmed。
時間付き採取と操作schema全体を共通化したものではなく、今回の荷下ろしは一つのwait操作。失効・再送は既存操作ID管理を使用。
新モードでは夜間の自動荷下ろしを停止し、明示要求を必要とする。旧モードは変更しない。

空荷の場合は、現在の局所到達観測と対応するwait結果があれば到着扱いとする。配送便や学習支持を生成しない。
旧経路と互換のhome_like_observed outcomeを使い、diagnosticをlocal_arrival_confirmedとする。

## 帰還探索の候補自由度

帰還中の候補枯渇・局所接近の閉塞・接近予算切れ等の明示waitに、別のreturn_reposition状態を持たせる。
既存の観測済み目印探索は維持し、それも止まった場合に局所residualを蓄積する。
毎秒0.5減衰、適格判断+1、上限8。2以上で試行し、4未満では観測済み目印方向に近い身体候補を優先、4以上は観測済み身体方向全体から再現可能に選ぶ。
目印は一時的な観測方向の根拠であり、拠点や恒久的対象と認定しない。該当目印がなければ身体候補を使う。

旋回後には接近制御へ即座に戻さず、現在の前方を再検査して一歩を試す。前方が不明・blockedなら計画を根拠に強行しない。
追加旋回・移動は合計16回/個体/日。探索用の16回枠とは別。帰還目的と荷物は保持し、Foodの取り直しへ切り替えない。
未知の経路、正確な拠点方向、全体地図、ワープは使わない。方位感覚は取得されるが、今回の帰還候補抽選は方位履歴consumerと未接続。

局所residualはcanonical E/Hではない。到着方法を学習したM_Bではなく、初期の行動利用規則。
新しい局所感覚、明示荷下ろし、候補拡張をまとめた実験なので、単一要因の改善とは扱わない。
