# Luanti L6 Sleep / Deep Candidate Contract

## Status

L6 operational shadow-learning reference on Luanti 5.17.0.

## Purpose

Carry repeated Luanti-owned outcomes through the existing Local Bias Sleep
Profile and Deep Similarity path without granting the result authority.

```text
three distinct Luanti attack outcomes
-> three Territory Experiences
-> three Outcome Gradients
-> agent-owned Local Bias materials
-> Local Bias Sleep Profiles
-> pairwise Deep Similarity
-> one shadow CandidateRelation
```

## Cycle Boundary

The L6 fixture admits exactly three outcome cycles. After each of the first two
attacks, tasty Food is absent from one bounded observation. The existing Food
Trajectory therefore releases before the Food becomes visible again. This
separates the three World outcomes without resetting Runtime learning stores.

The headless fixture maintains its finite NPC, Food, Base, and Beast entity set
while the mapblock remains loaded. Entity restoration is World harness behavior,
not NPC memory or action authority.

## Explicit Sleep Boundary

Sleep processing is not triggered by attack. After three admitted Experiences,
the experiment explicitly calls `POST /v1/luanti-bias-sleep` with agent,
sleep-cycle, and formation-tick provenance.

The coordinator reuses:

```text
LocalBiasStore.sleep_projection()
build_local_bias_profiles()
build_local_bias_deep_shadow()
```

No comparator or candidate rule is changed for Luanti.

## Candidate

The one finite shadow candidate has support count 3 and preserves:

```text
acquisition -> negative STRONG
return      -> negative MEDIUM
injury      -> negative MEDIUM
```

It retains all Profile, Experience, Bias, Gradient, and World event provenance.

## Separation

```text
repeated outcome != automatic Sleep
Sleep Profile != Similarity Observation
Similarity Observation != truth
shadow CandidateRelation != adopted relation
CandidateRelation != E / H / theta_eff / M_delta
CandidateRelation != T1 selection / M_B / action
```

## Acceptance

1. Three distinct real Luanti attack outcomes are admitted for one agent.
2. Every cycle retains a distinct World event and Experience identity.
3. Explicit Sleep forms exactly three same-agent Profiles.
4. Deep Similarity forms one deterministic support-3 shadow candidate.
5. Candidate provenance contains all three World event sources.
6. Fewer than three Profiles are rejected.
7. No T1, M_B, canonical, Goal, Trajectory, or action promotion occurs.
