# Shared resource access baseline

状態: 既存の共用動作を明文化・回帰固定。2026-09-29。

現在の軽量Worldでは全個体が同じ資源場を利用できる。
所有者、親密さ、所属、利用権、警告・境界防衛による採取制限は設けない。
ただし本人の現在観測・到達範囲・身体状態・作業成立を必要とし、利用可能とは全資源の位置を知ることではない。

資源残量はWorldに一つだけあり、誰かの採取で共通残量が減る。
同時に最後の1単位を要求した場合は、実行順により後の個体が取得できないことがある。
公平な割当や全個体の取得成功は保証しない。既存の固定処理順も今回変更していない。
個体別の観測参照tokenは情報・操作の束縛であって所有権ではない。

`World.resource_access = shared-all-agents-v1`をtimed_harvestのmanifestへ保存する。
個体の判断入力に新しい権限情報を追加する変更ではない。旧ログの欠落は旧実験の非共用を意味しない。
所有・境界防衛は別の実験契約で導入し、この基準条件へ暗黙に混ぜない。

検証: 同一地点の3単位をA/B/Cがそれぞれ取得し、共通残量が0になり全員の観測から消える。
既存の最後の1単位の競合・再送非重複も保持。`tests/test_timed_harvest.py`計6テストPASS。
採取可否の実装規則は変更していないため、30日走行は再実行していない。


[後続30日再実行](../experiment-evidence/LW_shared_access_30d_evidence.md): 48採取・48持帰り、全指令が前回と一致。地点0をA/Bが4/8ずつ共用。
