# 日次評価と30日Sleep比較

2026-10-03。基準b90eb26。

初版の日次評価は本人の観測と操作結果・持帰り受付から作る読み取り専用記録。
日次評価の有無で行動を変える試験ではなく、Sleep自動採用なし/ありを30日比較し、
どの日に何が変わったかを追う。現在は夜間runtimeへ新しい日次Hを投入しない。

64秒を1日として操作の実行時刻で日を区切り、各個体ごとに保存する。
採取・持帰り・移動距離・絶対旋回量・待機回数・blocked・警戒観測数・帰還証拠、
使用model_ref、直接の候補変更数、元操作ID/受付IDを残す。
Worldの絶対座標、隠れた資源量、脅威真値は評価に使わない。

前日との差は成分別。初日は比較なし。身体負荷proxyは移動距離＋旋回度数/360で、
生理学的疲労でも回復後の残存疲労でもない。負荷増が必ず悪いとも決めない。
帰還はdelivered/home_like/unconfirmedを区別し、未確認を野宿確定とは呼ばない。
同一操作/持帰り受付のログ再送は二重計数しない。

日次評価からM_Bへ一律に成功/失敗creditを配らない。前日とWorld条件が異なり得るため、
日全体の変化を各M_Bの因果効果と断定しない。日次記録は後日の上位目標評価の材料。

比較条件: seed20261002、A/B/C、30日、資源8地点各最大12、3日ごと補充、
縄張り＋巡回、両条件Sleep学習あり、自動採用だけ切替。帰還3回の早期終了なし。
`python -m integrations.lightweight.sleep_comparison --auto-adoption --days 30`。

注意: Sleep局所モデルの実行成立率は、各夜に選んだ代表経験内の比率。
全操作の実頻度・校正済み確率ではない。日次評価はこのモデル選択窓と独立に集計する。
