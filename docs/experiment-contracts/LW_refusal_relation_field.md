# 拒否経験のHと関係場への有限投影

2026-10-04。基準14c605f。専用軽量World比較。通常3日生活への自動適用はまだ行わない。

実際にAがBへ要求し、Bが明示拒否する2往復から、本人の受信記録と
既存aid_method_pressureのH_after=1,2を取得する。
相手別の拒否経験モデルは元要求ID・取得時Hを保持し、重み `min(2,0.6*max(H_after))` を持つ。
モデルの再生成・再評価で支持数を増やさない。他人の材料や比較保留を拒否経験へ昇格しない。
これはGameAI-localな未検証M_B近似。canonical採用ではない。

## 意図的に置く使用仮説

現在の明示候補に対し、拒否経験の重みを「再要求」と「同じ相手へ譲渡する」のscoreから引く。
逆方向の協力への適用は**設計者が置いた使用規則**であり、経験からその規則を発見したわけではない。
拒否記録そのものが「相手を拒絶すべき」という事実を証明するとは扱わない。
無応答はこの明示拒否モデルの対象外。要求Hが増えていても、拒絶意図へ変換しない。

初期scoreはrequest/give=1、wait/refuse=0。
譲渡には現在の身体必要量max(0,(80-reserve)/40)を減点し、固定affiliation 0〜2を加える。
affiliationは比較用入力であり、関係学習の成果ではない。
食料未保持ならgiveは候補外。未観測相手、受信していない要求へ応答しない。
候補softmaxとSHA-256由来のseed drawで選ぶ。対照と実験で同じseed/drawを使う。
ここでのseedは候補選択のみ。Worldの地形seed比較ではない。

訓練後の別Episodeは身体・食料・配置を共通条件へ再初期化し、拒否モデルだけ引き継ぐ。
各seedの選択を既存CommunicationWorldで実行し、食料移転・保存・再送非重複を検査する。
同じ32seedを7条件で使う224回の有限実行。全条件を連続した生活や独立な統計標本とは扱わない。

保持したHは過去の拒否時の出典であり、現在の目的Hそのものではない。
長期減衰・新しい援助経験との再構成・Sleepによる採用・全行動への共通Hは次の契約。
