# 時間補充を伴う30日危険物体比較

基準 `8f03e1a`。lightweight World用。採取所8地点各12単位の有限共有資源を、World時刻の3日ごとに最大12まで補充する。第4/7/10/13/16/19/22/25/28日開始時に9回。残量へ12を上乗せするのではなく不足分を補う。枯渇していない地点も同じ周期を使う。

補充は採取所の場所を変えない。容量・採取時間・荷下ろし・移動・M_B・Hを初期化しない。NPCへ補充通知・補充予定・World座標を渡さず、現在の観測に再びFoodが現れたときだけ認識可能。資源の周期性そのものを学習する機構は今回の範囲外。

1日は従来の64シミュレーション秒。境界では、期限に達した作業の完了を先に処理し、次に補充、次に通常観測。この順序を生ログへ残す。同tickに補充を再実行しない。無限資源モードと補充は併用不可。

実験条件は3個体・30日・2 seed（20261001/20261002）。各seedで縄張り1体のみと、縄張り1体＋巡回1体を比較。継続選択有効、縄張り内3採取場、3便達成による打切りなし。旧5日比較ファイルを上書きしない。

`--regrowth-days 3` を指定しない既存runは非補充のまま。実験者用manifest、各補充のbefore/after/added、取得eventを保存し、初期在庫＋補充−採取＝最終在庫、採取＝所持＋持帰りを検査する。補充自体をExperienceや成功支持に数えない。

```
py -3.11 -m integrations.lightweight.patrol_comparison --run --days 30 --regrowth-days 3
```
