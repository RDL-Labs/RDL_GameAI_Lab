# 最小コミュニケーションと保持境界

2026-10-04。専用軽量World。通常探索・Sleep・援助関係更新には未接続。

接触圏0.6以内・非遮蔽の既知個体間で、要求、譲渡、拒否、手を伸ばす、警告、
引く、食べる、待つを実行する。言語生成や交渉ではなく固定の初期通信能力。
通常OBS聴覚配送を使う遠距離通信ではない。

相手について観測できるのは既知IDと食料保持の有無。内部reserveや正確な保持数は渡さない。
要求/拒否/警告は受信能力が必要。接触圏の手伸ばし/実譲渡は視覚的に観測される。
メッセージ寿命は3秒、発信者と参照元の結合を検査する。
譲渡/拒否は現在受信している当該相手の要求への応答に限る。
1要求への応答は一度。失効、遠隔、別人宛要求、再送による複製を許可しない。

保持食料は本人だけが消費・譲渡できる。要求や手伸ばしだけでは移転しない。
giveは双方inventoryを1減/1増、eatは本人inventoryを1減らし既存身体eatを適用。
所有権、置いた物への権利、強奪、交換は未実装。

接近や要求では警告せず、手伸ばしを観測した場合に警告できる。
警告後はwithdraw/reachを再選択する。引くことは要求の停止表明で、退避移動ではない。
初版のshare/heed_warningは実験用固定傾向。L11のload/閾値や感情を接続したものではない。
全候補を共通のH選択へ接続する前の能力検査。

最大64操作の専用台帳、個体別操作ID再送は同じ結果、内容変更は拒否。
1秒ごとの3操作fixture。基礎代謝・通信の消耗・夜間集合は未実装。
