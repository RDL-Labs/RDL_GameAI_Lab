# 重量・障害・身体と荷物を置く操作

2026-10-04。基準35ad832。有限専用実験。

四層身体に任意のload引数を追加。既定0で既存結果を維持。
effort=1+.1×重量。walk/run/climbのreserve・burst・strain消費とblocked試行消費に
effortを掛け、越え高さを.6×(1-damage)/effortとする。係数はfixture用で生理値ではない。
歩行速度は今回は固定。休息は重量を減らさず、疲労と瞬発余力だけ回復。
障害圧力は高さ/現在の越え能力。1を越えるとclimb不可。

採取物は1単位重量の実資源。拾うとstockからcargoへ移す。
dropは1個を現在位置に置き、Worldに残す。総個数・総重量を保存。
自他とも再取得できる。再取得すると重量制約も戻る。所有権・場所記憶は付与しない。
同一操作ID再送は保存結果、異内容は拒否。drop/拾得は各1秒、今回その消耗は未設定。

選択は本人の身体・積載・正面障害高さ、明示目的、観測済み側方候補だけを入力にする。
climb/rest/drop/detourを比較する固定初期規則。6個という数で分岐せず、実重量と能力で選ぶ。
帰還では荷物保持を優先し、側方候補があればそちらへ。逃走では重量軽減の優先度を上げる。
これは初期の選好値であり学習した判断ではない。

detourは既知の側方への実1歩のみ。迂回完了・帰還完了とは呼ばない。
escape目的は試験側の入力であり、追跡動物との逃走完了を検証するものではない。
身体/幾何は既存モジュールを使うが、cargo台帳とdropは独立fixture。
通常探索・帰還の所持台帳・Sleepへの重量/drop接続は未実装。
既存body-modeのinventoryを暗黙に重量へ読み替えず、過去3日比較は変更しない。
