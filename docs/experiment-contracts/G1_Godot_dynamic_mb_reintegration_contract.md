# G1 Godot Dynamic M_B Reintegration Contract

## Purpose

Confirm that bounded observations produced from the Godot-owned body, space, and
accepted world action can traverse the already established Dynamic `M_B` path.
G1 does not move review, T1, model activation, or game action authority into
Godot.

## Finite Path

```text
Godot bounded observation
-> Runtime local action
-> Godot position change
-> subsequent bounded observation
-> canonical RIB_B / F / F' / E
-> explicit review / H / theta_eff / M_delta
-> T1-A / T1-B / T1-C
-> inactive M_B'
-> explicit cutover / REENTERED
-> fresh Godot observation window under M_B'
```

The Sleep candidate used by T1 is produced by the existing S4 Godot vertical.
It remains material only until explicit T1-B retention.

## Authority Boundary

```text
Godot = body, position, action resolution, world-derived observation
Runtime local policy = game action authority
canonical sidecar = diagnostic comparison and explicit Dynamic M_B transitions
```

`M_B'` activation must not change the local action selected for the same bounded
fixture. Re-entry must not reuse the parent model's previous comparison window.

## Acceptance

1. An accepted Godot action changes position and yields a distinct subsequent observation.
2. The resulting bounded difference enters the existing canonical review and DMB path.
3. The reconstructed model retains the explicitly selected Sleep candidate provenance.
4. Cutover archives the parent and resolves `M_delta` as `REENTERED`.
5. Two fresh Godot observations produce exactly one new comparison under `M_B'`.
6. The local policy returns the same action sequence before and after cutover.
