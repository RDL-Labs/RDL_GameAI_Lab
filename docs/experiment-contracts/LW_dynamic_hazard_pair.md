状態: IMPLEMENTED。基準 `1b1bff6`。対象はlightweight Worldの継続方法選択。

## World

既存の縄張り1体に巡回1体を追加する。資源8地点各12単位、縄張り内3地点、A/B/C、5日、seed20261001/20261002。各seedで巡回なし/ありを比較する。

巡回は(-12,-8)から東向きに速度1.5で移動し、12秒ごとに90度向きを変える。固定障害物との衝突時はそのstepを進まず90度変更する。250ms刻み、同tick再送は同じWorld結果。地形やNPCの結果に合わせて軌道を選び直さない。NPCを学習して追跡する動物ではない。

危険物体は危険観測の対象であり、探索個体へのダメージ、押し出し、動的な物理通行禁止は未実装。接近を避ける保証はない。巡回側の固定障害物衝突だけを実行する。World位置/軌道/個体識別は実験者ログに限定する。

## 観測と選択

`finite-two-hazard-safety-v1` は最大2視覚記録。既存の前方視界、距離12以内、遮蔽、粗い方位/距離帯を利用する。同じ粗い区分でも元の2記録を残すが、NPCにはWorld IDを渡さず恒久追跡もしない。取得が不完全ならpartialを維持する。旧1体schemaは引き続き最大1件。

警戒起動・遠距離確認には最も近い距離帯を使う。遠い1体が見えていても、別の近い1体を無視して解除しない。子方法の方向スコアは全可視脅威に対する方向圧力の最大値を使い、左右の相殺で脅威が消えないようにする。単体時は従来式と同じ。身体結果・現在地面による実行条件、毎観測の選択、親警戒Hは維持。

この規則は最も近い相手が前回と同じだとは仮定しない。距離帯の改善は現在の観測集合における確認材料であり、特定個体から離れた証明ではない。

CLI: `--dynamic-hazard --hazard-scenario territorial --selection-mode continuous`。hazard modeは既存disabled/shadow/enabledを維持。巡回を指定しない旧実験の条件は変えない。

再現: `py -3.11 -m integrations.lightweight.patrol_comparison --run`。保存集約は `tests/fixtures/lightweight_patrol_comparison.json`。World移動量、同tick再実行、遮蔽後の観測情報、入力順不変、2件上限、共有在庫保存、警戒中の行動権限を検査する。
