# L15A — 塔の目印による帰還と有限な昼夜サイクル

状態: FINITE IMPLEMENTATION / 実機受入はEvidence参照。
基準: `edca0b6`。観測v1や既存Sleepの契約を書き換えない明示opt-in。

## 問いと停止範囲

同じWorldでA/B/Cが探索し、開始時に取得した目印を頼りに帰還を試み、
夜間休止後も位置・在庫・履歴を保持して翌日に進めるか。
初版は3日、同じ固定steady profile、1.5倍。帰還・採取成功を強制しない。
一般的な経路記憶や複数目印の連鎖は未実装。初版は塔の粗い外観による帰巣制御。

## 一日の権限

1日64秒。0〜1秒は開始確認のwait、1〜32秒は既存steering v2付き探索、
32〜56秒は帰還、56〜64秒は夜間wait。3日で192秒・1個体768観測。
各命令の期限をphase境界でも切り、前phaseの身体作用を持ち越さない。
昼夜は実験phaseであり、今回のWorld照度は昼間のまま。夜間視界・代謝・飢餓は追加しない。
同じWorldで時計が進む。日ごとに位置・資源8地点×12単位・在庫・採用済みモデルを初期化しない。
探索の一日枠のみ翌日に更新する。夜間に探索selectorを呼んで隠れて予算を使わない。

この専用経路はsteering v2と既存harvest学習を再利用する。
日中のfinite rest/internal reactivation/goal reassessment/reversal reviewは今回は合成しない。
既存各opt-inは変更せず、全機構の同時受入とは呼ばない。

## 塔と観測

Worldに高さ12の黄土色の塔を置く。開始位置は塔の手前。
空域は高さ31まで有限生成する。通常Worldの生成上限18は維持する。
新しい`finite-elevated-fan-v1`は仰角0/15/30度×方位13本、最大39ray、
刻み0.25・最大48のfirst surface観測。距離はnear<=8/mid<=24/far<=48へ量子化する。
遮蔽物・未ロード・未分類はそのまま観測結果へ残す。
返すものは色・方向区間・仰角・距離帯と、個体/観測/取得時刻/姿勢の参照。
座標・node名・正確な距離・World IDは実験者auditだけに残す。
これは波形/画像認識ではなく、既存固定surface型センサーと同じ有限な色分類である。

最初の本人観測で、近距離かつ仰角15度以上に見える色が一種類だけなら、
その観測全体と色を開始目印として保持する。色名を帰還器へ初期設定しない。
取得不完了や複数色なら開始目印未確定のまま。翌朝の野外位置で取り直して拠点を改名しない。
frame内ray参照を恒久的な物体IDとして扱わない。

## 帰還制御

本人の現在skylineと記憶の色を照合し、隣接方向を粗い対応角域へまとめる。
一致色が一角域ならそこへ向けて最大45度の旋回/1単位の前進。
複数角域・不在・取得不完了なら、合計最大4回の90度見回し。
取得不完了から近距離再認を確定しない。4回で不足が残れば未解決としてwaitする。
接近は最大64判断か帰還期限まで。実blockedや身体対応不足で保留する。
移動履歴を逆再生せず、World拠点方位・地図・最短経路APIを入力しない。

近距離の一致色を見た場合は`home_like_observed`。物体同定や厳密な出発点到着ではない。
実験者は塔中心から水平10以内を拠点域として別監査する。
誤再認・未再認・実帰還未達を別に記録し、この真値を個体の選択に戻さない。
帰れなくても転送せず、現在位置で夜間休止する。

## 夜間と記憶

夜間は通常観測・通信を継続し、waitの実結果と身体位置不変を検査する。
これは初期スケジュールによる身体休止であり、生理学的睡眠や安全な宿泊の認定ではない。
身体負荷proxyは実移動距離+旋回量/360を上限12で蓄積し、対応するwaitの実結果から
観測1間隔250msを上限に秒あたり2回復する。日境界でゼロにしない。
このproxyは今回の夜間開始を決めず、経過観測に使う。

夜入り時に本人の当日の移動・旋回・採取指令について、直近最大16受理済み観測/身体結果を出典付きで整理する。
waitは対象外とし、blocked等の不成立結果は残す。対象がなければ空集合として残す。
`local_records_reviewed`とし、`canonical_sleep=not_connected`、`admission=none`を明示する。
SleepConsolidationCoordinatorへ移動ログをExperienceとして偽装投入しない。
既存のharvest学習は従来の検査条件が成立した場合だけ進み、夜間整理から権限を追加しない。
整理したことによる行動改善、複数目印の経路学習は今回の主張外。
