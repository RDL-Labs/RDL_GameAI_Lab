# 継続する局所方法選択

状態: IMPLEMENTED / finite lightweight World comparison。基準: `657185f`。

## 原則と範囲

現行lightweightの探索・採取・帰還・警戒・夜間の共通入口に、毎観測の方法選択を置く。行動回数を使い切ったことだけで永久waitに入らない。待機・見回し・移動も現在の候補として選び直す。実験終了まで動き続けることは、常に並進することや必ず目標を達成することではない。

`timed_harvest` CLIは `--selection-mode continuous` が既定。Pythonの `run()` と直接生成する旧agentは、既存再生契約を保持するためlegacy既定。新しいPython実験は `selection_mode='continuous'` を明示する。`legacy` は比較・旧受入の再現用である。過去の独立Luanti/Godot実験を一斉に変更したものではない。

## E / H / θと選択

`continuous-local-method-selection-v1` はGameAI-localな方法評価。上位food/home/safetyと各方法の状態を分ける。canonical CoreのM_B更新・H受付・T1再構成を主張しない。

- 前回の操作と今回の身体結果・観測の対応があるときだけ比較する。欠測はdeferで、失敗票を増やさない。
- 問いは、粗い見え方が変わったか、実旋回後に現在の前進候補が得られたか、距離帯が離れた等の警戒確認材料が得られたか、採取できたか、実際に休めたか。
- F=1、観測結果F'=0/1、E=1−F'。不成立でHを1加算、成立で当該方法のHを0に戻す。H上限32は数値飽和であり失権条件ではない。
- θ=2。候補スコアに `min(2,H/θ)` の有限負寄与を付ける。同点は最終選択が古い方法、方法名順。毎回新しい乱数を引かない。
- 平常時の実行可能な既存提案は、その方法Hがθ未満なら維持する。θ到達後とwait提案時には代替候補を展開する。警戒中は毎回展開する。
- 候補は待機・左右見回し・現在sample済み方向への旋回/一歩、および既存提案。方法を使い切って永久除外する規則はない。

局所の見え方変化は食料確保や帰還成功とは異なる。旋回によって見え方だけが変わる場合もあるため、この機構だけで循環や迷子が解消するとはしない。上位警戒を維持する根拠のHと、この子方法Hは別記録。

## 権限と出典

身体結果未対応ならawait_bodyを選ぶ。取得不能・高さ不明・出力制限の地面から歩行を作らない。旋回後は新しい前方sampleを必要とし、古い左右sampleを前進許可へ流用しない。近距離の正面脅威へ前進しない。ただし粗い方向による退避は安全保証ではない。

採取作業・荷下ろし・確認済み到着・所持容量・有限休憩・夜間・初期方位取得の既存ゲートは保つ。夜間waitも各観測で選択・実行結果確認する。上位目的や日課そのものを学習生成する変更ではない。

提案を差し替えた場合、未実行の経路・場・位置変更のpendingを消し、経路途中記録を成功強化に使わない。既存経路支持は消さない。同じ観測再送は既存受付キャッシュから同じcommandと同じH状態を返す。

警戒の全周確認は実測の符号付き旋回を積む。左右往復を360度見回した証拠へ昇格させない。不完全な空視界も不在の証明にしない。

## 上限の棚卸し

| 種類 | continuousでの扱い |
|---|---|
| 目印8目標・各12操作・4scan | 回数だけの終了を撤去 |
| 帰還探索32・接近64・4scan | 回数終了を撤去、未達結果も次観測で再検討 |
| 再位置取り16・経路/合成場48・再訪上限 | 回数終了を撤去 |
| 警戒32操作/16秒 | 終端化を撤去。操作数は計測値として残す |
| 逆旋回抑制 | 一提案を抑制できるが、それだけで対象を永久blacklistにしない |
| 採取時間・容量・荷下ろし・body binding | 実行契約として保持 |
| 日課・最大日数・実験停止条件 | 実験/生活境界として保持 |
| sensor処理・記録件数・受信容量 | 有限計算/保存境界として保持 |
| 旧独立rest/reactivation/Probe実験 | 元の有限契約を保持。現行agentへの統合とは別 |

一判断の候補最大9、方法状態最大64、比較履歴末尾32件。試験は3個体・5日、資源8地点各12・有限共有在庫、縄張り重複3地点、脅威有無×旧/新選択の4条件。改善を受入条件にせず、継続選択・身体対応・在庫保存・警戒中採取禁止を検査する。
