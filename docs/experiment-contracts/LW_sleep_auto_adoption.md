# Sleep関係の自動採用実験 v1

2026-10-03。基準84e873c。FINITE IMPLEMENTED。

`--sleep-learning --sleep-auto-adopt --selection-mode continuous`。
自動採用なしを対照とする。既存の厳密な採取T1経路は維持する。

夜間の異種経験窓から、Food有無・危険有無・操作種・操作量を条件として、
実行結果の局所M_B `sleep-unvalidated-action-model-v1` を自動構築する。
1経験でも採用し、独立検査を待たない。成功例を選別せずblocked/not_foundも含む。
completeでない観測は条件不明として残し、学習セルを作らない。
stale/expired等を身体操作の失敗と混同しない。因果関係や普遍則は保証しない。

初版の仮説言語はこの有限な条件表である。任意の概念関係や、全ての共通signatureを
自動的に意味理解する実装ではない。現在目標・phase・場所の一致は適用条件にせず、
異なる局面への粗い一般化が誤ることも実験対象に含める。

成功率はmoved/turned/picked_up/waitedの比率。これは**実行成立率**であって、
食料確保・帰還など大目標の達成率ではない。待機が成立したという反復が待機を
選びやすくすることも許す。負例は消さず、次の睡眠で再集計する。

毎晩の出典IDを重複排除して蓄積（最大192件、超過は明示拒否）。同じ経験を
何晩参照しても支持数を増やさない。採取用M_Bとは別のlocal model_refを持ち、
GameAI-localなM_Bとして記録する。canonical T1検査済みと偽装しない。

既存の実行可能候補のscoreへ `0.75*(2*execution_rate-1)` を寄与させる。
未観測地面を通行可能にせず、新しい操作権限・対象座標を作らない。
候補集合が一件なら順位変更は起きない。夜間/採取等の既存保護も維持する。
各判断にmodel_ref、出典、寄与、寄与前後の選択を保存する。

評価基準は有益性の達成ではなく、本人の経験から自動採用し実行へ効くこと。
採取減少・帰還増減・待機増加もそのまま記録する。
