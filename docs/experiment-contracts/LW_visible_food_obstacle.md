# 見える食料と身体障害 v1

2026-10-04。基準 d53dee7。軽量World専用の有限実験。

食料の視認と身体の通過、採取可能性を分離する。既存探索のセンサーや
移動receiptは変更しない。四層身体BodyWorldを使う独立controllerである。

- 観測点(0,0)、眼高1、食料(0,1.8)・視認高さ.2、障害中心(0,.5)・半径.1。
- 視線と垂直円柱の交差で遮蔽。障害高さ.4/.7/2を比較。
- 歩行・障害越えは既存BodyWorldの掃引衝突、着地空間、高さ能力を使う。
- controller入力は食料の可視/相対距離、経路上障害の粗い高さ、身体能力。
  World座標、stock、ケース名を選択へ渡さない。全対象正面の専用配置であり、
  障害高さの取得はfixtureセンサーの初期能力。一般画像認識ではない。
- 初期規則: 歩いてみる→blockedなら高さと身体能力でclimb/rest/defer。
  食料が近く、間に障害がなければpickup。歩行能力不足ならrest。
- pickupはWorld側でも距離1.25、視認、間の物理障害、実在stockを確認する。
  1単位をstockからinventoryへ移す。操作再送は同じreceiptで副作用なし。
- 各操作1秒、最大8操作は実験観測期限。期限到達は取得失敗や永久不能と同義ではない。

climbは水平移動と高さ制約の近似であり、跳躍軌道・重力・転落は未実装。
迂回、危険、自由探索、Sleep、M_B学習への接続は今回の範囲外。
「越え方を学習した」ではなく、与えた初期能力を現在の観測と身体条件で使う試験。
