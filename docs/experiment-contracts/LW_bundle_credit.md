# 親Hによる経験束の拘束強化

2026-10-07 / FINITE IMPLEMENTED / 既定off。
親は本人のfood-sufficiency、子は未検証のexperience-conjunction。
汎用canonical M_B採用や親子ツリー全体の更新ではない。

経験束の寄与で最終候補が変化した判断に、現在の親goal/model/trialとHを保存する。
最終commandが選択候補と一致し、本人の実行結果が確認された場合だけ試用として登録。
同じ親trialでは最初の適格試用1件のみ。複数寄与は独立した成功票とせず分配する。

既存の5秒評価がreserve>80を確認した場合、選択時Hからmin(H,8)を強化予算とし、
寄与束へ等分する。各束の累計credit上限8。比較不能/未充足では強化0。
操作の成功だけ、単なるreserve増加だけでは強化しない。
再送・同じ比較の再処理では増えない。H解消後もcreditを保持する。

現在の子は行動生成器ではなく、類似条件下で過去行動を抑える局所場である。
creditはその既存寄与を1+0.125*credit倍（最大2倍）にする。
親から子を離散的に一つ選ぶ新しいselectorは作らない。
同じ粗いcontext/phaseでのみ作用し、blockedや上位権限を変更しない。
Sleep休眠後も保持する。shadowと機能offはscore非介入。

成功との時間的関連を帰属する有限仮説であり、因果証明ではない。
試用後の別行動や他者の援助で充足しても強化され得る。
長期間後の成果を遡って帰属しない。失敗時の子独自Hやcredit減衰は次の範囲。
