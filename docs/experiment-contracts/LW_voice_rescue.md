# 声による有限救助

2026-10-04。軽量EnergyWorldの専用実験。通常探索schedulerへの統合は未実装。

初期能力として、歩行不能時の救援発声、粗い救援声の認識、食料携行中の接近、
接触圏での給食を固定する。援助意図の学習、関係性による選別、搬送ではない。
判定は本人の身体、荷物、受信音、接触圏の他個体だけを参照する。

声は半径8・寿命2秒・方位30度刻み。solidによる遮蔽を受ける。
発声位置はWorldだけが保持し、受信側へ座標や発声者IDを渡さない。
近接0.6以内かつ非遮蔽で、現在救援を求めている相手へ食料1個を消費して給食する。
既存layered_bodyのeatを使いreserveを回復する。遠隔給食、食料複製は許可しない。

歩行には既存荷重・抵抗・身体消耗と障害幾何を使用する。
救助者の到達保証、予備エネルギーの自動補給、転送はない。
救助者自身が歩行不能なら救援を呼べる。双方が動けなくても実験結果として残す。
これは行動不能であり、死亡・飢餓経過・不可逆損傷の証明ではない。

12秒、各秒各個体1操作のfixture。再送は個体別操作IDで冪等、内容変更は拒否。
発声・旋回・給食の独自エネルギー消費は初版では未モデル化。
声は移動reserveと独立の初期能力とし、完全に消耗した身体でも発声できる近似。
通常OBS聴覚schema/配送やSleep、危険による負傷とは未接続。
固定反応を自律学習・一般救助知識として扱わない。

次工程は通常探索の救援モードとの調停、発声/受信の配送契約、
援助側の現在目的・危険・身体との候補比較、救助結果のExperience/Sleep保存。
