# Dynamic M_B Inactive Cycle Contract

**Status:** DMB-A end-to-end inactive cycle operational

## Purpose

Join the GameAI-local Experience/candidate path with the canonical rupture path
only at explicit T1 material expansion, then trace one reconstruction to an
inactive `M_B'`.

```text
same agent

-> Sleep window / Profiles / Deep Similarity

-> H >= theta_eff -> M_delta
```

## Causal boundary

The two upstream paths remain independent until T1-A.

```text
Experience != E
Experience != H
CandidateRelation != rupture cause
candidate existence != M_delta entry
```

This reference does not claim that Experience caused the canonical mismatch or
rupture. It proves that a separately sourced candidate can become finite T1
material after the canonical boundary has independently admitted `M_delta`.

## Provenance chain

The cycle retains all raw Experience IDs in the Sleep candidate, the candidate
ID in the T1 material bundle, bundle and selection IDs in reconstruction, and
candidate ID in the adopted inactive relation. The canonical chain retains its
own RIB, assessment, review, H, theta, transition, and model identities.

## Separation

The resulting artifact remains `RECONSTRUCTED_INACTIVE`. It is not inserted into
the active model registry. Old `M_B`, Review Path, active `M_delta`, and Runtime
action authority remain unchanged.

Authority cutover and re-entry are DMB-B responsibilities and require a
separate contract.

## Acceptance

1. A real finite Experience set produces a sourced Sleep candidate.
2. Canonical rupture occurs without reading that Experience/candidate path.
3. The paths join only through explicit T1-A input.
4. T1-B retains the candidate with explicit provenance.
5. T1-C adopts only that retained candidate into inactive `M_B'`.
6. Old model registry and `M_delta` remain unchanged.
