# 拠点所属からの主観的援助関係

2026-10-04。軽量World専用有限実験。一般好感度、canonical M_B/T1、Sleepには未接続。

A/B/Cを同じ拠点の既知メンバーとして初期化する。所属は学習せず、相手認識も初期能力。
個体ごとの援助期待は方向付きで、A→Bの更新からB→Aを更新しない。
援助以外の信頼・敵意・所有・包含関係へ一般化しない。

援助期待の初期値は0.5。有限な局所規則 `(1+援助観測Episode数)/(2+終了Episode数)` を使う。
この擬似カウントは初期設定であり、Experience支持数ではない。
本人が近接観測した相手について援助を期待し、発声から3秒以内の本人向け給食を検査する。
給食が複数回でも1 Episodeは1件。無応答は `no_aid_observed`、意図は常に `unknown`。
聞こえたか・拒否したかという実験者情報は関係更新へ渡さない。
本人に取得されていない個体へ責任を割り当てない。最大16 Episode、再評価で件数は増えない。

次の選択は現在近接観測しているメンバー間の援助期待で比較し、同値はID順。
対象は「次に援助を期待する相手」。実発声は従来の無指向救援声であり、
名前を呼び分ける音声伝達・受信者限定・選んだ相手の応答保証は未実装。

初回は救助、聞いたが応答しない、受信不能の3条件。
無応答条件は実験者がrestを指定し、受信不能はBの聴覚と救援声認識を無効化する。
個体の悪意・聴覚障害の自律推論・聞き流す性格を実装したものではない。
第二EpisodeはWorld/身体を再初期化し、Aの関係記録だけ保持してBによる救助を実行する。
次回比較時はCを近接に配置する共通fixture。自律探索で相手を見つけた証拠ではない。

次工程は通常探索への接続、声の相手指定、援助する側の目的競合、
援助以外の相互作用、保存材料とSleep/T1の契約。今回は局所援助期待だけを検査する。
