# Luanti L13T — 自然地形での有限探索・再訪

状態: 実装済み。実行結果は[Evidence](../experiment-evidence/LUANTI_L13T_natural_exploration_evidence.md)。2026-09-27。
意味基準は[Core参照](../semantic-reference/RDL_Core_T0_T1_reference.md)。
[L13S](LUANTI_L13S_learned_exploration_contract.md)の学習・独立検査・T1/M_B経路を維持して、Worldと身体・取得条件を広げる。

## 問いと固定条件

道を教えない初期試行と本人の経験経路が、草地・起伏・木立・岩・水辺のあるWorldでどうなるか。
有限な手続き生成地形であり、現実の地形や生態系を再現したという主張ではない。
一般のmapgen Worldを自由に歩けることも受入条件にしない。

- `natural_meadow` / `natural_woodland`の2配置を先に固定。同じ地表形状・岩・水辺・Food・開始位置で、木立の密度だけが違う。
- 人工的な色帯・道・案内標識は置かない。地面の草/土の分布と木立はFood位置や試行乱数から独立に生成する。
- 実ノード範囲x/z±56、y=-6..18。身体の活動範囲はx/z±32。地表高-3..3、遠景の山3か所は既存共有センサーの有限対象を維持。
- 草/土の起伏、木の幹/樹冠、岩4か所、固定水面の浅い水域を置く。水は静的な通行不能ノードで、流体・水泳は実装しない。
- 実験者だけがFoodの位置を配置する。Runtimeには地形図、高さ関数、配置seed、scenario、Foodへの経路を渡さない。
- 初期試行seedは既存と同じ`20260927`。成功するseedや配置への探索・救済をしない。
- 昼間、単独A、1日16秒/64枠。別日の発見3回、最大30日。初回発見後の日末Sleep、日ごとのWorld復元、pickupと発見の分離はL13Sと同じ。

## 自然地形専用の取得・身体契約

configureは`l13t-natural-exploration-v1`。旧`FiniteExploration`では拒否し、明示した学習用入口だけが受け付ける。
旧L13A/R/Sの平地schema、取得条件、保存replayは維持。同じ学習系列の途中で平地/自然地形の契約を交換しない。

**局所面観測**は`l13t-local-surface-rays-v1` / `l13t-natural-fixed-v1`。
現在の眼高（身体基準+0.5）から、身体相対の中央・前後左右1/2を終端方向とする9本の下向きray。
終端高は身体基準-3、間隔は最大0.125node。各rayの最初の面から粗色のみを返す。
草/葉green、土/幹brown、石gray、水blue。地表座標、高さ、node名、材質分類、通行可能性は返さない。
木や岩に当たればその表面を取得したことになり、その後ろの地面を透視しない。
未ロード・未知の遮蔽物・到達面なしはunknown/partialとする。旧平地9地点の直接サンプルとは別モデル。

**局所Food**は半径12の3D距離に加え、眼からFoodへの最大0.125node間隔の遮蔽検査を行う。
取得済みのFood参照・相対forward/right/up・3D距離だけを返す。距離内でも実ノードで遮られればvisibleは空。
判定途中の未ロードはpartial。完全な空観測をWorld全体のFood不在へ読み替えない。
現行の方向制限なしの局所Food検出を維持し、画像認識や視野内物体認識へ拡張したとはしない。
共有遠景は従来の粗い山の色/角域のみ。木の同定や樹冠の意味理解は実装しない。

**身体**はkinematicな有限step adapter。物理エンジンの歩行・跳躍・転倒ではない。
moveは水平1node、上下差は最大1node。4つの中間地点で、局所ノードから支持面と身体2ノード分の空間を検査する。
全地点で通れる場合のみ位置を変更する。2段の段差、支持面なし、幹・樹冠・水域、活動範囲外はblocked。
地形全体の高さ関数や経路探索を移動決定に使わない。回転±90度・wait・観測reach内pickupは従来どおり。
中心線と足場の有限検査であり、任意の身体幅・斜面接触・動的障害物を扱う一般collision solverではない。

結果に実測`up`を追加し、moved以外は0、movedでも±1以内の整数段差を要求する。
pose/revision/期限/同操作再送の一回実行条件を維持する。
1stepの3D変位は最大√2、64操作の距離上限は64√2。距離指標は実測forward/right/upから計算する。
旧平地の64node予算は変更しない。

## 学習の境界

抽選器は変更しない。草を追う、木を避けて曲がる、水なら遠回りする等の探索規則は追加しない。
blockedを実経験として記録するが、障害を見ただけで一般的な迂回能力を得るわけではない。
取得不足時のwait、観測reach内pickupも既存契約どおり。

本人の初回発見までの観測・実作用を候補化し、未使用日の明示Probeで検査し、T1/M_Bへ採用する。
元観測条件に加えて、各stepの実測上下差も保存・照合する。指令move1だけで同じ身体結果とみなさない。
同じ粗い外観でも上下差が変われば経路を中止し、検査はDEFERとなり得る。
旧平地の色/取得モデルが自然地形と一致したことにはせず、採用済みの旧モデルを無条件適用しない。
一般的な地形理解、場所同定、最短経路、経路圧縮、障害回避の学習、複数候補再検査は引き続き後続。

## 受入と記録

1. 実ノードから地形・支持面・身体変位・遮蔽を読み戻し、実行記録と照合する。
2. 両配置で同じ初期試行乱数を使い、地形は各日同じ状態へ復元する。
3. 実取得をHTTPで受理し、全wireを現在コードで再生して同じ状態・判断になることを確認する。
4. 草地/木立で、発見日・通行不能・上下移動・遮蔽・pickup・検査/採用をそれぞれ数える。
5. 3回発見または30日打切りをそのまま保存する。発見できないことを機構エラーにしない。
6. 地形図や実位置は実験者専用Evidence/可視化に隔離する。
7. 旧L13Sの固定replay・全体試験を維持し、旧平地の実Luanti回帰も実行する。

地形差と学習効果を同一視しない。地形が違えば観測・衝突・履歴も変わるため、
両配置の発見日差だけからM_B採用の因果効果や生物一般の探索能力を結論しない。
