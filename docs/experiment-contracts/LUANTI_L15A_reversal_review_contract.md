# L15A — 逆旋回停止後の静止再観測

入口は `l15a-reversal-review-v1`、`reversal_review_mode=disabled/enabled` の明示opt-in。
単一32秒作業・3個体・1.5倍・草地・障害除去を同条件で比較する。

## 権限

既存steeringが実旋回の反対向きへの要求を止めたとき、個体ごと作業内最大1回だけ、
その対象を直ちにblocked_targetsへ確定せず保留する。身体はwaitを実行する。
次の通常250ms観測で1回だけ検討する。センサーの追加呼出し、見回し、移動の強制はない。

停止元の観測ID、取得時刻、sample_seq、姿勢参照・revision、対象と接近操作数、
停止前の実旋回方向と連続旋回数を保持する。
次観測のseqが直後で500ms以内、wait実行結果が受理済み、取得姿勢が不変であることを要求する。
待機を「旋回をしていなかったこと」や「移動に成功したこと」にはしない。

- 現在観測と既存制御が同じ反転要求を返す：`same_reversal_deferred`、waitと対象保留。
- 姿勢・時刻・wait結果が不足：`correspondence_unavailable`、再試行権限を消費して保留。
- 取得/選択を確定できない：`acquisition_unresolved` / `selection_unresolved`。
- 別対象や上位条件へ移った：`target_or_priority_changed`。その現在の処理を乗っ取らない。
- 同じ対象が採取可能：`pickup_priority`。既存の採取条件を優先。
- 現在の完全な地形から非反転のmove/turnが選択された：`released_to_existing_control`。

最後の状態も身体実行成功を意味しない。後段の疲労休憩・現在の権限・実身体結果を別に確認する。
一回の再検討後にまた停止しても、このモードの検討枠は増えない。
保留を既存期間内の除外集合へ記録するが、通行不能・資源価値・恒久的な負例とはしない。
接近操作数、目標数、追加目標枠、休憩枠をリセットせず、新M_Bや学習材料へ昇格させない。

## 検証

disabledは既存制御を維持する。enabledの静止・次観測・診断・保留まで実Luantiで検査する。
変化した現在選択を通す正例は合成試験として区別し、実機で起きなければ成功を作らない。
再送で検討や身体作用を増やさず、不正設定はstateを変更せず拒否する。
通常観測数は32秒×4×3=384件、個体ごとの開始は最大1件。
