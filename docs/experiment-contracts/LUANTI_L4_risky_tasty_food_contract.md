# Luanti L4 Risky Tasty Food Contract

## Status

L4 operational World reference on Luanti 5.17.0.

## Purpose

Establish the physical Risky Tasty Food vertical without adding a new Runtime
preference, danger belief, or action authority.

```text
sourced God Statue statement
+ visible tasty Food
+ finite territory relation
+ visible beast
-> existing BaseFoodLifePolicy approaches the Food
-> Luanti warning
-> Luanti chase
-> Luanti attack
-> medium injury + forced retreat
-> subsequent bounded observation
```

## World Ownership

Luanti owns the Food and beast positions, territory geometry, intrusion count,
warning/chase/attack transition, injury, and forced retreat. The Runtime receives
only finite visible entities, visible region relations, recent World events, the
sourced external statement, and a bounded self Body snapshot.

The God Statue statement is information with source and provenance. It is not
World truth and does not command an action.

## Runtime Reuse

L4 uses `python -m runtime.bridge --base-food-life`. The existing policy selects
the visible Food and requests `approach`. No Luanti-specific danger, reward, or
preference policy is added.

The resulting failure path is produced by Luanti while resolving successive
approach requests inside the territory.

## Separation

```text
God Statue statement != World truth
territory relation != danger belief
beast entity != dangerous concept
warning/chase/attack fact != E or H
medium injury != Local Bias
forced retreat != Runtime action authority
L4 World consequence != Experience admission
L4 != Outcome Gradient, CandidateRelation, T1, or M_B update
```

The observation packet does not contain `danger`, `dangerous`, or `threat_score`
labels.

## Acceptance

1. The packet contains a source-bearing God Statue statement about tasty Food.
2. Tasty Food, the beast, and their finite territory relation are observable.
3. Existing Runtime behavior approaches the Food without a new policy.
4. Luanti resolves repeated intrusion as warning, chase, then attack.
5. Attack produces medium injury and a forced retreat owned by the World.
6. A subsequent bounded Body snapshot reports the injury.
7. No learning, canonical admission, or action-policy promotion occurs in L4.
