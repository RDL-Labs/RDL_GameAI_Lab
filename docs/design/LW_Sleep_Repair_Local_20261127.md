# 睡眠だけで身体消耗を修復する局所比較

通常LW未接続。ActivityCapacity.step!へ任意wear_rulesを追加し、局所だけrest_per_hour=0とした。既定の身体動作は変更していない。起きたままの休息は短期疲労を減らせるが、身体消耗を回復しない。睡眠は両方を回復する。修復材料は十分と仮定、追加栄養費用は未接続。

configured_paths/sleep_repair_local.jlで、追加活動→帰宅、即帰宅、現地睡眠→帰宅、現地睡眠の4候補を同じ6生活時間で比較。帰路時間は入力済みの見積もりであり、今回身体能力の低下から所要時間を再計算するものではない。作業は歩行相当1時間・効用4、現地睡眠1時間という暫定固定。自宅価値と負担係数は既存RETURN_REST_RULESを再利用。将来は作業・場所MBの見込みへ置換する。本人の実身体は予測で更新しない。
