# 初日の拠点見回し（設定経路）

2026-10-25。`--home-observation on`で、実行開始から最初の1日だけ通常の探索移動を強制観察へ置き換える。既定off、MB地図ONが必要。4日実験なら1日観察＋3日通常行動。自律学習された段取りではなく、将来撤去する設定経路。

## 行動

安全行動、即時の食事、社会応答など既存の優先処理を通した後、通常の移動候補選択へ進む前に設定経路を選ぶ。240tickごとに開始位置から小さいオフセットを選び、最初の16tickだけ移動を試す。4地点のオフセットは(-0.6,0)、(0,0.8)、(0.6,0)、(0,-0.6)。大きな方向差は先に旋回し、歩幅は最大0.25。移動しない時間は30度ずつ旋回して観測する。障害物との衝突は通常の物理判定を通す。

夜間の静穏時間、疲労上限、エネルギー切れでは休息する。安全行動が設定範囲を越える可能性は残し、強制テレポートや安全処理の無効化はしない。初日の帰還目的開始は抑制し、翌日から既存の帰還・身体目的判断へ戻る。

開始位置と現在位置はこのテスト用の移動範囲に使う。拠点中心・入口・構造の正解をMB地図へ注入するものではない。これは観察を促す足場であり、純粋に感覚だけで動作する学習政策ではない。

## 記憶と報酬

見回しで得た通常の視覚と実行結果は既存のmb_observe!/mb_record!へ渡す。設定観察の動作をfood/homeの目的達成経路として報酬化しないため、MB記録上のpurpose_familyは空にする。視覚の2色条件、キーの作り方、深さ・鮮度、睡眠探索は変更しない。

したがって、1日観察しただけで拠点の関係構造を学習済みとは扱わない。観測材料を増やす試験であり、視点統合、1特徴観測の保持、ρ階層化は別の課題。

## 記録

result/summaryのhome_observationに初日のtick数・実際の行動数・有効観測数・観測キー・最大開始位置変位・初日末の地図サイズを保存する。翌日以降はカウンタを更新しない。イベントのconfigured_observation methodは初日の強制行動を識別する。

[4日試験](../../experiments/rock_gate/home_observation_report.md)。

## 初日用の有限備蓄

実験runnerの`--camp-provisions 4`は各開始位置に4食ずつ（3個体なら12食）を配置する。世界の初期条件であり、身体エネルギーや学習済み地図を直接与えない。food要素のrenewable=falseで自然再生の対象から除外する。既存の外部食料は従来どおり再生する。残った備蓄は初日後も物理的に残る。

見回し中、身体要求があり携行食料がない場合は、現在見えていて1.25以内にある食料の通常pickupを優先する。次に通常eatを行い、満たされたら観察へ戻る。3個体で取り合いになる共有倉庫ではなく、開始位置ごとの有限な食料置き場として実装した。取得・食料保存則は通常処理を使う。
