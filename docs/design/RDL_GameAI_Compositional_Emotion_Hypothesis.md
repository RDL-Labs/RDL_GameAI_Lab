## 1. 仮説

感情を最初から一つの数値や排他的なラベルとして与えるのではなく、目的・問いを持つM_B、個体側の評価機、関係ごとに残るH、それらが現在の観測や身体状態と相互作用する過程から、感情的と解釈できる挙動が現れると考える。

これはGameAIで検査する構成仮説であり、人間や動物の感情の実証済みモデルではない。「合成」は寄与を一つの快不快値へ潰す意味ではなく、複数の関係が同時に作用し、選択・身体操作・後続評価へつながることを指す。

## 2. 責務の分離

|要素|仮説上の役割|同一視しないもの|
|---|---|---|
|M_B|何を目的・問いとし、どの断面をどう解釈・予測するか|感情ラベルそのもの、単一の移動命令|
|評価機|現在の目的・身体状態・個体条件のもとで、差や未解消状態をどう扱い、候補に寄与させるか|Core Eの定義、World真値による正常／異常判定|
|E|比較条件をそろえた差|自動的な不快、恐怖、報酬|
|H|Eのうち未解消として残る状態|欲求の内容そのもの、必ず悪い量、支持数、モデルの太さ|
|行動選択|複数の寄与と適用条件・身体権限から現在の作用を選ぶ|感情を一つだけ選ぶ処理|
|観測側の感情記述|履歴・評価・作用の組合せを記述する仮説的な解釈|本人の主観体験が証明されたという主張|

評価機も将来は履歴・身体・神経条件に依存し得るが、初版の固定評価規則と経験から変化した規則を分ける。M_Bが初期設定か、本人の経験から採用されたかも出典で区別する。

## 3. 恐怖と好奇心は同時に成立し得る

同じ未知対象について、安全確保側は接近を抑制し、探索側は追加観測へ寄与し得る。

```text
未知の対象についての本人観測
├─ 安全確保の問い → 離れる／距離を保つ寄与
└─ 理解・探索の問い → 観測を続ける／近づく寄与
               ↓
       現在条件と身体権限で選択
```

未知であることを既知の危険と等置しない。また、未知そのものを自動的に大きなE/Hへ変換しない。予測がない／比較できない場合は未解決の問いや不確実性として保持し、Hが成立する場合だけ、その比較契約と出典を付ける。

個体によって回避が強い、追加観測が強い、両方が強いという違いを許す。最終的な移動量が0でも、両寄与が弱い場合と、強い接近・回避が拮抗した場合を区別する。

想定される観測例は、距離を保って見る、少し近づいて止まる、一度離れてから戻る、見続けるが接近しない、など。これらの行動だけから感情を一意に同定しない。

## 4. 中心シナリオ：退避後に「あれは何だったか」が残る

```text
未知の対象を観測
→ 安全確保が現在の操作権限を得る
→ 退避・待機・再観測
→ 限定された安全側の条件を確認
→ 保留されていた問いを再検討
→ 遠くから見る／見に戻る／今回は保留する
```

この変化を「恐怖の値が好奇心の値へ変換された」とは必ずしも扱わない。両方の関係が残っていて、安全側の切迫が下がることで、それまで抑制されていた探索側の寄与が選択へ現れるという説明を候補とする。

安全について解消した差と、対象の理解について未解消の問いを分ける。退避成功が、関連する全Hを一括で0にする理由にはならない。

ただし、理解側に比較可能なEが生じていないなら「理解Hが残る」と捏造せず、保留された問いとして扱う。同じ対象を再発見したという同一性も、外観が似ているだけで確定しない。

退避したことと安全が確認できたことは別。見失い／partial／期限超過では安全確認を成立させない。探索側の寄与が残っていても、身体操作権限や危険対処契約を飛び越えない。

## 5. 目的・関係に結び付いたHと欲求

未解消の差が後続の選択へ繰り返し作用するなら、目的に向かう欲求的な挙動として現れる可能性がある。

同じ大きさのHでも、何を問うM_Bに属するか、評価機がどう応じるかによって、安全を求める、確かめる、食料を探す、離れて保留するといった違いが生じ得る。

Hが大きいほど必ず回避する、あるいは必ず解消へ突進するとは固定しない。差のある対象への関与を好む個体も候補とする。ただし「差を楽しむ」はHを無制限に増やすことを目的にする規則とは異なる。

## 6. 循環と個体差

```text
M_Bと現在観測
→ 比較・未解消判定
→ 評価機による各候補への寄与
→ 操作権限の選択
→ 身体作用と新しい取得
→ 問いごとの解消／未解消／比較不能
→ 次の評価・M_B選択へ
```

局所M_Bの選択切替と、M_B内容の学習更新／canonical再構成は別である。感情的に見える挙動が変わっただけでT1やM_Δの成立とは呼ばない。

個体差の比較候補は、評価感度、残存・減衰、保留した問いを再参照する傾向、切替条件。最初は一要因ずつ固定系列で比較し、後に組合せる。研究由来の実証値ではなく有限実験の設定であることを残す。

## 7. H解消と成功経験の重み

[非線形強化メモ](RDL_GameAI_MB_Reinforcement_Nonlinearity.md)への追加仮説として、成功で実際に解消した目的・関係のHを、更新寄与の材料として記録できる。

個体の総H、単なる経過時間、無関係な負担を成功の強さに足さない。自然減衰・目的変更・評価条件変更によるH減少を、成功による解消量として誤帰属しない。

supportは独立した成功経験の計数、H解消量はその経験の別属性とする。Hをthicknessへ直接変換する式、学習率、逓減則は本書では定めない。予測のない初回経験でも学習材料は残せるが、大E/Hを仮定しない。

## 8. 保存すべき観測（schema案、未実装）

- 個体・run・取得／実行時刻、source frame、実行結果。
- active／保留中の目的・問い・M_B参照と版、初期設定／学習由来の区別。
- 比較契約、更新前モデル、Eの有無、defer理由、関係別のH前後と変更理由。
- 評価規則版、各候補への寄与、適用不能理由。最終合成値だけにしない。
- 現在の権限、切替元／先、保留理由、再参照理由、実際の操作。
- 待機時の拮抗・情報不足・安全条件・身体制約を区別する診断。
- 観測者による感情的解釈を付ける場合、その根拠と未確定性。個体入力へ戻さない。

同じeventの再送や、同一経験を複数の問いから評価したことを、独立経験の水増しにしない。各問いの評価は残せても、親子のHを無条件に加算しない。

## 9. 最小比較案（すべて未実施）

|比較|固定するもの|調べる違い|
|---|---|---|
|回避寄与／探索寄与／両方|同じ未知観測系列・身体条件|離れる、見る、距離を保つ、拮抗待機|
|退避前／限定安全確認後|未知についての保留記録|安全側の寄与低下後、問いが再選択されるか|
|保留問いあり／なし|安全観測と対処規則|退避後の再観測選択が保存された問いに依存するか|
|安全確認／見失い／取得不完了|探索側の設定|確認不足でも復帰したと誤認しないか|
|同じ合成0・異なる成分|身体操作の結果|無関心と強い拮抗をログで識別できるか|
|同じ成功・異なる関連H|成功event数と結果|支持計数を変えず解消量を別属性で保持できるか|

全個体が好奇心を示す、退避後は必ず戻る、感情が一つに決まることを成功条件にしない。問いを保留したまま終わる・食料へ戻る・再接近してまた退避する・機会を失う結果も保存する。

仮説を支持しない結果も明示する。例えば、問いを保持しなくても同じ復帰が起きるなら、今回の挙動を保留問いの効果に帰属しない。各寄与を変えても選択が同じなら、適用機会がなかったのか、身体制約や権限が支配したのかを分ける。
