# Hによる共通指数型探索：局所比較 2026-11-12

## 変更

共通の有界指数関数を兎の候補数と捕食者の探索半径へ接続。
詳細・設定・暫定の境界幾何参照・OFF方法はLW_Parameter_Catalogの同日項目を参照。
半径は4..64、H2で上限、曲率3。真の獲物分布は使わない。
既存の親H/未回収消費/空腹による選択Hを再利用し、別Hを加算しない。
低いHで近隣、高いHで遠方の仮目標へ進む。到着は食料成功にしない。
SEARCH時のみ適用し、匂い追従・視認追跡は優先。

共通化したのは指数の形であり、各動物のH単位や候補の意味を同一化していない。
既存の全行動がこの関数を使うという意味でもない。
初回H20試行は最大半径4.99に留まったため、食料評価尺度に応じH2へ調整した。
