# 捕食者の満腹待機中の再判断を抑える

2026-11-12。人なしで生態系を調整する前の省エネ変更。捕食圧は未変更。

## 条件と意味

暫定固定、既定ON。configured_paths/predator_idle_gate.jl に隔離。
既存のMBでidleが選ばれた後のみ、身体備蓄が初期備蓄目安900以上、回復需要が
既存need_band以下、可視ライバルなし、生存中なら同じ待機を継続する。
plan! のidle_gate=falseで無効化。休息restや狩猟huntはこのゲートの対象外。
既存のライバル視認は毎tick継続し、未観測の相手の情報は追加しない。
食料需要、回復需要、ライバル、死亡時は通常の試行終了・選択へ戻る。
代謝、身体更新、他個体から捕食者を観測する処理は継続する。
停止中は視線の周期更新も省略するため、復帰後を含む行動同一性は保証しない。
将来は共通の注意・割込み機構へ統合する。

## 記録・保存

進行中試行にidle_gate_sinceを記録。再開時に経過tickと累積消費を一括で
既存試行APIへ渡す。保存再開でもこの起点を保持する。停止中のelapsedは遅延更新であり、
観察時にそれだけを現在の経過時間と読まない。過去のチェックポイントは起点なしで読める。
短い待機の終了・経験更新・乱数消費が減るため、厳密な同値最適化ではない。
