# 初日の拠点外観観察（固定設定）

2026-11-03。scene.configured_camp_exterior=true で、既存の初日拠点散策に外観観察を追加する。既定false。home_observation/configured_camp_landmarkを有効にした初日だけ使用し、通常日の目標選択を変更しない。

固定介入：拠点座標を実験用誘導だけに用い、既存内側散策後、中心相対(0,3)を経由し(0,16)、(0,10)へ移動する。各地点で中心方向へ振り返り、3 tick通常観測を得て(0,3)、(0,1)へ戻る。歩行は通常の身体・衝突処理を通す。外観ON時3600秒上限（OFF時1200秒）、疲労・身体条件による既存中断を維持。通れた／見えたことを仮定して完了を捏造しない。

座標はconfigured_paths/camp_landmark.jl内の誘導に限定する。世界IDや塔専用報酬・帰還経路を記憶へ注入しない。通常のmb_observeとmb_place_collect!が散策中の観測・遷移を収集する。既存の散策終了後の拠点休息報酬は維持するが、今回新たな報酬は加えない。拠点episodeが外観を含むことは固定学習機会下の結果であり、自律的な外観学習の完成とは言わない。

記録：home_observation[actor].camp_landmark.recordsのexterior_camp_viewに距離・位置・向き・実観測の形状/上方特徴を保存。exterior_viewsは観察地点実行数で、塔の同定数ではない。実験条件にも固定設定を記載する。将来はMBによる自律的な観察地点選択へ置換する。
