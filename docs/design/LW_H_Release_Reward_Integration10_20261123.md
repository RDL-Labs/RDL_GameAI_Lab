  子への基礎報酬を重ねない。未知の目標やBoolだけでは予測を捏造しない。

  親・子の同じ成果を二重計上しないため減少量は最大値。中立帯以内の成果に報酬を付けない。
  成立だけで全Hを消さず、部分的な取引では不足が残る。
