# 拠点の安全地帯

実験用の世界ルール。config.camp_safe_zone / rock_gateの--camp-safe-zone onで有効（既定off）。荷下ろし・食事と同じ中心半径1.25以内を保護する。危険源との距離・観測方向に依存しない。半径5の観測用境界とは別。

センサーはsafe_zoneを明示し、作用する危険featuresを空にする。元の可視危険はobserved_hazardsへ保持する。方策へ世界座標を渡さない。既存・連続の両危険回避を即解除し、進行中の危険回避試行は成否不明で閉じて、方法の成功報酬を追加しない。夜間恐怖にも保護状態を渡し、Hは既存の時定数で減少する。安全地帯外では元の危険回避が働く。

現行の危険源は回避判断用で、直接攻撃ダメージを適用する系ではない。将来攻撃を実装する際は世界の被害処理にも同じ保護条件が必要。安全地帯は食料不足や疲労を解消せず、滞在自体を強制するものでもない。
