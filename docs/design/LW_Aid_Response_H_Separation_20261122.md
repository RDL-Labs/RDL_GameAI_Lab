# 援助要求Hと提供判断の分離

2026-11-22。開始HEAD `a173f20`。既存の未コミット変更を保持して局所修正。

## 変更

`experienced_response`は援助要求の`obtain-aid`ループを提供選択へ流用しない。
共通のBasicLoopによる今回の`provide-aid`評価をH=0で作り、要求Hを選択温度にも関係MBの検索幅にも渡さない。
提供側の独自H蓄積や感情の残留・減衰は未実装。毎回作る評価器は永続状態ではなく、要求の履歴・H・RNGを変更しない。
旧互換経路でも、自分が要求を拒否されたHを直接提供の罰点へ転用する処理を外した。

身体要求、食料不安、食料保持コスト、相手の観測表情、経験から得た関係評価は維持する。
確率選択のseedとハッシュによるdraw、資源可用性の検査は維持する。
診断ログも提供側のH=0を記録し、traceに`pressure_scope`と`response_H`を追加。
援助要求先選択・要求結果によるH更新は変更しない。
