# 食料目的 → 食料源 → 経路

目的のゴール候補を決める前に、経路の作りやすさや候補列の順序で食料源を暗黙に選ばない。
acquisition_targets!で視認中の機会と成功経験に結び付く食料源、未知の探索を比較する。
記憶食料源はfood_ref単位でまとめ、複数の成功経路があっても候補数を増やさない。
成功経路の最大関係強度、既存の獲得見積もり・H・糖予測、最後に観測した利用可能性を使う。
空確認によるavailability=0.25は既存値を維持。未知の世界在庫や食料座標は参照しない。
新たな固定行動、固定した採取先の優先順位は追加しない。

選択後、その食料源に結び付く記憶経路を生成・照合する。経路の上位4件への切り詰め前に絞り込み、
覚醒探索の終点判定、成功経路の接続表、目的付き目印、日次見積もりにも同じ選択を使う。
目印キャッシュは選択食料源の変更でも更新する。探索選択時には、既知の別ゴールへ勝手に置き換えない。
帰還には食料ゴールの制約を適用しない。局所歩行・見回し・再確認・経路放棄は残す。
通常経路から場所Hの別建て減点を外す。空情報の観測は残し、ゴール側の利用可能性へ使う。
旧場所減点関数は比較・専用検査のため残るが、通常dayの選択前には呼ばない。

記憶の目標選択には既存の親探索見積もりを粗い初期見積もりとして使う。選択後に経路の実現性を調べる。
経路が見つからなくても座標を生成して直進させない。次の既存64秒評価などで再選択できる。
これはゴールと経路を同時最適化する完成版ではない。参照の付いていない過去の食料経験は
特定食料源へ勝手に割り当てず、一般探索のまま扱う。
釣りの経験がある参照は既存acquisitionの記録から識別し、魚在庫の視認とみなさない。
研修の設定経路は既存の例外として残る。
