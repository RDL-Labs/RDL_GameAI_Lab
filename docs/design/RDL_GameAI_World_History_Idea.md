# 世界履歴 — 相互作用の痕跡が次の条件になる

状態: **IDEA / DESIGN ONLY / 未実装・未検証**  
作成: 2026-09-30  
照合基準: `0841645`

## 1. 基本アイディア

個体の行動結果を、個体内部のExperienceやM_Bだけでなく、Worldの状態変化として残す。その変化を後で本人や別個体が観測し、次の行動条件として利用し得る構造を「世界履歴」と呼ぶ。

```text
個体の作用
→ Worldの局所状態が変わる
→ 痕跡が残る／重なる／薄れる
→ 本人や他個体が有限に観測する
→ 各自の目的・経験・評価から次の作用を選ぶ
→ Worldがさらに変わる
```

主例は草地の踏み跡である。道を最初から配置するだけでなく、多数の通行が同じ場所に重なることで、World上に道が形成される状況を将来の目標とする。

## 2. 三つの履歴を分ける

|層|保持するもの|個体が知ってよい範囲|
|---|---|---|
|個体の履歴|本人が取得した観測・実結果・学習材料|既存の取得／記憶／採用契約に従う|
|Worldに残る履歴|踏まれた草、摩耗、資源状態など、現在の環境状態|現在観測できる痕跡。原因や過去の全過程を自動的には知らない|
|実験者のログ|誰がいつどこで作用したか、真の蓄積量、状態更新|監査専用。個体へ直接渡さない|

世界履歴は全イベントを保存するデータベースの別名ではない。Worldの現在状態が、過去の作用の影響を残していることを指す。痕跡から元の履歴を一意に復元できるとは限らない。

踏み跡が見えても、誰が作ったか、何回通ったか、どこへ続くか、安全か、所有者がいるかを自動的に知ることはない。他者の内部ExperienceやM_Bが共有されたとも扱わない。

## 3. 主例：草地から道へ

```text
未踏の草地
→ 一度通ると草が踏まれる
→ 通行が重なり薄い踏み跡になる
→ 草が少なくなり道筋として見分けられる
→ 多くの個体が利用し、道として定着する可能性
```

経路をプログラムが線として描くのではなく、実際に身体が通過した範囲へ局所作用を加える。移動指令だけ、旋回だけ、blocked、同一操作の再送では通行を水増ししない。移動の始終点だけでなく、その間の通過範囲を扱う場合は、1回の移動を何セルへどう配分するか固定する。

将来は同じ場所への利用が、外観だけでなく植生状態・足場・移動負荷を変える余地を持たせる。ただし「道らしい見た目＝必ず歩きやすい」とは固定しない。ぬかるみや損傷が起きる拡張なら、通行が条件を悪化させる場合もあり得る。

## 4. 初回実験候補は外観だけ

最初は草地→薄い踏み跡→道相当の外観段階に限定する。実験上の段階であり、植生生理の再現ではない。

- World側に有限な局所踏圧／摩耗状態を持たせる。
- 実移動結果に対応した通過だけで蓄積する。
- 既存地面観測へ粗い色・状態差として投影する。
- speed、移動cost、Food位置、採取条件は同時に変えない。
- 「道へ向かえ」「道は食料へ続く」という専用規則を与えない。
- 回復・季節変化は初回には混ぜず、必要なら後の独立比較にする。

外観変化を既存consumerがどう扱うかも確認する。色の変更が既存の通行可否や移動costを暗黙に変えるなら、外観だけの実験とは呼べない。痕跡が観測されても行動差0という結果を許す。

## 5. 複数個体から共有環境へ

Aが作った踏み跡をB/Cも観測できる。ただし痕跡の利用は、各個体の目的、観測範囲、現在M_B、評価規則による。初期状態から全員が道を好むとは仮定しない。

```text
個別の移動
→ 共通の環境痕跡
→ 個体ごとの読み取り・選択
→ 利用が集中／分岐／放棄
```

道筋が成長すれば、個体間の直接会話なしでも、過去の作用が他個体の条件を変える。ただし意図的な伝言、協働、合意、所有の成立とは別である。

道が形成されたことと、それが選択を誘導したことも分ける。形成だけなら作用→World、利用までならWorld観測→選択への接続を検査する。利用集中には、元から同じ資源へ向かっていた影響もあり、道の効果と混同しない。

## 6. 道以外の候補（未実装）

|痕跡の候補|残るWorld状態|後続の問い|
|---|---|---|
|資源の採取・消費|残量、採取痕、殻や残骸|まだ取れるか、以前と変わったか|
|道具・物体の移動|置き場所、積み重なり、空間の変化|通れるか、使える物があるか|
|繰り返しの接触|表面の摩耗、へこみ、損傷|操作条件が変わったか|
|休息や滞在|草の倒れ、局所的な地面変化|他の痕跡と区別できるか|
|遮蔽物の変化|草木が倒れる、物が移される|見通しや音の伝達が変わったか|
|後続の匂い等|有限に残存・拡散・消失する痕跡|現在の取得能力で検出できるか|

表は一括実装案ではない。例えば現在の無限資源実験へ枯渇を同時導入しない。匂いには新しいsensor契約が必要。痕跡だけで原因や主体を確定しない。

## 7. 記憶・M_B・ρとの関係

世界履歴はM_Bではない。個体が痕跡を取得し、その意味や利用条件を学ぶなら、既存の経験・検査・採用の経路を別に通す。

成功経路の内部記憶と、World上の道は独立に存在し得る。道が消えても経路記憶が残る場合、本人が覚えていなくても道が残る場合を分けられる。

[動的ρ](RDL_GameAI_ρ解像度遷移設計.md)との後続接続では、粗い段階で道筋、局所高ρで足元の状態等を扱う候補がある。ただし微細な踏み跡が必ず検出できるとはしない。

[危険対処](RDL_GameAI_Moving_Hazard_Safety_Plan.md)とも組み合わせられるが、通行の多い道が現在も安全とは限らない。危険で使われなくなった道の回復等は別段階で扱う。

## 8. 有限性と出典

実装時に、World領域／セル数、状態上限、踏圧の単位、身体幅、更新順序、観測への投影、復元や保存の範囲を固定する。多個体が同時に通る場合は順序依存と二重適用を検査する。

World更新は実行結果にひも付く一回の作用として扱い、再送で再加算しない。監査ログに対象セル・更新前後・操作ID・時刻・規則版を残すが、個体には観測として取得できた状態だけを返す。

Worldを初期化する実験と継続する実験を分け、日付変更で痕跡を暗黙に消さない。一方、run間の永続保存は初版の要件にしない。

## 9. 比較候補と判定

1. 同じ固定移動列で、痕跡蓄積・非蓄積を比較する。物理作用の一回計数を先に確認。
2. 痕跡ありで観測へ投影する／しないを分ける。World変化だけと個体への情報効果を分離。
3. 単独／複数個体の通行で、集中・分岐・道筋形成を観測。
4. 後続段階で外観のみ／移動負荷も変化を比較する。
5. さらに必要なら利用継続／放棄と植生回復を比較する。

指標は通行密度、痕跡段階、形成範囲、個体が取得した回数、選択・経路変化、再訪・採取・配送、未利用域など。World真値の図は観測者専用とする。

道が必ずできる、利用が集中する、効率が上がることを成功条件にしない。痕跡はできたが誰も利用しない、袋小路への集中、危険経路の残存も結果として保存する。

## 10. 停止境界

今回はアイディアの保存のみ。草地変更、World更新、地面schema、移動負荷、学習規則、描画は変更しない。現在進める危険対処や動的ρの必須条件にも加えない。

将来の共通化対象は「作用→環境状態→有限観測→次の作用」という循環。踏圧用の係数や草の回復式を、すべての世界履歴へ共通する法則にはしない。
