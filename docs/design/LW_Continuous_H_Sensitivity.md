# 連続Hと残差別感度の有限実装

2026-10-26。FINITE PROTOTYPE。[設計構想](RDL_GameAI_Rho_Sensitivity_Experience.md)のうち、LWの親MB・経路MBの予測残差とBasicLoopへの伝達を実装する。動的ρ・感度の自動学習・MBの自動分割統合は未実装。

## 実装範囲

BasicLoopとMethodNodeのH・閾値・失敗H累計をFloat64に変更。受け取るH増分は有限・非負の実数とし、NaN/Inf/Boolを拒否する。親Hの上限32、実際の目的達成時のリセットとH解消報酬、確率選択の既存式は維持する。通常の方法の成否そのものは依然Boolで、方法Hの失敗1回につき1という更新は残る。全システムの認識不一致を連続距離に置換したわけではない。

親MBの残差は以下とする。aは操作数、uは固定上限、wは進捗窓。

- 遅延: max(0, (a-u)/w)。従来の切上げを除去。
- 停滞: 新しい場面が期待され、観測場面が2未満の場合、max(0, a/w-1)。従来の切捨てを除去。
- 消費: max(0, (消費-固定予算)/消費単位)。従来の切捨てを除去。

経路MBは従来の進捗に応じた許容操作数と消費予算を維持し、消費残差の切捨てを除去する。操作数と矛盾件数自体は離散値なので、すべての入力が連続化するわけではない。

各残差にdelay/stagnation/energy/contradictionの感度をそれぞれ乗算する。既定値は全員1.0、許容範囲は0より大きく16以下。これらは実験用の範囲で、生物学的な定数ではない。応答はゼロ点で連続な区分線形であり、滑らかな微分や非線形応答までは導入しない。停滞は従来より早く小さい値で発生し、遅延・消費は丸めの段差が減るため、必ずHが小さくなる変更ではない。

感度を適用した親残差と子経路からの累積増分の最大を採用し、既に課した量との差だけをHへ渡す。子の量を親感度で再乗算しない。同じsourceの再評価も重複加算しない。試行中の固定見積もりと、次回向けの経験更新は維持する。

## 個体別設定

統合specのconfig.mb_sensitivities、またはlw_dayのmb_sensitivitiesキーワードから個体別に設定できる。例:

    "mb_sensitivities": {
      "npc_a": {"delay": 0.5, "stagnation": 1.0},
      "npc_b": {"energy": 2.0, "contradiction": 1.5}
    }

省略した個体・要素は1.0。直接mb_map_state(actor; sensitivity=...)でも指定可能。各個体の設定と直近の残差記録に感度を残す。現段階は固定感度であり、身体状態による変調や経験による感度更新は行わない。ρは独立で、この変更では固定profileを変えない。
