# 疲労容量を超えても近い家へ戻る見積もり：局所試験

前回の[容量版](LW_Activity_Capacity_Local_20261127.md)は、帰路の予測疲労比率が1以上だと
現地休息に固定していた。今回は別の局所アダプターreturn_rest_local.jlを追加し、
超過は連続費用、身体能力0は実行不能と分けた。旧試験は比較用に保持。
どちらも通常LWへは未接続。実際の身体の構造体や保存形式を変更しない。

## 暫定設定

初期wear=.35、疲労=.69、容量=.65（比率約1.062）。栄養・修復材料は十分に固定。
直帰と、現地で0.5時間休んでから帰る案を、共通の4時間の評価枠で比較する。
帰宅後は残り時間を睡眠修復として扱う。睡眠可能時刻・安全性の実認識は未接続。
追加作業を続ける候補は今回含めない（帰還段階の比較）。

歩行中の負担=疲労比率²＋4×max(0,比率−1)²＋wear²を、0.05時間刻みの台形則で積算。
自宅価値=.8/時、現地休息費用=.2/時、帰宅までの遅延費用=.25/時。
初期負担からの回復量の価値係数=1。
自分で追加した消耗まで回復報酬として水増しせず、元の疲労＋wearからの減少を評価。
これらは実験用の固定係数であり、学習された安全性・人体の実測値とは扱わない。
将来は場所MB・行程MBの見込みを入力する。

候補価値=自宅滞在時間の価値＋初期負担の回復見込み−歩行負担−現地滞在費用−到着遅延費用。
容量超過だけで候補を除外しない。経路途中で身体能力が0になる案は除外する。
両案とも実行不能なら現地休息を残す。休息後に再判定する通常ループは未接続。
損傷1による移動不能は、近い家でも直帰にしない。

## 結果

同じ128シード、既存BasicLoopの確率選択。

| 帰路の見積もり | 直接帰宅の確率 | 実際の選択（直帰／先に休息） |
|---|---:|---:|
| 3分 | 64.6% | 84／44 |
| 15分 | 63.1% | 82／46 |
| 30分 | 59.8% | 79／49 |
| 1時間 | 49.0% | 70／58 |
| 2時間 | 16.8% | 26／102 |

1時間条件のサンプルで直帰が多数なのは、確率選択の揺らぎを含む。
近距離では負担の追加より早い帰宅の見込みが勝ち、遠距離では先に疲労を下げる利点が勝った。
家のIDや距離閾値で直帰を強制していない。
検査21項目PASS。容量超過でも直帰可能、予測時の元状態保持、能力0の実行不能、
安全価値を外したときの評価変化、距離による選択確率の変化を確認。

限界: 距離は入力された所要時間で代用し、能力低下による移動時間延長や地形は未接続。
容量超過に比例する追加の実組織損傷も今回追加していない（予測費用のみ）。
通常LWの帰宅頻度・処理時間の改善を示す試験ではない。
