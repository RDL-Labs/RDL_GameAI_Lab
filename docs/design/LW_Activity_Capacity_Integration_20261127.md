# 活動消耗・帰宅見積もりの通常LW接続

## 条件と適用

`scene.activity_capacity`（既定false）を有効にすると、人の身体に遅い活動消耗と疲労を保持する。個人宅を必要とする。旧短期strainによる制限は併用せず、新モデルの疲労へ置換する。栄養収支は既存の三栄養素モデルを継続する。

身体の更新は実行後の消化更新で一度だけ行う。移動予測は実身体を更新しない。活動消耗は移動能力と疲労容量を下げ、休息・睡眠で回復する。現状では修復材料を十分と仮定しており、修復のための栄養の追加引落しは未接続。

## 暫定固定の判断

`configured_paths/activity_capacity_lw.jl` に隔離。将来は作業MBの見込みへ置換する。

- 追加作業を1生活時間、現地休息を0.5生活時間と仮定する。
- 本人の拠点観測距離、または既存の日次帰還見積もりから帰路時間を得る。
- 予測疲労比が既存onset未満なら64シミュレーション秒後まで再判定しない。
- 活動継続・帰宅・現地休息後帰宅を、共通の予測期間における負担と回復で比較する。容量超過だけで帰宅を禁止しない。
- 継続の効用は暫定的に1＋身体要求値。継続選択は1生活時間後に再判定する。
- 帰宅選択は到着まで保持する。食事・援助・研修など既存の上位処理は残す。自宅休息候補へ渡す要求値は0として、選んだ身体休息を許す。既存の割込み・食事判定は残る。
- 身体休息中のmodeは疲労と消耗がともに0になると解除する。これは暫定の回復判定で、MBの達成やH解放を表さない。
- 専用選択ループを持ち、進行中の帰還MB試行を上書きしない。この選択自体は学習済み行動として扱わない。

記録は `mb_map.*.activity_capacity_plan`、日末physicalの同名項目、身体のactivity_capacity。判断履歴は直近128件、判断回数は累積。身体の構造が変わるため、本試験は初期状態から新しい凍結ソースで実行する。
