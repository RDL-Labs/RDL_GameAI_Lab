# 個人宅への帰宅・待機・睡眠（暫定設定）

## 目的と固定の範囲

`scene.personal_house_idle=true`（通常入力の省略時はfalse）で、用事のない拠点休息を
自宅へ移す。`personal_houses=true`が必要。旧`post_return_idle`との併用は不可。
本人の家の座標を初期知識として使う暫定固定で、学習から生まれた帰宅行動ではない。
実装は`configured_paths/personal_house_idle.jl`へ隔離。将来は用事の見込み・帰宅MB・
注意配分へ置換する。家の入居・認知停止を通常の親MB成功報酬にしない。

## 動作

- 既存の安全、教育、食事・加工、援助、取引の選択を先に行う。
  拠点内で帰還／備蓄で外出不要／夜の休息に相当し、荷物がなく、
  未決の返答・取引・援助配送がなく、身体要求が許容内なら帰宅へ。
- 日中の取引有効時は、既存の取引評価で「今回はしない」と判断済みであることを要求。
  評価のクールダウンや未観測を「用事なし」と読み替えない。夜は通常仕様で取引を
  開始しないため、その評価待ちは要求しない。
- 自宅への移動中は通常の観測と移動・障害物処理を続ける。家へ瞬間移動しない。
  近距離の停止半径だけ家の広さに合わせる。到着後にだけ高レベル認知を停止する。
- 待機は睡眠と別。待機中も休息の身体更新、消化・代謝、世界時間は進む。
  夜になれば通常認知へ戻り、家でのrestから既存睡眠ゲートと内部整理へ接続する。
  本設定ON時の睡眠ゲート入口は共有拠点中心ではなく本人の家。
- 聞こえた未応答メッセージ、名前の呼びかけ、未決処理、身体要求の増加、近接危険、
  翌日で再開する。単に近くを別の人が歩いただけでは再開しない。
  危険は既存hazard_modeの発生源に対する近接チェックを暫定ショートカットとして使う。
  野生動物を自動的に危険認定する機能はない。
- 睡眠中の身体要求による再開は日中より高い閾値。睡眠中も通知・未決処理で解除可能。
  中央拠点の取引接触・倉庫アクセス判定は変えない。家の入口への訪問・交渉の移動は未実装。

## 数値と記録

`HOUSE_IDLE_RULES`：身体要求上限0.35、待機開始からの増加0.10で再開、
睡眠時要求0.80以上で再開、到着半径は家の半径×0.8、遷移記録64件。
暫定の省コスト設定であり、生理学的閾値ではない。通常移動の歩幅・危険センサー距離は
既存値を使用する。本人の`mb_map.configured_house`と日別physical.house_attentionに
移動・待機・睡眠tick、進入回数、再開理由、直近遷移を保存する。
