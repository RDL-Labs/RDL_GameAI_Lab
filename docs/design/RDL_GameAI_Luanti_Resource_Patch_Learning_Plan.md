# Luanti — 有限資源群の枯渇・再探索・特徴関係の長期学習

**状態: DESIGN ONLY / DRAFT v0.1。2026-09-27。実装・実機受入は未実施。**

基準はGameAI `b7499983`、[L13W契約](../experiment-contracts/LUANTI_L13W_multi_food_exploration_contract.md)と
[Evidence](../experiment-evidence/LUANTI_L13W_multi_food_exploration_evidence.md)。
本書は[探索本線](RDL_GameAI_Luanti_Exploration_Plan.md#learned-exploration-mainline)の次工程案。
既存L13S〜Wの停止条件、保存記録、受入済み機能は変更しない。

## 1. 問いと初期知識

**食べられる実の手掛かりだけを教わった個体が、複数の場所で採集し、資源が尽きると探索を再開し、
経験から得た木の外観と取得結果の関係を、まだ訪れていない場所の選択へ使えるか。**
後半の探索効率向上は検査する仮説であり、必ず改善するよう方策や配置を補正しない。

神の像は拠点でドングリの見本を提示し、「これは食料になる」という有限な情報を伝える。
教わる対象は実の観測特徴と用途。どの木から落ちるか、木の特徴、資源位置、残量、正解経路は伝えない。
必要な加工法は初期知識として明示してよい。教示だけで可食性を自力発見したとは数えない。
初版の到達点は実物の取得までとし、加工・摂食・栄養回復・貯蔵成功は別の作用契約ができるまで主張しない。

初期設定、像からの教示、本人の実験結果は別の出典として保存する。
神の像のstatementをWorld Truthや行動命令にせず、[既存の情報源の境界](RDL_GameAI_暫定プレイヤー役割_しゃべる神の像.md)を維持する。
実物の提示と観測上の照合・用途への有限接続は新しい実装事項であり、自由会話の理解が実装済みとはしない。

## 2. Worldには規則を置き、個体には教えない

- 実験期間は「実が採れる秋」に固定し、昼間・sensor profileも固定する。季節変化、豊凶、自然再生は後続。
- 木には既存の有限観測で取得可能な粗い外観差を置く。描画で違って見えるだけでなく、遮蔽・距離・視野を通した
  受理済みframeへ違いが届くことを先に検査する。樹種名、食用樹フラグ、World ID、全配置図は渡さない。
- 同じ特徴の木を複数置き、その周辺でドングリを得られやすい配置にする。別特徴の木、同特徴でも実のない木も置く。
  各外観と資源の対応、地点数・間隔・総資源量・seedは実行前に固定する。結果を見て移動・追加しない。
- 資源のある一地点は初期量2単位、実pickup一回につき1単位だけ減る。**同じ場所での成功採集は最大2回**。
  訪問・発見・失敗したpickup・再送では減らさない。資源群全体の上限であり、実のentityを変えて上限を復活させない。
- 2回目の取得後も木とその外観は残す。空の木を自動消去して、個体が枯渇を認識する問題を消さない。

初期案は採集可能な資源群を少なくとも6地点とし、形成・独立検査・未訪問場所への適用を別々に観察する余地を作る。
無資源の木を含めた総数、外観別の配置比率、到達可能性、観測に必要な予算は実装契約で確定する。
これは生態系の再現ではなく、空間的な関係を学べる有限な試験Worldである。

## 3. 2回の上限はWorldの条件であり、探索先を切り替える規則ではない

個体には「2回採ったら次へ行け」や隠れた残量を渡さない。自身の成功取得は知ってよいが、
初期量2を知っているとはしない。現在観測と実作用結果から、取得可能なものが残っているかを扱う。

```text
実を観測 → 現在の実観測を使って接近 → 実pickup
    ↓
同じ周辺で再観測・採集（World上は成功最大2回）
    ↓
取得を続ける根拠がない／有限に調べても未発見
    ↓
同じ食材取得Goalのもとで、新たな探索候補を評価
    ↓
採用済みM_Bが使えるなら、観測した別の木の特徴から周辺探索を予測
使えない候補はunknownのまま、有限試行・再観測・保留
```

再探索の起動と、探索先を何にするかは別の責務。取得Goalと有限な身体・観測・再計画機構は与えるが、
木の色別の価値、巡回順、一定回数後の別地点への移動を初期方策や初期M_Bへ埋め込まない。
観測済みの実への接近を与える場合は有限な視覚運動制御と明示し、木と資源の関係学習と分けて評価する。

全体が空になったというWorldの真値を、本人の枯渇認識・次の行先・終了判断へ戻さない。
取得不可、現在の完全な局所未発見、遮蔽・未取得、場所照合の不確かさ、時間切れは別の結果とする。
同じ木から採れなくなっても、過去の取得記録や「この特徴の周辺で得た」という関係を直ちに消さない。
場所の現在在庫と、外観に条件付けた採集可能性を別の予測対象として扱う。

## 4. 長期系列と引継ぎ

**新系列では3回発見で終了せず、最大30探索期間まで継続する。**
予算案は1期間16秒・通常取得250ms・最大64枠/操作許可、合計480秒・1920枠/操作許可。
ここで期間は有限な集計・記憶処理の区切りであり、季節の日数、睡眠による身体回復、自力帰還を意味しない。

期間をまたいで地形、資源残量、実物の取得状態、身体位置・向き、本人のExperience・M_Bを引き継ぐ。
同じWorld時計を使い、記憶処理や通信待ち中の時間も記録する。通常取得は同一枠に一回だけ。
期間境界では新しい身体許可の発行を止め、処理中の作用と受付を閉じて学習材料を凍結する。
境界を越えて旧許可を新しいモデルの作用へ流用しない。配送待ち中の取得を含む容量と超過時の停止は別途固定する。

日ごとの資源復元・拠点への瞬間移動・向きの初期化は行わない。
次期間開始時に実が見えていても不正とはしない。再発見や成功pickupで期間全体を早期終了させない。
運搬容量が尽きた場合の有限な取り扱いは実装契約で定め、期間境界で所持品を黙って消去しない。

正常な終了は規定の時間／容量上限。全資源を取得済みでも、本人が未確認の場所を調べることは許容する。
機構エラーは通常の未達と分ける。再起動をまたぐ永続化は初版の必要条件にせず、同一実行内の状態保持を先に通す。

## 5. 場所の再訪と特徴からの帰納を分ける

学習経路は本人の観測・実測作用・取得結果→Experience→Sleepでの有限な候補形成→独立検査→T1/M_B→選択とする。
対象の問いは「観測した外観条件の木の周辺を、指定した取得範囲と操作予算で調べたときに実を得られるか」。
木が実を生産した原因や普遍的な樹種同定まで結論にしない。

場所ごとの再訪記憶と、複数場所にまたがる外観関係を別に保持する。
既知の一地点へ早く着いたことだけでは、未訪問の木への一般化を主張しない。
同じ外観には複数の木が対応し得る。frame内特徴IDを恒久的な木・資源群IDにしない。

成功だけでなく、完全な範囲を調べた未発見、観測不足、接近不能、照合不確かも出典とともに残す。
「取れやすい」の分母は比較可能な有限探索機会とし、同じ実を見たframe数や通信再送を機会数にしない。
同じ場所の2個は実収量2だが、独立な2地点の裏付けではない。
期間番号・経験の別名・Sleep cycleだけで支持を増やさず、同地点の依存性を保持する。
本人が場所対応を判断できない場合は不確かさを残し、独立性を都合よく補完しない。

形成用の材料と検査用の材料・eventを分離し、特徴の一般化検査には形成に使わなかった場所を要求する。
実験者はWorldの地点IDで漏洩・重複や未訪問性を監査できるが、そのIDや場所の答えを個体へ渡さない。
形成件数、検査件数、反例・不足の扱い、候補の特徴語彙と上限を専用契約にする。
L13Sの一経路1支持＋1検査を、そのまま一般化の十分な証拠へ読み替えない。

新しい場所の経験を後続の有限cycleで再検査できるようにし、各cycleの更新前M_Bと評価材料を凍結する。
履歴・候補・検査・採用版の容量は明示し、満杯時に黙って材料を切らない。
再送・並行受付で二重更新せず、失敗時には以前の公開モデルを維持する。
採集失敗数、在庫減少、探索費用そのものをCore E/H/θとせず、[意味参照](../semantic-reference/RDL_Core_T0_T1_reference.md)の比較条件を定める。

## 6. 「後半に効率が上がった」の測り方

最初から期間1〜10、11〜20、21〜30に区切り、同じ窓で全系列を報告する。
発見数だけでなく実取得量と投入費用を測る。取得0や打切りも残し、成功した系列だけの平均にしない。

| 指標 | 読み方 |
|---|---|
| 新しい資源群を初めて発見／取得するまでの時間・距離・操作数 | 既知地点の2回目取得と分ける。未達はnullと消費予算を併記 |
| 次の実取得までに調べた木・有限探索機会数 | 実を見ただけ、木へ近づいただけを収穫としない |
| 一定予算あたりの取得量、取得一単位あたりの費用 | 取得0の費用比はnull。未達側を低費用の成功としない |
| 採集できなくなった場所への再試行と離脱までの費用 | 本人の根拠とWorldの在庫真値を別々に保存 |
| 未訪問の同特徴の木に対する選択、予測と実結果 | 採用model_ref・候補・材料・unknownを追う |
| 枯渇済み量、残資源量・配置・到達難度 | 実験者側だけで監査。後半ほど資源が減る交絡を示す |

前半と後半の単純比較だけでは学習効果を確定しない。次の対照を別に置く。

1. 同じ事前登録配置・seed・見本教示・身体能力・予算で、記録/検査はするが学習採用を無効にした系列と比較する。
   採用の有無を除く選択規則は同じ。行動が分かれた後の資源残量・経験の違いも記録する。
2. 採用直後の同一履歴・現在観測・候補・抽選条件を固定してモデル有効/無効の選択を比較し、
   有限のWorld分岐対照で実作用まで確認する。一般化の対象は本人がまだ採集していない木とする。
3. 実の位置・量と木の位置を維持して外観との対応を入れ替える対照を事前登録する。
   描画とセンサーの両方を変更し、経路の暗記と特徴の利用を区別する。

偶然の近道、最後に残った資源の遠さ、明示検査Probeの案内、同じ場所の再訪効果を分ける。
配置・seedは事前に複数固定し、都合のよい成功系列だけを選ばない。
改善がない、誤一般化した、枯渇地点に固執したという結果も保存する。

## 7. 実装順と受入境界

現行L13Wは毎日資源・身体を復元し、3回発見で終了する。系列あたり一候補・一検査・一採用であり、
遠くで見えたFoodへ新たに接近する制御も追加していない。設定値の変更だけで本計画が成立するとはしない。

| 段階 | 必要な追加 | そこで検査すること |
|---|---|---|
| 資源と取得 | 一地点2単位、対象別の一回減算、見えた実への有限接近、継続するWorldと身体 | 取得・残量・所持品が一致し、再送で3個目を得ない。期間をまたいで復元されない |
| 教示と観測 | 実の見本と出典、木の粗い外観、現在観測での対応 | 教示に木・場所・残量が入らず、外観は実センサー由来。取得不足を空としない |
| 再探索と更新 | 有限な再計画、複数cycleの候補/独立検査/T1/M_B | 2回カウンタで巡回せず、現在情報と採用関係から候補を評価する |
| 長期比較 | 上記を統合した30期間、未訪問場所と採用対照、資源audit | 後半の効率と限界を全系列で報告し、選択差の出典を追う |

実装前に地点配置、特徴語彙、局所取得/接近、所持容量、継続clockと期間境界、学習件数・比較規則・
反例/DEFER、保存容量、必要回帰を契約化する。現行の本線禁止事項を守り、World真値で行先を作らない。
固定された正当な入力による陽性試験で候補形成・独立検査・採用・未知地点の選択まで検査し、
自然探索で材料が不足した結果とは分ける。機構が未接続のまま効率不変を学習結果にしない。

**停止境界:** 単独個体、秋・昼間固定、有限資源、明示した食材取得Goal。
加工の発明、実際の調理・長期保存、季節予測、飢餓・死亡、一般帰還、複数個体の競争、
資源再生、神の像との自由会話は今回の長期探索の必要条件にしない。
既存Observation v1を再開発せず、使う観測能力と追加した有限契約だけを明示する。
