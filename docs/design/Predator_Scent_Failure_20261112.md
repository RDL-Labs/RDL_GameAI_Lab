# 弱い・古い匂いの不成果評価（2026-11-12）

## 変更と暫定設定
既存の強い匂い限定の不成果抑制を、弱い体臭・古い糞にも適用する。
configured_prey_scent_steer! に隔離。cautious=true かつ mind を渡す場合に既定ON。
`mind.estimates["scent_all_strengths"]=0` で従来へ戻る。
同じ匂い区画を手掛かりにSEARCHした時間を累積し、120tick以上でその区画を
600tick匂い候補から除外する。既存定数を再利用する暫定固定判断であり、
滑らかな確率的重み学習ではない。到達直後に匂いを再確認するまでの時間も含む。
強い匂いで慎重に移動する条件は従来のまま。実際の獲物位置を参照しない。

視認・追跡だけでは不成果を消さない。捕獲が増えた時、直近に従った匂い区画の
蓄積と除外を解除する。これは暫定的な成果帰属であり、その匂いが捕獲原因だった
ことを保証しない。区画ごとの蓄積は既存mind.estimates、除外期限は既存cooldownへ保存。
将来は経験から学ぶ成果見積もりと関係の重みに置き換える。
歴史的比較スクリプトは明示的にOFFとして旧条件を保持した。
