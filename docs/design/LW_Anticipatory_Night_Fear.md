# 日没予測から生じる恐怖H（2026-10-26）

`night_fear: "on"`（rock_gate runnerでは`--night-fear on`）で有効。既定off。MB/BasicLoopが必要。既存の帰還Hと別の連続値として保持し、帰還が一度成立しただけではゼロへ戻さない。完全な安全MB階層の実装ではなく、夜間露出への初期の予測圧を既存home目的へ接続する段階。

## 帰還見積もり

観測できるhomeの距離、観測済みの有向帰還経路、未確認の探索の順で親MBの所要操作数見積もりを使う。経験がある場合は既存の学習値、なければ初期値。推定は最大64操作秒キャッシュし、拠点を確認した時点で破棄する。キャッシュ期間中の距離・地図変更は次回更新まで反映されない場合がある。

日没はclock.phase_boundaries_us[3]、本試験では日内11520秒。帰還時間のupper_actionsに、既知の場合は1日の5%、未確認の場合は25%の余裕を加える。未確認を所要時間0にはしない。この余裕は実験用の事前仮定で、到着保証や校正済み確率区間ではない。時間はシミュレーションの操作秒。

`夜間露出残差 = max(0, (帰還時間 + 余裕 − 日没までの時間) / (1日の12.5%))`

日没後は残り時間が負となり、拠点外にいる予測圧が強まる。近くて帰路が分かる場合は遅く、時間がかかる・帰路が未確認の場合は早く残差が現れる。拠点内の夜間露出残差は0。

## Hの更新

視認した危険にも0〜2の圧を置き、夜間残差との最大値を目標Hとする。上限8。Hは上昇時30秒・低下時120秒の時定数で目標へ近づく。固定残差を毎秒加算する方式ではなく、同じ目標ならそこへ収束する。記録上のincrement/reliefは新旧Hの正負差であり、既存の親Hへ加算しない。

拠点に入っても恐怖は即座に消えない。危険が見えていれば圧が残る。危険観測が欠ける/不完全な状態では、到着だけを根拠にHを減らさない。空の完全観測も世界全体の安全証明ではなく、その観測範囲での暫定的な安心として扱う。夜明けにもHは滑らかに低下する。今回の恐怖係数は全個体共通で、既存4種類の残差感度とは別設定。

## 選択への接続

恐怖からhomeを追加選択する確率は`1-exp(-1.5H)`。固定帰還を強制せず、既存の帰還要求は保持する。設定された身体維持のreplenishing中には、この追加要求でfoodを上書きしない。安全・摂食等の優先行動は維持。初日の設定観察期間にはHを更新するだけで、追加の目的選択は適用しない。

home候補を作るときの起床時MB探索・睡眠MB候補検索に`max(親H, 恐怖H)`を渡し、帰路未確認時に候補を広げる。H自体や既存経路の報酬・成否は上書きしない。恐怖が弱い間、既存の候補生成制約をすべて撤去するわけではない。全候補は観測と記憶由来で、世界の拠点座標や架空の逆方向辺を追加しない。

従来の定時帰還・夜間休息は今回残るため、近い拠点への既定帰還時刻より早くならないケースもある。体力・空腹・危険との完全な共通目的選択や、夜への恐怖そのものの経験更新は未実装。H、見積もり、残差、日没前の残差評価数、要求数をmb_map.night_fearに保存する。
