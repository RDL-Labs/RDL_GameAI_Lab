# 初期能力と経験学習の境界

状態: 方位入力＋既存再見回しconsumerを有限実装。広い初期能力・方向保持は設計案。
[初版契約](../experiment-contracts/LW_initial_orientation_contract.md) / [Evidence](../experiment-evidence/LW_initial_orientation_evidence.md)。
以下の設計照合基準は `68e595e`。
本書は探索実験へ初期に与えてよい能力の設計方針。実装範囲は初版契約を正本とし、目印方向の保持・帰還利用は未実装。

## 目的

移動能力や方位感覚をすべてゼロから学ばせることを、探索・経験学習の前提条件にしない。
初期能力は個体が経験を得るための足場として明示する。食料や拠点の場所、通れる経路、目印と成果の関係は経験側に残す。
ここでの初期設定は実験上の仮定であり、人間の子供や動物の生得能力を実証したものではない。

## 能力・知識・実験者情報の区分

| 区分 | 初期に与える候補 | 経験から得る内容／制限 |
|---|---|---|
| 身体操作 | 有限な移動・旋回・待機と実行結果の取得 | 指令どおり動いたとは仮定しない |
| 方位感覚 | 昼の太陽・影相当、夜の星相当の粗い方位基準を読み取る能力 | 拠点や資源への方向は含まない |
| 短期方向保持 | 観測した目印の方向を、本人の旋回結果と結び付けて有限保持する能力 | 対象同一性や現在位置は保証しない。誤差・失効を扱う |
| 課題設定・教示 | 食料確保や帰還の目的、何を食料として試すか等を明示的に設定できる | 教示は学習成果や支持Experienceに数えない |
| 経験学習 | 記録・検査・採用を行う仕組み | 目印と食料、採取条件、経路、失敗条件などの内容は事前投入しない |
| 実験者情報 | World生成・真値・到着監査 | 全体地図、未観測資源、拠点の正確な座標や常時の帰還ベクトルは個体へ渡さない |

この表は能力の分類である。既存実装が全項目を満たすという棚卸しではない。

## 初版候補：天体由来の相対方位感覚

太陽・影・星をWorldへ描画・配置する代わりに、感覚adapterがシミュレーション時刻と取得時の身体姿勢から、天体の手掛かりに相当する粗い相対方位を計算する。
時刻だけで身体に対する方向は決まらない。World側の計算に用いた正確な姿勢を、そのまま個体入力にはしない。

初期能力には、その手掛かりを昼夜共通の方位基準へ読み替えられることを含める。
初版の出力案は「共通基準方向が身体から見てどの角域にあるか」であり、太陽の生の方位そのものとは区別する。
昼夜で方位基準が切り替わって飛ぶことは避け、手掛かりの由来を別に残す。
太陽と影は同じ由来なので独立した二票として数えない。月は初版に含めない。

入力記録には少なくとも次を残す。フィールド名・角度幅・取得周期は実装契約で固定する。

- 個体、run、取得時刻、取得時姿勢参照。
- 共通方位基準の参照と、身体相対の角度区間。
- 昼／夜の手掛かり種別、取得可否、簡略化した環境条件。
- 分解能・誤差の意味、生成規則版。乱数を使う場合は再現seed。

粗い区間を毎回独立に揺らし、平均すると実質的に正確な方位へ戻るような入力には注意する。
量子化と誤差を区別し、反復取得でどこまで精度を上げられるかも契約化する。
配送遅延・再送で取得時刻や方向を書き換えない。

初回比較は昼夜とも手掛かりを取得できる簡略条件としてよい。曇天・樹冠・空の遮蔽は未モデル化と明記する。
これは空が実際に見えたというセンサー検証ではない。夜の方位取得を許すことは、夜間移動を許すこととは別である。

## 方位保持が保証しないこと

「基準方向が右側」「以前の塔はこの方位に見えた」と分かっても、現在地から塔への正しい方向が分かるとは限らない。
その場の旋回は方向基準を対応づけられるが、並進すると目印への方位そのものが変わる。
過去の方向を現在の帰還ベクトルとして使い続けず、移動・時間経過に応じた不確かさや失効、再観測による照合を別契約にする。

方位感覚は未観測の地面を通行可能にしない。`partial` な地面観測を補完せず、再観測や行動選択の権限を飛び越えない。
迷子、似た目印の誤対応、帰還未達は許容する。

## 既存経路との接続と停止境界

[探索・帰還・睡眠計画](RDL_GameAI_Exploration_Return_Sleep_Plan.md)の目印基準の帰還を維持する。
既存の観測、身体結果、M_B、移動場、steeringと、初期方位感覚の寄与を分離して記録する。
初期能力そのものをExperienceや採用済みM_Bとして登録しない。方位と目印の関係を学習・採用する場合は、その本人記録と検査を別に必要とする。

次の実装は、まず方位感覚adapterと既存探索への有限なconsumerを別契約にする。
夜間行動、一般的な経路積分、全体地図、天文学習、正確な自己位置推定は本書だけでは追加しない。

## 比較計画（未実施）

1. 同じWorld seed・個体数・資源・閾値・左右傾向で、方位入力の有無を比較する。
2. 回転前後、角度の折返し、昼夜境界、遅延再送で、取得基準と粗さが維持されるかを検査する。
3. 未取得、期限切れ、並進後の旧目印方向を、現在の確かな方向として扱わないことを検査する。
4. 方位入力だけでは未観測資源・拠点座標・通行可能性が得られないことを確認する。
5. 経路、再訪、帰還、採取、待機理由、学習記録を保存する。改善や帰還成功を必須結果にしない。

既存の seed `20260930` の停止には、目印不足に加え地面取得不完了も含まれる。
方位感覚の追加だけで停止全体を解消したとは扱わず、寄与が適用された判断と適用されなかった判断を分ける。
