# 木・岩・草群落の有限な世界特徴

2026-10-26。FINITE PROTOTYPE。Juliaのみ。世界側の情報を増やす最初の実装で、動的ρや人間AIの新しい抽象化学習は含めない。

## 世界表現

| 対象 | 固定した個体差 | 状態・作用 |
| --- | --- | --- |
| 木 | 茶/緑、幹半径、高さ | 近傍の既存食料サイトを実の在庫として参照 |
| 岩 | 灰/黄土、半径、高さ | 既存の接触・見通し判定に同じ寸法を渡す |
| 草 | 色区分、高さ、基準密度、群落区画 | 食料残量と遮蔽が同じ採食・回復状態から変わる |

WorldFeatures.enrich_sceneは既存配置へseed付きの個体差を付ける。形状を毎観測で抽選し直さない。既存の茶/緑の障害を木、灰を岩として移行し、塔や光源などその他の属性は保持する。これは既存シーンを変換するためのルールで、AIが色から正解種別を受け取る機構ではない。幹/岩の半径は既存の70〜100%、高さは80〜120%とし、既存スポーンの空間を塞がない。初版は球/円柱近似で、枝・葉・岩の凹凸は持たない。

木の実は1個ずつのオブジェクトではなく既存の食料サイトのstock。初期量を既存の50〜150%から整数化する。world_idとfood_indexは世界側の追跡・関連づけ用で、観測の正解IDとして渡さない。LWの採取・補充は既存のサイト在庫を更新する。樹冠内の実の描画や、実の量を視覚で厳密に読む専用センサーは今回追加しない。複数の木と近傍サイトの対応は簡易的な距離3以内の関連付けであり、植物の生理モデルではない。

## 草は管理区画と認識を分ける

既存の2mセルを食料状態の小区画として維持し、最大4×4セル（8m四方）へ共通の色・高さ・密度を割り当てる。水・岩・歩行不可セルには草を置かない。穴や川で分かれた領域をひとつの連結群落と保証しない。ここでいう群落IDは更新・保持のための区画であり、個体が認識したまとまりではない。

草の色は数値ID1=green、2=yellow_green、3=brown_green。高さは0.15〜1.0、基準密度は0.4〜1.0の有限パラメータ。容量にも基準密度を反映し、採食は従来どおり同時比例配分、回復は遅延更新の線形補充を使う。一本ごとの状態は作らない。

遮蔽は概念上 density × remaining/capacity × min(1,height/body_height) を0〜1へ制限する。食べると実効密度と遮蔽が低下し、回復すると戻る。高さ自体は固定。捕食者から見た兎は体高0.4、兎から見た捕食者は0.9という試験用定数を使用する。生物学的な校正値ではない。対象位置の草による検出距離の補正であり、視線全経路の草を積分するモデルや完全な不可視判定ではない。

## 観測と既存システムへの接続

生態系の局所草観測へ、色・区画幅・高さ・実効密度・食料量・遮蔽の値スナップショットを追加。observe_objectsは範囲と障害遮蔽を通った色ID・幅・高さ・相対距離/方位を返す。world_id、群落ID、真の種別、隠れた食料在庫は返さない。物体の色ID0は共通表にない色。

兎の採食判断は既存の食料量を使い、捕食者・動態視覚・方向視覚の検出距離は草の高さ/密度を使う。兎が将来の安全性を学習して隠れ場所を選ぶ機構は未追加。LWでは木・岩の形状と色、実の在庫が既存の観測・物理・採取に接続される。草の食料/遮蔽は生態系側の実装であり、LWの人間AIの草遮蔽・描画への統合は未実装。

## 有効化と検証

既存比較条件は既定のまま。LWはnative CLIの --layout rich-riparian、またはrich_landscape_scene(seed)。生態系はbuild/simulate/trialのrich=true。個体差は乱数系列を分離し、元の実験用生成器を置換しない。
