# 疲労休息と継続の見積もり比較

2026-11-11。人間LWの通常MB移動で、strain >= 0.8の固定休息と
継続移動側の同じ禁止条件を、共通の `fatigue_navigation_continue!` に置換した。
`scene.fatigue_forecast` は既定true。falseは旧停止条件で比較する。
非MB経路・研修・拠点作業・夜間睡眠・帰還後認知停止は今回の変更対象外。

## 評価

- 観測目標の距離区分から概算到着時間を得る。帰還先未観測なら既存の
  日次MBの帰還所要時間学習を使う。未経験は128秒の初期仮説。隠れた座標は読まない。
- 身体モデルの歩行1操作から積載を含む疲労・消耗を予測し、代謝も加える。
  現状の外挿は平地歩行であり、迂回・地面抵抗・走行を精密に予測しない。
- 今休む回復と、到着までの追加疲労・資源不足リスクを比べる。
  帰還では本人のembedded_rest.place_valueを、遅延で割り引いた休息見込みに使う。
  食料到着後の疲労回復は仮定しない。
- 同じ `method_distribution` のHによる分布調整を使って継続/休息を選ぶ。
  この選択を帰還成功として報酬化せず、独立した未達Hを加算しない。
- 0.8は即時停止ではなく評価を始める認知上の帯。未満では追加乱数を使わない。
  継続選択は同じ目標について最大64秒または見積時間まで保持する。
  身体限界到達では保持を解除。休息の実行・集中・再確認は既存処理を使う。

初期係数は `FATIGUE_FORECAST_RULES` に集約した。係数そのものを学習済みと扱わない。
予測誤差の専用学習や専用Hは新設せず、既存の親・経路試行を維持する。
長期の疲労・帰還・計算費用の改善は未確認。
