# 腐敗見込みからの売り出し・局所実験（2026-11-27）

通常LW未接続。`camp_surplus_local.jl` は検査側だけがincludeする暫定設定経路。
本人の記憶にある食べられる所有食品について、1個手放す場合の既存trade_compound_gradientを計算する。
廃棄見込みの軽減があり、材料損失・不足・費用を含む合成評価が正なら売却候補。
未知の対価や相手の隠れた在庫は予測に加えない。数量・期限は既存CAMP_TRADE_CALL_RULESを共用。

局所実験は候補を明示採用し、既知で欲しい買い手の返答を通常会合へ接続する。
買い手が対価を提示し、売り手は通常の評価/応答で判断する。返答・提示では所有権を動かさない。
現時点は売却と摂食・加工・維持との通常の選択競合、自律的な発話、時間経過中の可聴性/期限処理を実験していない。
可聴範囲内・覚醒・作業なしをfixtureの前提とし、提示1個・先着相手を暫定固定として扱う。
将来は参加費用と関係MBに基づく候補選択/注意へ置換する。

## 結果

`experiments/social_relationships/camp_surplus_local_checks.jl`: 316 PASS（既存110、新規206）。
売り手は焼き魚8個、買い手は果実8個。日末まで60秒の本人予測を用いた16シード。
候補評価は材料損失 -0.2001、廃棄軽減 +1.0、費用 -0.002、合計 +0.7979。
使い切れる対照（同じ予測の消費容量100）では売却候補なし。
未知の食品を提示された相手、既知だが相手も魚を余らせる見込みの条件では返答/会合なし。

- 16条件で提示15、受渡成立15、提示見送り1。
- 対価ありの交換6、無償提供9。内部status=exchangedを全件有償交換とは数えない。
- 返答・提示時の在庫不変、非公開倉庫、成立時の食品総数16の保存を確認。

当初検査は双方が食品を得ると想定し9件失敗した。実際は無償の魚提供だったため、
強制的に対価を要求する変更はせず、対価あり/なしを分離して検査・集計した。
「腐らせるより渡す」が既存の廃棄軽減によって成立し得る。現行係数での結果であり望ましい比率の保証ではない。
全体生活条件・長期的な売買頻度は未検証。通常LWの挙動は変更していない。
