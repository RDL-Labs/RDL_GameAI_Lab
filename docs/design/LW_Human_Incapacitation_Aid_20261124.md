# 人間の行動不能と援助の足切り撤去

2026-11-24。開始HEAD `0c1f855`。ユーザー指示：人間の消耗は行動不能として扱い、援助の固定条件を外す。

## 身体

人間のMacroBridgeだけ `starvation_fatal=false`。組織下限50ではaliveをfalseにせず、
mobility=0で行動・通常認知を止める。代謝・消化は継続し、賄えない消費はunmetへ記録する。
食料から実際に糖・材料を得て組織が下限を上回れば次tickから活動可能。身体値の直接補填はない。
この暫定世界では栄養欠乏だけで行動不能者が後から死亡する期限は設けない。
回復直後のmobilityは小さい。完全回復を保証する機構ではない。

共通MacroParametersの既定starvation_fatal=trueは維持。野生動物・単独身体実験の死亡規則は変更しない。
保存済みalive=falseを自動でtrueにしない。C死亡後の旧チェックポイントから再開しても蘇生はしない。
新条件の評価は死亡前の状態、または初期状態から行う。既存凍結実験は変更していない。
bodydictにincapacitated追加。生存数と活動可能数は区別する。counts.collapsedを使用し、deadに数えない。

## 援助判断

自発的援助から次の足切りを撤去：身体要求==0、strain<0.8、余剰>=1、相手が食料を持っていないこと。
提供可能な食品・接触・身体的に動けることは実行条件として残す。
身体要求は連続的な不利として、自分の不足増加は取引共通trade_compound_gradientのsecurity項として評価する。
相手の表情、関係MB、援助の予測、続行候補と共通選択で比較。援助の成立を強制しない。
相手の内部在庫・栄養値を判断へ追加していない。

要求への返答は既存の現在要求・留保・不安・関係評価を維持する。
全固定撤去済みではない：自発援助の64秒検討間隔、選択後300秒間隔、64秒実行期限、
1個の提供と先頭可食品選択、初期評価係数は従来のまま。移動して救助する計画も今回の対象外。

## 介助の暫定固定

`src/lw/configured_paths/assisted_feeding.jl`へ隔離。
scene.assisted_feeding既定true（falseで無効）。援助として選択・実行されたgiveが届いたときだけ、
行動不能かつ生存中の受領者に渡した1個を食べさせる。可食性・腸容量を検査。
既存手持ちを勝手に消費せず、今回届いた末尾の品を通常の栄養入力へ渡す。
これは嚥下・介助の動作を省いた実行上のショートカットで、MBによる自発的摂食とは報告しない。
将来、介助動作の候補・費用・観測へ置換する。提供側の援助選択は変更・強制しない。
所有物・cargo・食品品質/期限・消費数を一度だけ更新。二重適用は操作receiptで防ぐ。
イベントassist_feed / status=assisted_fed / configured_rule=assisted_feeding、提供側counts.assisted_feedに記録。
行動不能中の認知は停止しているため、この摂食を新たな味MB学習とはしない。
