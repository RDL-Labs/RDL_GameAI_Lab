# 目的から組む局所関係構造：H・ρ・境界の役割

2026-11-22。開始HEAD a173f20、未コミットの身体・取引等の変更がある作業ツリー上で実施。
設計案と局所試作であり、既存LW全域の移行完了を意味しない。

## 役割

目的に関係するMBを、経験による関係拘束の強さから呼び出し、今回扱う局所構造を組む。
目的自身もMBとして関係構造に含まれ、上位の要求との関係から再検討され得る。

| 要素 | 担うこと | 同一視しないもの |
|---|---|---|
| 関係拘束・勾配 | 現在の観測と経験から、どの変化が見込めるか、どちらへ流れやすいか | Hによる揺らぎ |
| 境界B | 今回扱うMB・関係・依存の範囲 | 解像度そのもの、世界全体の真の状態 |
| 操作解像度ρ | 呼び出した対象を何単位に分け、どの違いまで区別するか | 候補数だけ、単純な良さの指標 |
| H | 現在の関係構成・選択を揺らし、別の対処を試せるようにする | 欲求量そのもの、特定方向への報酬・罰 |
| 感度 | 観測された未解消差にどれほど反応するか | ρ、差を許容する幅 |
| 未回収ξ | 未観測・未展開など、今回扱えていない関係を残す | 不一致の確定、入力バグ、必ず正のH |

未解消差からHを作る規則と、Hから選択を揺らす規則を分ける。
身体要求や危険は目的・行動の勾配へ作用し、その解決見込みが外れた差はHの材料になる。
同じ観測が両者へ関係することはあるが、同じ尺度・同じ状態として混ぜない。
失敗経験による関係更新と、その場のHによる揺らぎも別の作用として記録する。

## 処理の流れ

1. 現在の目的と観測から強い関係のMBを呼び出す。未展開のまとまりも使える。
2. 境界Bとρを記録し、関係から候補・消費・成果の見込みを作る。
3. 関係勾配と局所Hから選択し、実行・観測する。
4. 見積もりに対して吸収できず残った差を、その目的・試行に結びつける。
5. Hによって別行動、確認、内部展開、粗い再構成、境界拡張も選ばれ得る。
6. 解決の証拠で該当する局所Hを解消する。子の成功だけで親の達成やHを変更しない。

Hが高いから必ずρを高くする、遠方へ進む、と固定しない。
細部が必要なら細かくし、細部に囚われているなら粗く再構成することも対処候補。
それぞれの見込まれる解消と計算・行動コストを評価する必要がある。
高Hでも候補が一つなら選択は変わらない。未呼出しの候補をHだけで生み出せない。

## 観測器ノートとの接続

参照：ユーザー提供「関係拘束における局所整合観測器 数式接続ノート v0.4.0」
（2026-11-21、原本はDownloads。添付文書の仕様を実装済みと扱わない）。

採用するのは境界・解像度・停止理由・依存・未回収・差分を明示する枠組み。
内部展開、仮除外、条件変更は別操作として記録する。今回は仮除外演算は未実装。
Φは比較可能な不一致の集計例であり、Hへそのまま代入する根拠にはしない。
ノートのqはモデル内の比較値。実世界の成功確率ではない。
ρ10はqの集中度変換であり、操作解像度ρとは別記号・別実装とする。
異なるρや境界で候補・尺度が変われば、HやΦの単純差分を改善量としない。

観測器全体を毎tick実行する必要はない。まず問題場面の診断用とし、通常は
必要な関係だけ扱う。停止したMBを真と確定せず、未展開として保持する。

## 局所試作と条件

`experiments/local_relational_observer/probe.jl`。本体未接続、実際の個体MB・地形は使わない。
既存 `BasicLoop.method_distribution` と `relational_transition` を再利用。
親目的はhome、同目的の人工経路MB二つと、境界混入を検査するfood MB一つ。
人工的な関係強度・粗い評価・細かい評価を入力する。細かい観測を生成する視覚処理や
粗視化演算は未実装。各条件を外から切り替えて比較し、個体が自動でρを変えたとはしない。
確認候補refine/coarsen/widenの見込みも人工値であり、学習成果ではない。
方法H・失敗履歴は空。既存の方法H減点や到着時の例外を全域で解消した試験ではない。

試験パラメータ `PROBE_RULES`：許容幅0.1、感度1、比較H=0/8、境界1/2件、seed22。
すべて単位なしの合成試験値。Hは現在の未解消差の許容幅超過分へ置換する試作で、
全域共通の累積・冷却式として採用していない。未観測は保留、同一証拠は再適用しない。
感情として目的間に残るHは対象外。

実行：`julia --startup-file=no experiments/local_relational_observer/probe.jl`

## 結果

Julia 1.13.1、25/25 PASS。分布の実数値は同ディレクトリの `result.md`。

- Hだけ変更した場合、候補と勾配は不変で選択分布の集中が弱まった。
- ρ変更では同じMBの評価が変わり、優位な候補が反転した。
- 境界拡張では同目的の別MBが追加され、別目的のMBは混入しなかった。
- 同じHでも確認の見込み次第で、細かくする／粗くする候補の優位が変わった。
- 未観測・別目的の成功は局所Hを消さず、同じ証拠は二重適用しない。
- 候補一つの確率1でも未回収は残る。不正なMB参照はエラーになる。
