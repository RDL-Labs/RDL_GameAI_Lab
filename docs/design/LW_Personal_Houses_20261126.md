# 個人宅の世界側の土台

2026-11-26。拠点の共有空間と、各個体に属する住まいを分ける初版。
建築行動ではなく、世界生成時から存在する簡略住宅。自動帰宅・認知停止を追加しない。

## 接続

- `scene.personal_houses=true` で実行側の `IDS` 全員に一戸ずつ配置する。
  `native_scene`（そこから派生する通常生成地形も含む）はON。
  既存入力でキー省略時はOFF。凍結入力・実行中ソースは変更しない。
- `house:<actor ID>` が永続的な対応キー。個人数やA/B/Cへの特別扱いはない。
  同じ個体列の末尾へ人数を追加しても先行個体の家を移動しない。
  個体列の並べ替えは別配置になるため、途中参加時も既存順を維持する。
- 中央共有領域を空け、四角い環を順に広げて配置する。障害物、低障害物、
  視覚目印、加工設備、採取点、水域、地形の外側を避ける。
  指定探索範囲に収まらなければエラー。重なった家を無理に生成しない。
- 家には所有者、中心、広さ、高さ、拠点中央を向いた入口、休息位置、
  `storage_owner` を持たせる。倉庫の数量は家にコピーしない。
  食品・物品の既存個人倉庫を同じ所有者キーで参照する設計。
- 屋根の外形は既存の目印・遠景観測へ接続。所有者IDや倉庫内容を視覚特徴へ
  渡さない。「誰の家か」の知識を全員へ自動注入する仕組みではない。
- `world_checkpoint.personal_houses` と `summary.personal_houses` に配置を記録。
  日初・日末のphysicalには本人の家IDと室内判定を観察者用に記録。
  配置は入力と個体列から再構成できるため、日次チェックポイントの状態項目は増やさない。

## 今回まだ変えていないこと

初版は壁なしの領域と見える屋根。壁・扉による遮蔽、衝突、遮音はない。
共有拠点への帰還、倉庫へのアクセス範囲、加工、食事、休息・睡眠の場所判定は従来のまま。
家を建てたことで勝手に入居・休息・認知停止する固定行動は追加していない。
GUI専用の家描画や人物の訪問・ノックも未接続。

次の接続は「共有拠点へ戻る」と「自宅へ帰る」の関係を分け、必要な用事を
終えた後の帰宅候補にすること。中央拠点座標を各家で一括置換すると、共有加工・取引の
場所判定まで変わるため行わない。人数拡大時の実行個体一覧の設定は既存ランナー側の責務。

## 設定と検査

`src/lw/world/personal_houses.jl` の `PERSONAL_HOUSE_DEFAULTS`。
scene.personal_house_settingsで上書き可能。単位はworld距離（人間尺度では1=10m）。
半径0.6、高さ0.4、余白0.4、間隔2、中央空間半径2、探索環上限32。
いずれも配置用の暫定世界条件であり、認知閾値・学習値ではない。
水際は余白を含めた範囲をz方向に刻んで検査するため、任意地形に対する厳密な建築判定ではない。

検査: `julia --startup-file=no --threads=1 --project=. experiments/social_relationships/personal_houses_checks.jl`
4/10/100戸、増員時の既存位置維持、所有者、重なり、水域、ON/OFF、配置不能、
乱数非消費、シリアライズ、および短いLW実行の保存再開を検査する。
長期生活で自宅を使用する試験ではない。

実行結果: Julia 1.13.1 / 1 thread、配置16項目・LW保存再開4項目、計20項目PASS。
再開と連続実行の最終個体状態・行動回数を比較。全内部状態とRNG状態の完全照合ではない。
