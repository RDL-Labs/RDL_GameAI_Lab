# 糞の痕跡：半日の個別情報と区画への統合

2026-11-12。初版は動物単独の任意sidecar。通常実験は未有効、
`animal_trial_advance!(...;scat_state=ScatTraces())` の状態を呼出し側で一度作り、
毎回同じ状態を渡す。nothingでOFF。捕食圧と身体収支は変更しない。

## 暫定固定設定

configured_paths/scat_traces.jl のSCAT_TRACEへ隔離。
兎はゲーム内1時間ごと、地上捕食者は4時間ごとに一まとまりを置く。
実際の粒数・排泄頻度ではなく、痕跡の集約間隔。各時点の位置を代表位置にする。
兎の基準エネルギー85、捕食者900。量は0.2+0.8*clamp(energy/reference,0,1)。
摂取履歴は追加せず、毎tickの消化も追加しない。無次元の情報量であり、
排泄でエネルギーを引かず、肥料や資源収支に加えない。幼体も初版では共通近似。
猛禽の排泄は未接続。

新鮮期間8640tick（半日）は位置・種別・量・時刻を個別保持。
4単位の区画で空間索引を持つ。半日後、残量を区画・種別ごとに統合して個別記録を削除。
統合後は半減期10日、量0.01未満で削除。30日一律消失ではない。
新規分の追加で古い量の鮮度を戻さず、減衰後に合算する。
半減期は生物学的な測定値ではなく仮設定。将来は天候・消化モデルへ置換する。

毎tickは時刻と間隔確認のみ。個体走査・整理は1時間ごと。
観測APIは近隣区画だけを検索し、個体ID・正確な排泄時刻を返さない。
古い痕跡の位置は区画中心へ粗くする。判断・匂い場・描画への自動接続はまだ行わない。
同一tick再呼出しは二重排泄しない。sidecarを世界と同時にSerialization保存する。
既存長期ランナーのチェックポイントへの自動組込みは未実施。

## 動作・負荷検査

`experiments/lw_wildlife/scat_trace_checks.jl [出力JSON]`。
半日統合、減衰、残量収支、保存復元、死体除外、同tick二重生成防止、時間逆行を検査。
実世界30成体＋初期幼体5、地上捕食者2、人なし、3日。
共有MB・身体モデルと満腹待機ゲートを使い、同じ初期状態を複製してON/OFF比較。
ウォームアップ後OFF/ON/ON/OFF。生態系・捕食者・MB・身体のSerializationバイト列を
照合する（その中のRNGも含む）。観測APIを動物の判断へ渡す試験ではない。
実測値は検証後追記。
