# 帰還後、夜までの認知停止（実験用固定設定）

2026-11-03。帰還後も毎tick観測・照合していた費用を分離するための、ユーザー指定の暫定介入。学習した省エネルギー行動や睡眠の生理モデルではない。

- 有効化：`scene.post_return_idle=true`。既定値はfalse。`daily_delivery=on`が必要で、社会関係・取引を無効にした航行実験に限定する。
- 条件：当日の親計画が帰還済みで閉じ、直前の方法の成否評価も済んだ個体。未達・探索中の個体は通常どおり動く。初日の固定見学もこの機能で短縮しない。
- 介入：観測前に対象個体を除外し、毎秒の行動を休息へ強制する。観測、候補評価、MB更新、覚醒中の経験記録を止める。食事・荷物操作も自動では行わない。
- 継続：身体の休息更新、代謝、消化、世界時計、資源・動物など世界側の更新、会計検査、日末保存は維持する。
- 解除：`clock.phase_boundaries_us[3]`（既存のnight開始）。通常処理へ戻し、既存の睡眠開始・整理・完了処理を実行する。睡眠完了まで認知を止める機能ではない。翌日の古い閉じた計画は停止理由にしない。
- 記録：`mb_map[actor].configured_post_return_idle`に累積停止tick数、開始回数、直近64回の開始／再開を保存し、通常イベントにも設定経路の休息と明記する。チェックポイントにも保持する。
- 実行前の条件表：有効/無効、終了済み帰還への適用、夜開始で解除、代謝・消化・睡眠維持、食事も停止することを記載する。
- 撤去方針：必要な観測だけ行う共通の注意・予測機構へ置換する。停止による計算削減と、食事や学習の機会減少による行動変化を分けて評価する。

既存の加工なし入力・終了済み30日試験は変更しない。古い凍結ソースには本実装がないため、新しいソースで実行する。

次回用の`experiments/rock_gate/navigation_idle_10d_input.json`は既存の加工なし入力に本設定だけ追加したもの。4体（A/B感度0.5、C/D感度1.0）、初日見学、有限だが潤沢な食料を維持する。実行側の`IDS`も4体にした新しい凍結ソースを用いること。入力の準備のみで、10日試験はまだ起動していない。

検査：`experiments/rock_gate/post_return_idle_checks.jl`。対象条件、保留中の行動評価、夜・翌日での解除に加え、実際の2日実行で停止tickとMB観測数の対応、全操作数、代謝、睡眠整理、食料会計、1日目チェックポイントからの完全一致を確認する。

近距離食料・3体・2日（初日見学OFF）の検査では、各34,560tickのうちA=21,967、B=21,900、C=21,901tickを停止。MB観測回数は停止分だけ減った（約63.4%）。各個体の睡眠整理は2回完了。これは観測回数の削減であり、既存30日試験の実行時間改善率ではない。
