# 共通身体組成：捕食者の局所接続（2026-11-12）

## 実装範囲

src/body/composition.jl に種非依存の Composition を追加。
即利用分・脂肪・身体タンパク質を、従来モデルと同じエネルギー相当単位で保持する。
実重量や栄養学的kcalではない。維持組織の下限は利用可能エネルギーに含めない。
消費は即利用分→脂肪→下限を超えるタンパク質の順。これは簡略化で、実際の並行代謝を再現しない。
身体タンパク質が減ると速度・攻撃移動倍率が低下。一定量以下でへたり込み、
最小維持組織へ達すると死亡する。回復中も代謝は続く。

捕食者は ComposedPredatorPhysiology(p) を明示した場合のみ接続。
既存 PredatorPhysiology と TrialPredator の構造を変更していないため旧保存用の型は維持。
通常ランナー/進行中360日実験は従来身体のまま。人・兎の接続は未実施。
共有Bodyのreserveとp.foodは組成から算出する合計のミラーで、別の備蓄ではない。
世界側の実消費・実摂取を一度だけ組成へ反映し、spent/eatenと照合する。

## 暫定設定と救助

predator_composition.jl に隔離。初期900を即利用150・脂肪450・消耗可能タンパク300へ分配。
構造タンパクの維持下限300、初期600、へたり込み450以下。
身体の燃料を増やして飢餓耐性を延ばす変更は今回行っていない。
repair_per_tick=.05 は未較正。即利用分を同量だけ組織へ移す（エネルギー保存）。
修復費用、栄養別の合成制約、脂肪の再蓄積、消化は次段階。
このため現在の給餌は栄養組成を問わないエネルギー相当量であり、
脂肪だけから筋肉が作れるという生物学的主張ではない。

へたり込み後は給餌なしの休息では復帰しない。給餌後も即復帰せず、
タンパク質が初期量まで修復されたところで解除する（暫定身体条件）。
意思決定ゲートは通常のMB探索を停止し、代謝・外部給餌は継続。
独立した救助行動/人の観測判断は未接続。
configured_predator_feed! は直接給餌の試験API。死亡後の復活はしない。
局所試験では獲物捕獲と移動を停止して飢餓だけを検証する固定条件を使用。
将来は人のgive/動物の摂食、種別の身体設定と共通化する。

## 上限あり脂肪蓄積（2026-11-12追記）

共通関数 composition_store_fat! を追加。維持・活動消費と組織修復の後に呼ぶ。
転送量=min(即利用分の留保超過,脂肪上限までの余地,蓄積速度×経過時間)。
即利用分から同量を脂肪へ移すため総エネルギーは不変。
生存中、へたり込みでなく、タンパク質が目標まで修復済みの場合だけ蓄積。
上限超過の古い状態を渡しても削除はせず、新しい蓄積だけ止める。
留保は脂肪変換から守る量であり、維持代謝で使うことは禁止しない。

捕食者の暫定設定はstorage_reserve_floor=300、fat_capacity=900、fat_storage_per_day=30。
種/体格別に差替え可能なパラメータで、個体の行動を固定するものではない。
総備蓄上限1800と脂肪上限900は別。総備蓄上限を超える給餌分は受け取らない。
既存組成型/保存形式は変更なし。ComposedPredatorPhysiologyだけ有効。

## 糖相当の不足と脂肪による支持（2026-11-12）

身体組成ありの地上捕食者は、空腹を available の不足で評価する。
充足目安は既存の storage_reserve_floor=300 と共通の暫定身体値。
脂肪・消耗可能タンパク質を足して満腹とはしない。
消費は既存の available → fat → protein の順で、available の下限0に達すると
脂肪が消費を肩代わりする。脂肪から available を増やさないので空腹は継続する。
総利用可能量は死亡・収支・移動可能性の評価に引き続き保持する。

狩りの優先度、食料需要による候補絞り込み、満腹待機、採食不成果の空腹増幅、
渡河候補の空腹、休息中の空腹変化を同じ predator_hunger/food_deficit に接続した。
試行開始時の空腹は候補へ記録し、旧保存データでは従来値をfallbackに使う。
身体組成なしは従来の総備蓄基準を維持。兎の食欲は今回変更しない。

これは血糖の生理モデルではなくエネルギー相当量の簡略化。
脂肪900・available0でも狩り候補が残り、待機固定が解除される。
摂取300でavailableが回復すると不足が0になる局所検査は17項目PASS。
脂肪が高いほど空腹が消えるという経路を除いた確認であり、
死亡直前の地形停滞の解決や、長期生存率改善を確認したものではない。
