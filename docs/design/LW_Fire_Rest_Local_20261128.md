# 焚火周囲の弱い休息吸引：局所モデル

通常LW未接続・既定OFF。`configured_paths/fire_rest_local.jl` を局所から明示include。
安全と認識した制御火に対する休息場所効用を加える仮説であり、生得的安心の実証モデルではない。
全MBのH冷却、休息報酬、取引・集合の強制は追加しない。

## 条件と暫定設定

4人、200シード、各40回の休息場所選択。各条件で同じ乱数列を使用。
候補は現在地・自宅・焚火周囲の各1つ。焚火周囲を多数の座標候補にして票を増やさない。
全員が場所と安全な火を知る実験設定。世界中心の火から半径6に自宅、半径2に休息候補。
休息場所の候補効用から移動距離費用を引き、softmaxで選択する抽出モデル。
同じ座標になる現在地・自宅等の候補は両条件で同様に残るため、場所確率の一般値とはしない。
選んだ場所へ直線移動し待機する局所ハーネスであり、通常LWの移動・身体・障害物・生活判断は動かさない。

`FIRE_REST_LOCAL_RULES`：gain=.4（最大オッズ倍率約1.49）、comfortable_distance=2、
width=1.5、hot_distance=1.2、heat_penalty=2。近すぎる火には反発、遠距離・未観測には加点なし。
安全度0なら吸引なし。距離の単位は世界距離。将来は身体の暖かさ評価と場所MB経験で置換。
`FIRE_REST_FIXTURE`：seeds=200、actors=4、episodes=40、travel_cost=.12/距離、
home_value=.20、speed=.5/tick、rest_ticks=12、arrival=.2。tickは局所単位で生活日へ換算しない。
試験値は実測の人間心理係数ではなく、弱い作用の方向を確認する設定。

## 結果

Julia 1.13.1、1thread。境界・OFF・未観測・安全度・再現性8項目PASS。

|指標|OFF|ON|
|---|---:|---:|
|焚火周囲候補の選択|9,086|11,404|
|自宅候補の選択|11,598|9,099|
|焚火周囲の延べ個体tick|232,542|306,778|
|全個体tick中の周囲滞在率|41.8%|55.1%|
|2人以上が周囲にいるtick|77,022|105,504|
|全tick中の2人以上滞在率|55.3%|75.9%|

周囲は1.2<距離<=3。総tickはOFF139,176、ON139,080。
200シード中199で同時滞在tickが増加した。周囲同時滞在は会話距離・接触・取引成立を意味しない。
移動中も含む占有指標で、休息中限定の指標ではない。

これは選択モデルに加えた吸引の作動確認。実際のLWでの集合・市場形成・MB学習の証拠ではない。
通常系へつなぐ際は既存の休息候補効用へ加え、食事・帰宅・身体負荷と比較する必要がある。
安全度や火の位置を世界の真値から直接渡さず、観測・経験に接続する。
