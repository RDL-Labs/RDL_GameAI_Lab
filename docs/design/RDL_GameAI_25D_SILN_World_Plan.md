# 2.5D SILN World — 独立した物理構造帯

状態: **DESIGN ONLY / 統合レイヤー未実装・未検証**  
作成: 2026-10-04  
照合基準: `3d05b11`  
対象: RDL_GameAI_Labの軽量World。Core定義・semantic referenceを変更する文書ではない。

## 1. 目的

平面上の移動と高さを持つ物体を土台に、重量・障害・肉体・抵抗の相互作用を
独立したWorldレイヤーで扱う。認知的な関係の多次元性と、物理空間の次元数は分ける。
初版は地面を平坦に固定し、坂・下り・落下の一般3D計算を持ち込まない。

Worldも、用途と境界を明示したモデルとして記述できるようにする。
「2.5D SILN World」はそのGameAI側の設計名であり、Worldが自律的に学習・T1更新する
機構や、CoreのSILN適合性を実証済みという宣言ではない。

## 2. World側のモデルと個体側M_B

| 区分 | 保持・更新 | 個体への提供 |
| --- | --- | --- |
| 実験者が定めるWorldモデル | 境界、更新規則、形状、物性、資源・配置、モデル版 | 真値を直接渡さない |
| Worldの実行状態 | 位置、速度、物体、積載、接触、散逸、作用履歴 | センサー・身体receiptを通す |
| 身体 | 出せる力・出力、余力、疲労、肉体限界 | 本人の有限な身体観測 |
| 個体側M_B | 本人の経験から形成する解釈・予測・目標・方法 | 他個体と独立 |
| 実験者ログ | World真値と結果監査 | 個体入力にしない |

World側モデルをM_Bとして扱う際も、誰が・何の問いで・どの境界Bを切ったモデルかを
明記する。初版の実行エンジンは固定規則でよく、個体の採用済みM_Bと同じ台帳へ入れない。
Worldの状態更新とモデル規則そのものの改訂も別にする。
力・仕事・散逸をそのままCore E/H/θへ同一視しない。

```text
World規則＋現在状態
    ↓ 有限観測                  ↑ 操作要求
個体の観測・身体感覚 → M_B → 方法選択
    ↑ 実行結果                  ↓
Worldと身体が共同で作用を解決 → World/身体の状態変化
```

## 3. 初版の空間・責務

- 移動と掃引衝突は水平2D。物体は平面形状＋高さを持つ。
- 視認は眼高、対象高、距離、仰角、遮蔽で決まる。塔や山の遠景を維持する。
- 見えること、身体が通れること、手が届くことを別判定にする。
- 障害越えは高さ・必要仕事・身体能力・着地点を検査する有限操作。
  連続する上下軌道、空中制御、落下・転倒は初版外。
- 個体の目的は駆動要求に作用するが、Worldの物性や成功条件を直接書き換えない。
- 複数個体の同時作用はWorld側で解決する。初版の個体間衝突を扱うかは実装契約で固定し、
  現行の非衝突挙動を暗黙に変更しない。

## 4. 力・仕事・身体消耗の接続案

以下は未実装の近似案。単位と係数は受入実験前に固定する。

```text
総質量 m = 身体質量 + Σ(荷物の単位質量 × 数量)
平面抵抗の大きさ R = μ_eff × m × g
平面運動: m a = 駆動力 + 制動力 + 抵抗力 + 接触反力
上昇仕事の下限: W_up = m g h
```

μ_effは草地・道・砂などの損失をまとめる有効抵抗値で、精密な歩行摩擦モデルではない。
抵抗は運動を妨げる向きに作用する。静止時に自発的な逆向き加速を生まないようにする。
時間刻み、速度上限、接触処理、駆動力/出力上限を先に固定する。
停止や衝突で失う運動エネルギーを身体のreserveへ回収しない。

身体消耗は物理仕事だけでは決まらない。基本動作コストと変換効率、制動負荷を別に持つ。
現行burst/strain/reserveは無次元のproxyなので、ジュールと直接足し引きしない。
仕事→proxyの変換契約を置き、これまでの荷重係数と二重課金しない。
力が不足、エネルギー不足、形状不適合、着地点なしを別の結果理由にする。

登る操作でmghを消費しても、着地で同量を回復させない。
平坦Worldでの越え操作は、上昇と着地散逸をまとめた近似として収支に記録する。
完全な熱力学的閉鎖系ではない。食料補充など外部入力を明示する。

## 5. 所持・設置・世界履歴

採取、drop、再取得、荷下ろし、食事を一つの資源/積載台帳に接続する。
dropは消去ではなく地面への移動。他個体も有限観測で見つければ取得できる。
誰の物か、安全か、置いた場所を覚えているかは別の認知・関係契約。

同一操作再送で物や通行痕跡を増やさない。共有資源の競合を個体別経験へ返す。
個数・質量は、明示した生成/消費/外部配送分を含めて監査する。
Worldの現在状態に作用の結果が残るという点で、
[世界履歴案](RDL_GameAI_World_History_Idea.md)の草地→踏み跡→道へ拡張できる。
ただし初版で道形成を実装せず、外観変化と抵抗変化も別の比較にする。

## 7. 境界インターフェース案

| 入出力 | 内容 |
| --- | --- |
| World定義 | model/version、単位、時刻規則、物性、境界・外部入力 |
| 操作要求 | run/agent/operation ID、元観測、取得時刻、目的とは分離した身体要求 |
| 物理解決結果 | 実変位、荷物移転、仕事、散逸、身体消耗、成功/不成立理由 |
| 個体への投影 | 契約で許された実変位・身体感覚・観測。未知の障害物IDや全座標は除く |
| 監査ログ | 全状態の前後、解決順序、収支、再送処理。個体用とは分離 |

一般forceベクトルを直接個体へ要求するか、move/climbをadapterが変換するかは
実装前に固定する。初回は既存操作語彙のadapterを優先する。
Worldモデル版の変更で既存経路M_Bを無条件に有効扱いせず、比較条件として追跡する。

## 8. 段階計画と受入候補

| 工程 | 範囲 | 受入候補 |
| --- | --- | --- |
| PW-0 | 単位・時計・状態・receipt契約 | 旧資産との対応、個体入力/真値分離 |
| PW-1 | 既存幾何/観測の共通化 | 塔の遠景、低壁越しの視認、身体衝突の区別 |
| PW-2 | 平面の質量・駆動・抵抗 | 静止安定、加速/停止、抵抗/重量に応じた仕事、刻み依存の許容差 |
| PW-3 | 積載・drop・障害越え | 空荷/5個/6個、休息だけでは荷重不変、再取得・配送の保存則 |
| PW-4 | 探索・危険・帰還・Sleep | 同じ条件の比較、重複作用なし、身体条件付き経験、未達も保存 |
| 後続 | 世界履歴 | 実通過による痕跡。外観と抵抗の変化は別検証 |

全工程は予定。今回は文書化のみで、新規実行・物理実装は行わない。
移動効率や全員帰還を完了条件にせず、作用が継続し、不成立理由と収支を追えることを重視する。
斜面、一般剛体エンジン、精密生理、World自身の学習的モデル更新は初版の必要条件にしない。
