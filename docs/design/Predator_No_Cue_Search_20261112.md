# 匂いヒントなしの探索拡張：局所検査（2026-11-12）

## 実装
匂いの未観測を不在と扱わない。実際の定期嗅覚確認3回連続で観測ヒントが
なければ、H由来の探索半径の下限を32にする。Hによる上限64の拡張は維持。
ヒントが得られた際は連続不検出を解消し、無ヒント状態からの復帰時だけ
遠方仮目標を失効させる。匂いを確認するたびに乱数を引き直さない。
設定・OFF方法はLW_Parameter_Catalogの同日項目を参照。
嗅覚の半径や閾値、古い匂いの評価は今回変更しない。

## 局所検査
個体2: 元68日末から71日末、個体5: 元77日末から80日末。
Hのみの版と今回版を順次実行。同じ保存状態を各回復元。
実際の観測なし・3回連続不検出・検出復帰・二重計数防止・休息・保存復元を
専用fixtureで確認。共通指数29項目、無ヒント判定8項目、
以前のHのみ版との代表集計一致6項目、計43項目PASS。

調査途中、毎回の匂い確認で仮目標を失効させる版は個体2で捕獲1となったが、
無ヒント拡張は作動していなかった。この副作用は除去し、採用結果に含めない。

両個体とも判定対象の嗅覚確認はすべてヒントあり。
そのため自然再現では無ヒント拡張を試せる場面がなく、効果判定はできない。
「近くに兎がいない」と「有効な匂い観測がない」は同一ではない。
体臭の履歴や糞も観測対象。どの種類・鮮度が支配していたかは未集計。
次の調査候補は、実体のない古いヒントが近隣探索を持続させていないか。

診断のヒント回数は実際に嗅覚確認した時だけ集計。
旧prey_observationsを捕食者の視認数と解釈しない。
