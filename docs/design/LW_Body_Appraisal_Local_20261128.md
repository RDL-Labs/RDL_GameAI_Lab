# 実限界より早く悪化する身体評価の局所実験

身体評価を独立した疲労蓄積量ではなく、身体状態から導出する。今回の局所評価は `(1-capacity)^2/reference^2`。capacityは既存の消耗・damageから導出し、実限界は変えない。reference=.35は停止閾値ではなく負担尺度の暫定基準。比較はreference=1。同じ栄養条件を仮定し、今回栄養状態は評価に追加していない。

通常LW未接続。sleep_repair_forecastへ評価関数と回復対象量の任意引数を追加し、既定は従来式を維持。局所では短期fatigueを負担・回復報酬のどちらにも使わない。fatigue=0/99で候補が完全一致することを確認した。既存状態型のfatigueフィールド自体はまだ削除しない。

身体消耗10/35/50/70/90%、帰路6/30/60/120分の20条件。作業利益4・追加作業1時間・同じ6時間評価は先行局所モデルを共用。確率は共通method_distribution。以下は実際の生活試験ではなく、候補分布の比較。
