# 近傍障害物場の候補間共有（2026-11-03）

障害物の勾配は従来も近距離だけで作用していた。ただし各移動候補で
全構造の観測点を走査し、道の主軸・近接度を繰り返し計算していた。
この変更は知覚範囲や行動規則を変えず、その重複計算を削る。

- `rho_local_field` は、一歩の最大移動距離spanとρに応じた反発の支持半径から、
  どの候補にも届かない障害物・水辺の観測点を除外する。
- 採用半径は `abs(span) + rho_boundary_range(map, clearance)` に丸め誤差分を加える。
  その外の点は三角不等式により全候補で反発0になる。
- 道の向きは遠方の観測点でも変わり得るため、道の点は全て残し、主軸を一度計算する。
- 候補のrho affordance評価は一つの準備済み場を共有する。
  選択後の9方向ステアリングも、同じ準備済み場を共有する。
- 引力の方向は各候補・目標ごとに計算する。遠い壁・川の構造MBや
  通路候補は削らない。物理的な衝突判定も変更しない。
- 場は一つの候補バッチ内だけで使い、観測・個体・tickをまたいで保持しない。
  準備したspan外の問い合わせには使わない。観測間隔を広げる変更は未実施。

元の単点評価 `rho_potential` は参照式として残す。比較対象は同じ式・同じ入力で、
新しい強制行動や固定優先順位は追加していない。

## 検査

`rho_local_field_checks.jl` の専用257項目PASS。fine/coarse、荷物・走行相当の
clearance、歩幅、道・水・岩、支持境界の前後、観測差替えを含め、
元の式とポテンシャル全成分・選択角度が完全一致することを確認した。
既存の地形構造・狭い入口・物理衝突の検査も同じ実行でPASS。

計測は55日目末の4体の実観測地図と、近距離・遠距離混在の人工fixture。
37方向の候補評価バッチと9方向ステアリングを、コンパイル後に各100回×7回測定。
値は1バッチ当たりの中央値。新方式の準備費用も含む。
これは観測生成やMB探索を含むシミュレーション全体の速度ではない。
