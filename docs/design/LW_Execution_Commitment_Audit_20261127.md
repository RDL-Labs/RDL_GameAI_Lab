# 選択・遂行・再検討の共通化調査

開始HEAD 6e65f28。対象は通常LWの人間側。釣りで見つかった二重選択を、
単なる確率の低さと混同せず、親目的・手段・場所・子動作に分けて調査した。

## 共通契約

選択時点で見込んでいた不確実性だけを理由に、同じ決定を実行直前に再抽選しない。
選んだ計画は遂行し、完了、中断、観測された矛盾、関連する状況変化、要求/Hの増加、
見込み時間の超過があれば、その階層で再比較する。視界消失は矛盾の証拠ではない。
子の局所修正は親の失敗ではなく、場所変更は手段断念でもない。

`learning/execution_commitment.jl` は選択キー・固定期限・文脈・圧の基準を保持し、
再検討理由を返す。行動選択、Hや報酬の更新、世界の実行判定は行わない。
再検討は候補の再比較であり、現在の候補を強制的に禁止することではない。

## 実装の境界

取得候補は固定した `seconds` から期限を作り、採取・釣り・探索で共用。
空だという**新しい**観測は再比較理由にするが、すでに空と知って選んだ場所に同じ観測を
繰り返しても新たな矛盾にはしない。観測を捏造せず、視界が空なら空の観測を返す。
選択直後でまだ試行の実行記録がない場合も、明示的な親変更では選択を終了する。

日次計画では既存64秒を検査間隔として残し、毎回の抽選間隔とはしない。
取得量、計画の段階/epoch、補給状態が変わる、本人の空腹Hが増す、固定見込みを超える、
探索中に新しい/再生した食料源を認識する場合に再比較する。
未知食料の発見・確定した枯渇・実際の取得・帰還・日次期限の処理を残す。
切替理由を acquisition.records / daily_plan.decisions の review_reason へ記録する。

## 限界

見込みは現状の近似秒数で、共通期限は経過時刻による。すべての階層で停止時間を差し引く
実行予算になったわけではない。Hの増分をどう吸収するかや個性の感度は今回変更しない。
既存の日次目的・固定研修・呼びかけなどを自律的な目的形成へ置き換える変更ではない。
すでに正しく保持する系を新APIへ機械的に書き換えることは避けた。
親決定より前に取得候補を作る配置自体は残り、不要な候補構築の削減は別の速度課題。
