# 観測された遷移から類似基準を学ぶ

2026-10-26。FINITE PROTOTYPE。固定の個性感度とは独立に、MB認識の距離帯差と相対方位差への重みを個体別に学ぶ。初期重みは従来と同じ距離2・配置1。同じ色の対応があることを入口とする点は従来どおりで、色自体の同等性、幅/高さ、物体の真の同一性、目的に応じた抽象化は今回の学習対象ではない。

## 教師は実行後の観測

実行済みwalk/scanの直前/直後の場面キーを直近64件保持する。同じ操作種別・15度単位の相対操作角・0.1単位の移動距離・親目的の経験から、直近最大8件を比較する。失敗した操作、次tick以外、観測なし、共通色が2未満の比較は学習しない。学習対象は経路MBを使った操作だけに限定せず、通常の実経験も含める。

比較先の実観測と今回の実観測を、学習前からの固定基準（距離2・配置1）で照合する。一致度0.85以上を正、0.65以下を負、その中間は不明とする。これは「同じ操作の先を同様に予測できるか」の弱い教師であり、同じ場所・同じ個体という正解ではない。環境変化や遷移の違いも混ざり得る。学習した類似度をそのまま自身の教師へ使わず、目的未達や空腹を見た目の不一致ラベルにしない。

## 更新と利用

共通色の各特徴について、距離帯差dと回転整列後の相対方位差a（30度単位）からexp(-w_distance*d-w_layout*a)を求め、平均を類似度とする。固定教師0/1との二乗誤差から学習率0.05で更新し、各重みを0.25〜4へ制限する。特徴差が両方0の比較では更新しない。数値は実験用の初期設定であり、最適値の根拠ではない。

候補対応、経路継続の再対応、局所再接続には学習した重みを使う。診断用の予測一致/不一致判定は固定基準のままにし、学習によって過去の失敗が自動的に成功へ変わらないようにする。元の場面記録を統合・削除したり、仮想辺を実績化したりはしない。

更新回数は経験の件数ではなく経験ペアの比較回数。1操作から最大8回更新し得るため、独立な試行数として数えない。記録は重み・正負更新数・不明比較数・直近64比較、経験バッファ64件。係数が上限/下限へ張り付く可能性も検査する。個性感度A=.5/B=1/C=2は変更しない。

## 切替と確認

統合specのconfig.mb_similarity_learning="off"で従来の固定基準へ戻せる。既定はon。rock_gate/run.jlでは --similarity-learning on|off。無効時は学習も停止し、初期固定重みを使う。

専用検査では正例で該当特徴の罰が弱まること、負例で強まること、無関係な特徴を更新しないこと、上限/保持数、通常観測からの更新、実行不能/観測なしの除外、診断教師の不変を確認する。サイズ特徴をまだ保持していない問題、色を越える対応、場面の自動統合は残る。

3日実行結果は[検証レポート](../../experiments/rock_gate/learned_similarity_report.md)を参照。重みは実経験から変化したが、今回の行動軌跡は固定基準版と一致し、経路再利用への効果は未確認。
