# ρ・差への感度・経験更新の共通設計

2026-10-26。状態: **DESIGN ONLY**。この文書は会話から整理したGameAIの設計仮説であり、人間の認知機構についての実証的説明でも、RDL_Coreの定義変更でもない。今回は文書のみを追加し、実行中の30日試験やruntimeは変更しない。

## 1. 区別するもの

予測と現実に差があること自体は普通である。すべての差を失敗や強いHにすると、認識も経路も安定しない。一方、差を無条件に吸収すると、危険な誤認や目的未達を見逃す。

| 要素 | 役割 | 混同しないもの |
| --- | --- | --- |
| B | 今回扱う関係・比較の境界 | B内の区別の細かさ |
| ρ | どの特徴・関係をどの細かさで区別・操作するか | 差への感度、単一の抽象度やズーム倍率 |
| 予測と観測の差 | 同じ比較条件で想定から何がずれたか | すべてを失敗とする評価 |
| 経験上の変動幅・不確かさ | 普通のばらつきと、まだ知らない範囲 | 許容してよい危険の大きさ |
| 感度 | 捉えた差にどの程度反応するか | ρそのもの |
| H | 吸収・解決できずに残った差を行動再検討へつなぐ圧の操作的近似 | 生の特徴距離や単なる驚き |

ρを細かくしても、目的に無関係な差へ強く反応する必要はない。逆に粗い認識でも、危険や身体要求に関係する差には強く反応できる。感度をCoreのρやtheta_effへ直接同一視しない。

## 2. 認識は目的に応じて差を吸収する

「人」という分類では体格・服・姿勢の違いを吸収できる。一方「誰か」を区別するには顔・声・歩き方など別の特徴が必要になる。これは設計の直感例であって、具体的な人間モデルを確定するものではない。

人混みの移動では位置・流れ・隙間を粗く扱い、特定の相手を探す場合は必要な特徴を細かく扱う、という使い分けを目指す。知り合いに相当する経験の蓄積は細かな識別の材料を増やすが、常に細かな処理を実行することは意味しない。**経験が区別できる能力を育て、現在の目的が使う解像度を選ぶ。**

LWでは画素から始めず、個体が観測できた位置・色・形・動き・相互関係を材料にする軽量な構造認識を想定する。世界の正解ラベルや未観測の地図を渡さない。対の光源と隙間を入口候補として扱っても、実際に通れるかは別に検証する。

## 3. 地形・行動・抽象経験を同じ更新手順で扱う

岩の位置が少し違っても壁として扱い、経路の座標が少しずれても「壁沿いに進み、隙間を抜ける」という関係を再利用する。同様に、具体的行動から「障害を避けて目的へ近づく」、複数経験から「直接解決しなければ別手段を試す」という関係候補を作る。

共通化するのは表現の単一化ではなく、**候補化 → 予測 → 使用 → 結果照合 → 適用範囲の更新**という手順である。抽象度とρは単純な一軸に固定しない。抽象的な関係にも細かな条件の区別が必要になりうる。

1. 更新前のMB、目的、B、ρ、予測とその幅を固定して試行を始める。
2. 観測された関係から、既知のMBとの対応を仮に選ぶ。未知と誤認を分けて記録する。
3. 実際の行動と結果を照合する。見た目の近さだけで採用や成功を確定しない。
4. 違いがあっても予測・目的達成が保たれれば、その条件での共通性を強める。
5. 結果を分ける差が繰り返し現れれば、特徴の重み・適用条件を更新し、必要ならMBを分割する。
6. 別々の経験でも関係と予測が共通なら統合候補を作る。成功1回で普遍化しない。

同じ結果が偶然出た場合や、局所修正が元の経路を補った場合を区別する。睡眠中の整理・仮説生成は更新候補を作れるが、未実行の仮説を実経験や成功として加算しない。

## 4. 連続的な差・感度・Hへの接続案

Hの型を小数にするだけでなく、残差の評価と候補への作用を滑らかにする。時間超過・消費超過・認識不一致は単位も意味も異なるため、それぞれの予測に対応する尺度で比較する。早着などの有利な差を、遅延と同じ罰にしない。

概念上は「目的に関係する残差 → 経験上の幅を踏まえた評価 → 感度による反応 → 未吸収の圧 → 候補選択」とする。これは確定した数式ではない。普通の変動内では弱く、意味のある超過ほど強く反応する連続応答を比較する。高H時の候補拡張、ρの再検討、局所修正、全体変更も急な二値切替だけに依存させない。

経験上のばらつきと知識不足を分ける。未達が続いたから予測幅を際限なく広げ、Hを消す更新は禁止する。未達は未達の下限として記録し、身体の実際の不足や危険は独立して残す。現在の試行中に見積もりを書き換えて超過を帳消しにせず、学習結果は次回の予測へ反映する。

同じ未解決残差を毎tick再加算するかどうかも明示する。現行の親・経路の重複課金防止を維持し、累積残差・追加増分・解消を別々に記録する。ρ変更や感度低下で差が見えなくなっても、目的達成やH解消報酬にしない。異なるρの評価は対応関係なしに直接加算・比較しない。

## 5. 感度の個体差と学習

個性を「臆病」「粘り強い」と固定行動で指定する代わりに、何の差に敏感かの違いから行動傾向が生じる設計を目指す。空腹、危険、停滞、新奇性などの感度を一つの万能スカラーへ潰さない。新奇性への反応は危険回避や失敗罰と同義ではない。

感度には、生来の基準、経験による比較的持続する変化、身体状態・目的による一時的変調を区別して持たせる案とする。予測の精度向上、特徴の重要度変更、感度の変化は別々に観測できるようにする。同じ差への反応が弱まっても、学習による適切な許容なのか、単なる感度低下なのかを区別する。

## 6. ρ選択と計算コスト

まず粗い候補で足りるかを評価し、目的に関係する曖昧さや予測破綻がある部分に、細かな再解釈・追加観測を候補化する。常に粗から細へ進む固定段階は必須にしない。経験上、初めから細かく見る方が有効な場面も学べる。

既存観測を細かく解釈することと、新たな観測を取得することを区別する。元の入力にない特徴をρ変更だけで復元しない。詳細化による予測改善と、CPU時間・記憶量・観測時間・切替コストを比較する。身体の思考コストと実PCの実行時間は別の測定値とする。

## 7. 現状と検証順序

現行には固定ρの局所地図、確率的な認識、経験による見積もり更新、局所修正中の全体経路保持がある。本案の動的ρ選択、学習する特徴別感度、関係の自動分割・統合、抽象経験まで含む共通機構は未実装。連続量Hの全体導入もこの文書では行わない。

Juliaで、まず同じ凍結観測・目的に対するρと感度を独立に変える小規模比較から始める。位置・服相当の外観だけの変化には関係認識を保ち、通れない隙間や危険な変化は吸収しないことを確認する。次に結果から予測幅・特徴重みを更新し、分割・統合が必要な反例を与える。動的ρと感度学習を同時投入せず、固定版との比較で寄与を分ける。

同一seed群・初期条件で、誤認、見逃し、予測誤差、目的達成、経路保持と破棄、ρ切替、計算量を測る。未観測は不明のまま、誤認は誤認として残す。現在の局所修正版30日試験は比較基準であり、本案の検証結果には数えない。
