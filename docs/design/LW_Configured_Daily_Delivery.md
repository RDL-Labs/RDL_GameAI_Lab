# 設定経路：持ち帰りで一日の外出目標を達成

実験用の固定ルール。学習された目標形成・埋め込みMBとは別。`--daily-delivery on`で有効化（rock_gate runner、JSON config.daily_delivery）。既定off、MB/basic_loopが必要。

各個体が拠点で実際に1食以上をdepositした日に達成を記録する。空の荷下ろしや単なる到着は達成にしない。同日の重複達成は数えず、翌日リセットする。達成後はhome目的を保持し、既存の拠点内休息へ接続する。危険回避・食事・備蓄取り出しは既存の優先順位を保つ。退避で離れた場合も通常の帰還候補で戻り、移動の強制成功や座標誘導は追加しない。

食料補充要求があり、手持ちも最後に観測した備蓄も0なら滞在要求を追加しない。拠点外から共有在庫を透視せず、備蓄記憶は拠点内で更新する。他個体の消費で古くなる場合は帰還後に再評価する。初日の設定観察はこの滞在要求より優先する。

状態はmb_mapのconfigured_daily_deliveryに保存。completionsは日ごとの達成、stay_requestsは要求tick数で実休息時間ではない。独立した報酬や学習成功を捏造せず、従来の実行結果・拠点休息報酬から学習する。目的は取得→持ち帰り→身体維持の経験を可能にすること。将来はこの固定ルールを除き、滞在と外出の見積もり比較へ置き換える。
