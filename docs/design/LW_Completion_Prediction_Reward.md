# 達成証拠と予測差による報酬（2026-10-26）

food/home の親MBについて、実際の目的達成を確認した時点で報酬を計算する。Hの減少量だけに報酬を依存させない。初成功専用の定数加点は入れない。初回の見積もりは依然として仮定を含み、初成功が必ず高報酬になる保証はない。

## 計算

選択時に凍結した expected_actions と expected_energy を実績と比較する。energy は従来どおり上限予算であり、期待消費の中心 expected_energy とは区別する。

- 時間差 = (期待操作数 − 実操作数) / max(1, 期待操作数, 上限操作数 − 期待操作数)
- 消費差 = (期待消費 − 実消費) / max(0.01, 期待消費, 上限消費 − 期待消費)
- f(x) = tanh(sign(x) × max(0, abs(x) − 0.1))
- advantage = (f(時間差) + f(消費差)) / 2
- 報酬 = 1 + 0.75 × advantage

したがって予測どおりは1、小さな差は同等扱い、速い／低消費なら増加し、遅い／高消費なら減少する。範囲は0.25〜1.75。これらは実験用の固定係数で、学習済みの最適値ではない。尺度は予測の大きさと上限幅に基づく近似で、校正済みの標準偏差ではない。個体のH感度とは分離する。

時間は当該目的に使った操作数であり、休息や他目的の壁時計時間を含めない。局所修正の実コストは含む。目的達成後に見積もりを学習するので、今回の結果によって今回の報酬基準は変わらない。未達・未観測は成功報酬にならない。

## 接続と記録

親MBの評価記録に凍結見積もり・実績・符号付き差・尺度・報酬を保存し、goal/source/評価時刻が一致する結果だけを取り出す。同一の報酬値を方法選択、経路試行、実行した経路のまとまりに渡す。それぞれ別の学習統計であり、合算して三倍の報酬にしない。BasicLoopの同一証拠再投入は二重加点しない。

目的達成とHのゼロ判定を分離し、報酬が0でも、観測で裏付けられた連続した2辺以上の実行経路は成功経験として保存する。既存の接続・目的・観測・重複チェックは維持する。局所修正を含む成功は、元の計画経路がそのまま正しかったことの証明ではない。

親MBの対応する完了評価がない呼び出しには従来のH減少報酬を残す。全システム一律の移行ではない。帰還目的の成立には拠点内での確認も含むため、実際の外出→再入場回数とは分けて評価する。
