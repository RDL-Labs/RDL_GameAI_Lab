# 軽量Worldと探索Runtime接続計画

状態: LW-0/1 FINITE IMPLEMENTED、LW-2 READ-ONLY REPLAY IMPLEMENTED、LW-3比較完了（適用機会なし）、LW-4以降未実施
基準: `ae0f1ae`（2026-09-29）

## 目的

Luantiの長期安定運転を当面の主課題から外し、本人の経験・採用済みM_B・現在観測が探索行動をどう変えるかを短い実行時間で観察する。Pythonの仮想Worldと既存探索Runtimeを同一プロセスで接続し、p5を実験者用の再生表示に使う。速度倍率の保証値は実測するまで置かない。

迷子、停滞、未達、枯渇、行動差が出ない結果も保存する。採取成功や探索効率向上を実装完了の条件にしない。個体混線、未来情報の漏洩、二重実行など結果の意味を壊す不具合は検査する。

## 現在の資産と接続先

| 資産 | 利用方針 |
| --- | --- |
| `runtime/landmark_return_campaign.py` / ReturnCampaign | configure・observe・resultの既存入口を直接呼ぶ。初版は3個体 |
| `runtime/landmark_day_cycle.py` | 64秒の仮想日、探索・帰還・夜間の既存区分を維持 |
| movement terrain / steering / current_harvest_state | 既存判断を再利用。World移植と同時に係数・旋回規則を変えない |
| 採取Experience→relation採用→M_B→model field | 実際の採取結果から既存経路を通す。学習済みモデルを成功用に注入しない |
| `gui-p5/` | 既存表示を残し、軽量Worldの再生ビューを追加する候補 |
| Luanti | 有限観測・身体結果の契約確認と、節目の移植確認に残す |

現在の夜間wait/reviewをcanonical SleepConsolidationやT1接続済みとは扱わない。rest、internal_reactivation、SOC/NERV等はReturnCampaignに一括統合された前提にしない。個別に接続状況を確認する。

## 初版World

- 水平2D平面。移動距離・速度・旋回角の単位を既存adapterへ明示変換する。Luantiの3D斜面、重力、段差、一般物理は再現しない。
- 障害物、粗い外観の目印、有限資源8地点・各12単位、拠点と見えやすい塔。自然地形風の配置はseed付きで生成するが、地形ラベルから食料位置を教えない。
- 初版はA/B/Cの3個体。World資源は共有、Experience・M_B・所持品・操作権限は個体別。
- 食料の識別に使う既存teaching条件を維持し、木や資源場所を初期知識として教えない。
- 視野、距離帯、粗い方向、遮蔽、coverageを計算する。塔の遠方可視性は高さ属性による限定規則として契約化し、全域可視にはしない。
- 観測された採取可能量の有無と未観測を分離。枯渇はWorld状態からセンサーを経て本人に届く。初版は再生産なし。
- 帰還は観測目印基準。完全座標、最短経路、逆走テープ、自動転送は与えない。帰還未達ならその場で夜を迎える。
- 移動中の衝突を経路上で検査し、終点だけの判定による障害物すり抜けを避ける。初版の個体間衝突規則はLW-0で固定し、社会性とは呼ばない。

## 時刻と作用の順序

仮想時計は整数マイクロ秒。描画フレームやHTTP、壁時計に依存させない。センサーと判断の仮想周期は既存契約に合わせ、数値をLW-0で一覧化する。次の取得・作用完了・日相境界まで時計を進め、画面非表示でも同じ系列を生成する。

同一時刻ではWorld作用完了→有限観測の確定→各個体Runtime判断→次の身体操作登録の順序を固定する。同時採取競合はWorld側の再現可能な順序で解決し、失敗も実結果として返す。順序はログへ残し、個体優劣と混同しない。操作ID単位で作用は一度だけ。遅延・損失の故障注入は初版の高速基準実験から外し、直接呼出しを実ネットワーク検証とは扱わない。

## 情報境界と保存

World内部の座標・資源ID・在庫・完全地図は実験者側だけが持つ。adapterが既存packetへ有限観測を投影する。既存body correspondenceで認めた本人の移動結果は維持し、他対象の真値を紛れ込ませない。未知領域や未実装センサーをCOMPLETEな空観測として偽装しない。初版は探索に必要な視覚と身体結果を対象とし、聴覚・OBS-v1全機能の再現は主張しない。

ログは初期World/seed/版、操作と結果、観測、学習・M_B変更参照、日次要約を増分保存する。毎stepの全Runtime snapshotを連結しない。完了しなくても最後の確定記録まで読める形式にする。Runtime内部に残る履歴容量は別途測定し、出力形式変更だけで長期メモリ問題が解決したとはしない。

p5は記録を読み取る。全景には「実験者用」と表示し、個体視点ではその時点の取得済み情報だけを表示する。描画速度変更は仮想実験の判断を変えない。Runtimeの採用M_B、現在目的、選択理由を参照付きで表示する。HはLW-4実装前に架空の値を表示しない。

## 比較と受入

1. 小さな確定Worldで観測遮蔽・枯渇・移動衝突・同時採取・二重操作防止を確認。
2. 同seed/同設定の再実行で離散行動・結果が一致し、表示ON/OFFで変わらないことを確認。
3. 3個体・3日を通し、帰還失敗も含む日次ログと再生を確認。
4. 事前固定seed（初回20260928）で最大30日、全個体合計3回の資源持帰りで停止。持帰りは新たな採取由来の資源を拠点へ届けた単位で数え、所持継続や空帰還を加算しない。
5. disabled/enabledを同じ初期Worldで比較。採用M_Bが0なら「学習効果なし」と断定せず、適用機会なしと記録する。行動分岐後の観測は同一とは限らない。
6. 採取数・持帰り・未達・訪問範囲・停止理由・モデル形成/適用回数・処理時間・ログ量を保存。改善しない結果も完了として報告する。

## H接続の次契約

目標のB、比較するF/F'、未解消分の算出を定める。未達フラグを毎描画frame加算しない。探索の一区切りと取得範囲を出典にする。方法を切り替えても食料未確保なら目標側Hを自動消去せず、日付変更も解消の証拠にしない。減衰と解消は区別する。

θ超過で何を検査対象にするか、どの候補へ変更できるかを有限に定める。単なる行動切替をcanonical T1/M_Δ実装と呼ばず、その入口・権限・採用手順を確認する。これはWorld差し替えとは別の実験変更として実施する。

## 停止境界

初版はLuanti互換エンジンではなく、同じ探索Runtimeを用いる別World。3D物理、一般音響、任意通信障害、大規模個体群、神経・社会系の一括統合は必須にしない。研究対象は経験から行動への循環であり、成功率を上げるためのWorld真値利用や経路誘導は追加しない。
