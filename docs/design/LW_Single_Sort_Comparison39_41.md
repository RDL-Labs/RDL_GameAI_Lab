## 比較条件

入力と38/40日目保存状態は `human-wait-fresh60-every2-20261111`。
変更後も凍結ソースに当該2行だけを変更し、現在の他の変更を混ぜない。
`profile_human_only.jl` の `single_sort` モードで、512 tickウォームアップ後に保存状態を読み直し、1日を計測。
CPUサンプリング5ms、日末保存あり。元長期実験の39/41日目は保存なしなので元実時間とは直接比較しない。
比較用変更前は変更後2日の終了後に再実行し、並列によるCPU競合を避ける。

前回プロファイルの173.3/155.4秒に対して今回変更後は88.0/88.2秒だったが、変更対象外の保存・睡眠整理も大きく短縮した。その差を二重ソート削減の成果と扱わず、今回の変更前再計測を比較対象にする。

日内イベントは、変更後2日とも前回プロファイルとファイルハッシュが一致。
最終比較ではさらにactions・physical・home_activity・観測/判断/集中/睡眠/停止のtick数を照合する。
速度は各条件1回の測定であり、反復ベンチマークによる確定値ではない。
