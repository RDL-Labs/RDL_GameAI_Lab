# Gradient continuation experiment

2026-11-03. scene.gradient_roll opt-in (default false). A previously selected simple step_* walk/run may continue until confirmation time. The heading is held in the orientation frame and converted back to relative bearing; existing local structure repulsion and physical collision still run. No new destination, world coordinate target or correct route is injected. Complex MB route/chunk transitions are NOT enrolled; their normal checks remain.

Interval begins at one second, doubles up to eight on due confirmation, resets on changed heading >15 degrees, goal/phase change, stopped movement, H increase, missing receipt or intervening non-movement. Unknown goal distance caps at two seconds. Known observed target caps at quarter of time-to-contact, minimum one tick. Near targets trigger confirmation before pickup/arrival. Food/body/safety/social priorities are evaluated before continuation. The existing singleton method binding keeps per-operation parent evidence and energy accounting; skipping candidate enumeration is not reported as probabilistic reselection. Current chooser still binds a singleton trial and consumes RNG.

This first implementation skips candidate generation/retrieval and competitive scoring on continuation ticks. It does NOT yet skip shared observation, integration or result learning. Existing observation/physiology/receipt code stays current. Consequently this is not a claim of a complete minimal-physics tick. Continuation state and reason counters are in mb_map.gradient_roll and included in checkpoints.

## Confirmation retains intent (2026-11-03)

A due check no longer returns nothing merely because its timer expired. It checks accumulated proprioceptive progress projected onto the enrolled heading, requiring at least 25% of the estimated displacement since the previous check (initial nominal action speed, then previous confirmed actual speed). H increase still interrupts; this is not a guarantee that the ultimate goal is achieved. A successful check preserves heading/method, doubles the interval up to eight, and schedules the next check with the existing time-to-contact cap. Nearby targets shorten confirmation to one second without forcing reselection; actual interaction range <=1.25 returns control to ordinary arrival/pickup logic. Stopping, gap, purpose change, H increase or progress shortfall still release continuation. Counters confirmed/reconsidered separate confirmation from candidate reopening. The 25% tolerance is an experimental local-motion tolerance; parent forecasting remains authoritative for wider goal progress.

Fresh ten-day experiment: outputs/gradient-confirm-four-10d-20261103. Same conditions as previous ten-day gradient roll, no checkpoint migration. Unit checks: 26 assertions, including ten consecutive steps without re-enrollment, near-but-not-arrived, arrival, stop, sideways progress and H increase.

## Goal-distance correction (2026-11-03)

The heading-progress version allowed unbounded travel away from useful locations: trial gradient-confirm-four-10d ended with three zero reserves. Its accounting PASS was not behavioral validation.

Continuation now enrolls only an observed target with forward/right coordinates and an already selected simple step_* whose question is target_nearer. Unknown-target exploration is not enrolled. The observed egocentric target is retained and advanced with movement/turn receipts; steering uses that retained goal rather than an unrelated latest food target. Fresh observations geometrically compatible with the prediction may anchor it (provisional, no object identity oracle); inconsistent observations reopen selection. Distance reduction over the confirmation window replaces heading projection. Expected reduction is bounded by distance to arrival; the 25% tolerance remains experimental. Near distance accelerates checking, estimated arrival returns to normal interaction checks, and absence of reobservation beyond 8 seconds or uncertainty >1 releases continuation. Thus odometry alone cannot approve infinite straight travel. No unseen world target coordinates are consumed.

Tests gradient_roll_checks.jl: 27 assertions covering approach, increasing distance, sideways movement, unknown target, rotation, lost-target expiry, near/arrival and contradictory observations. Fresh trial outputs/gradient-distance-four-10d-20261103, same four actors and finite340 food; no state carried from failed behavioral experiment. Shared sensing still occurs every tick; savings apply to candidate expansion only.

## Fixed distance-30 experiment

scene.gradient_direction_distance=30 enables direction mode for estimated target distance >30 LW units; <=30 uses relative-position approach. Default 0 preserves the preceding distance-based implementation. Far bearing is refreshed at confirmation and otherwise held in orientation coordinates. Local steering respects that bearing (does not silently replace it with per-tick target bearing), while obstacle repulsion remains. Distance progress, H, uncertainty and limited blind continuation still gate both modes. This is a control approximation, not a claim that distant distance is measured precisely or a human perceptual threshold. direction_ticks/approach_ticks/mode_switches report actual exposure. Only previously selected simple goal-directed steps are enrolled; no hidden goal is inserted for unknown exploration. Fresh trial outputs/gradient-distance30-four-10d-20261103, same four actors/seed/finite340 food. Tests 32 assertions.
