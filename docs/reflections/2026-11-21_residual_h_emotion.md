## 検討した考え方

### 局所の由来と、他の出来事への影響は両立する

Hの由来は特定のMB・目的・見込みに属していても、作用までそのMBだけに閉じるとは限らない。
援助を断られた経験のMBを使うことで不機嫌になり、その直後の無関係な出来事への対応にも影響が残る、という構成を考えた。
親MBの切替と同時に影響が消える必要はない。

### 今の問いも本人が評価する

過去のHを新しい問いへそのままコピーするだけではなく、現在の複数MBの拘束から
「どうするべきか」を評価する。「渡したいが自分の確保も不安」など、現在の候補で要求や見込みを満たせなければHが上がり、候補を広げるという解釈が候補になった。
候補が複数あること自体をH発生条件にする案ではない。

### 親MBが変わっても残留し、減衰する

候補として次を区別した。

| 要素 | 想定する役割 |
| --- | --- |
| MB自身のH | その目的・関係に残る未解決分 |
| MBの活性度 | 現在どれだけ使われ、想起されているか |
| 残留H／個体の持続状態 | MBの作用が親切替後にも残り、時間とともに弱まる影響 |

これは別変数を必ず追加する決定ではない。MBの活性が徐々に下がるだけで表現できる可能性も残す。
問題から離れると落ち着き、再び同じMBを呼び出すと高まる形を想定した。
出来事の終了、問題の解決、影響の冷却を同じ時刻にする必要はない。
また、作用の減衰と、未解決の記憶そのものの消去は区別する。

## 再検討時の問い

- MBのH、活性、個体の残留状態をどこまで分けるか。二重計上をどう防ぐか。
- 同じHを毎tick加算して膨張させず、作用と減衰をどう表すか。
- 減衰は時間、解決、新たな経験、身体状態の何に依存するか。
- 残留の作用先を、注意・想起・見積もり・候補拡張・選択のどこに置くか。
- Hによる候補拡張と、確率を無差別に平坦化することをどう区別するか。
- 満たされた経験や上機嫌をどう表すか。非負の未解決量Hを減らすことだけで喜びを表せるとは限らない。
- 援助要求の失敗が提供判断に波及する場合、どの関係を通じて作用したのか追跡できるか。
- 計算負荷と説明可能性を保ち、固定の感情ラベルによる強制行動にしないで済むか。

再開するなら、未解決の出来事 → 親MB切替 → 無関係な相手との判断 → 時間経過 → 元のMBの再想起、という局所場面から検討する。
更新式・係数・実験日程は未決定。現在の共有Hの接続問題と、将来の感情モデルは別の課題として保持する。
