# 目的に関係するMBの実効質量と行動の安定

2026-10-30。状態：設計仮説・実装保留。

**現在の目的との関係が強いMBほど、選択へ及ぼす実効的な「質量」が増える。** ドーパミンと計画・報酬についての対話から、関係拘束による行動の持続を重力や河道の比喩で捉える案。

質量は選択への寄与を表す比喩であり、物理的な質量、ドーパミン濃度、既存コードの新しい保存変数を意味しない。ここではGameAIのモデルを考察し、RDL Coreの定義は変更しない。

## 目的から途中のMBへ作用する関係

帰還が目的なら、拠点だけでなく、拠点につながる目印、経路への合流地点、過去に成功した経路も選ばれやすくなる。未来の到着・休息の価値が、途中の関係を通じて現在の候補へ作用するという見方である。

同じ木でも、帰還中には「拠点への目印」、空腹時には「果実のある場所」という関係が強く作用し得る。MB一つに目的と無関係な恒久的質量を割り当てるだけでは、この違いを表せない。関係は個体の観測・経験・予測から呼び出す。世界側の正解座標や未観測の接続を与えず、誤認と修正を許す。

## 経験で残る強さと一時的な重み付け

| 要素 | この案での役割 |
| --- | --- |
| 経験による関係拘束 | 目的が切り替わっても保持される、候補を支持する根拠 |
| 現在の目的と身体状態 | どの利益・費用・関係が今の選択に重要かを変える |
| ドーパミンに相当する調節 | 関係が選択や学習へ及ぼす作用を、その時の状態に応じて変える |
| 受け手の応答特性 | 同じ調節信号に対して、どの関係・処理がどれだけ反応するかを変える |
| 一時作用の減衰 | 現在の調節を弱める。経験した関係の消去とは別に扱う |
| 結果による学習 | 見積もりと結果を照合し、次回以降に使う関係を更新する |

「今だけ強く引かれる」と「経験により引かれやすい経路が形成された」を分ける。目的が変われば一時的な重み付けは変わるが、帰還に役立った経験まで失う必要はない。どのMBが目的につながるかは関係網が持ち、調節信号はその効き方を変える、という分担を検討する。

選ばれたこと自体を成功の証拠にすると、選択と増強だけで閉じた循環になる。関係の更新には結果の証拠を使い、同じ経験を複数の経路から呼び出しただけで重複加算しない。「質量が増す」は、経験が常に一方向へ増強されるという意味でもない。

## 計画による安定とHによる再検討

計画では、将来の目的達成を見積もり、その途中の行動にも継続する価値が生まれる。強い関係が繰り返し選ばれることで、結果として慣性のような持続が見える構成を目指す。

Hは見積もりから吸収できずに残る差として保つ。目的の重みが強いことを理由にHを消したり、予測が外れても同じ候補を固定したりしない。見積もりの範囲内の未到着と、見積もりからの逸脱を区別し、後者を候補拡張・局所修正・目的の再検討へつなぐ。

Hによる確率の平坦化を調節する案と、目的に関連した候補の寄与を増す案は、別の操作として比較する。全候補の選択を鋭くするだけでは、目的との関連を扱ったことにならない。ρは何をどこまで区別するか、感度は捉えた差への反応として引き続き分ける。

## 神経研究から参照する範囲

以下は生物研究の観測であり、MBの質量モデルを直接実証したものではない。

- [Mohebi et al., 2019](https://pubmed.ncbi.nlm.nih.gov/31118513/)：ラットの同じ意思決定課題で、報酬を予告する手掛かりはドーパミン細胞の発火と側坐核での放出を増やした。一方、変化する報酬期待に伴う放出には、対応する発火変化がない場合もあった。学習信号・現在の動機付け・局所の放出を単一量へまとめないための参考。
- [Yagishita et al., 2014](https://pubmed.ncbi.nlm.nih.gov/25258080/)：マウス脳切片で、グルタミン酸入力後の限られた時間内のドーパミン入力が樹状突起スパインの拡大を促した。一時的な信号と、それによる構造更新を分ける参考。人の計画や記憶全体を説明した実験ではない。
- [Volkow et al., 2006](https://pmc.ncbi.nlm.nih.gov/articles/PMC6674019/)：コカイン依存の18人で、薬物が提供されないと知っていても、関連映像による渇望と線条体のドーパミン指標の変化が相関した。現在の入手見通しと、学習された手掛かりが誘発する欲求を区別する材料。依存全般の原因を示す因果実験ではない。

依存についての設計上の比喩は、「特定の報酬や苦痛軽減につながる関係が、他の目的・不利益を踏まえても選ばれ続ける状態」とする。アルコール依存では離脱時の不快さを軽減しようとする行動も重要とされるため、予想される快さだけを動機としない。[NIAAAの解説](https://www.niaaa.nih.gov/health-professionals-communities/core-resource-on-alcohol/neuroscience-brain-addiction-and-recovery)

回収が強いほど退屈になる、ドーパミンが多いほど満足する、強いMBがあるほど依存である、という対応は置かない。既存の[神経パラメーター設計図](../design/RDL_GameAI_神経パラメーター設計図.md)にあるD1〜D4等の役割名も、GameAI用の操作的近似であり、この案の生物学的根拠として用いない。

## 既存の仕組みとの接続候補

[目的関連の観測目印](../design/LW_Goal_Related_Cues.md)には、成功経路と目的の関係を通常の形状目印候補へ投影する有限実装がある。今回の案はそれを考える共通の見方になり得るが、任意MBへの適用、多段の関係伝播、動的な神経調節の完成を意味しない。既存の目的加点と同じ寄与を二重に足さない設計が必要になる。

[MB強化の非線形性](../design/RDL_GameAI_MB_Reinforcement_Nonlinearity.md)の証拠と選択寄与の分離、[ρと感度と経験](../design/RDL_GameAI_Rho_Sensitivity_Experience.md)、[合成的感情仮説](../design/RDL_GameAI_Compositional_Emotion_Hypothesis.md)とも照合する。余裕・退屈と目的外行動については、[既存の課題と実験記録](../design/LW_Portable_Items.md)を引き継ぐ。

## 次に確かめる問い

- 重みをどの関係単位で保持・評価するか。親目的、経路、目印、食料、他者へ共通化できるか。
- 目的が切り替わると適切な関係が強まり、元の目的の経験も保持されるか。
- 期待どおりの途中経過では安定し、誤認や費用超過では修正・切り替えが起きるか。
- 関係の多段伝播で循環的な自己増幅を避け、弱い候補を試す余地と計算予算を保てるか。
- 一時作用の強さ・減衰・受け手の違いを変えた時、学習結果と現在の選択への効果を分離して観測できるか。

生活基盤の安定を優先し、現段階では式・係数・実装時期を確定しない。実装へ進む際は既存方式との比較条件を別途定め、目的達成、身体維持、修正・切り替え、選択の偏り、処理時間を確認する。
