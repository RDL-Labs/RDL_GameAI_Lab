```bash
python -m unittest -v tests.test_experience_godot.GodotExperienceTests.test_long_life_crosses_sleep_dynamic_mb_and_next_day_autonomy
```

Requires Godot 4.7.x through `GODOT_BIN`.

## Result

One Godot Workbench process retained the same World provider across:

```text
two day-one Food cycles
-> danger / flee / resume
-> bounded Sleep
-> shadow candidate
-> explicit Dynamic M_B cutover
-> day-two cue-free autonomous Food completion
```

The Runtime retained two real assisted success records. Day-two autonomy used
`learned_low_stock_relation`; it did not manufacture a third cue-bound success.
Food-Safety and Sleep were selected only through explicit mutually exclusive
Godot body flags.
