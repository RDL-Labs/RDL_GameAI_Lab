# LW：日跨ぎ探索Hと遠方候補

基準a7f1de2、2026-10-07。明示opt-in `exploration_horizon_enabled`。
既存の食料目標Hは既に日跨ぎ保存されるが、日単位の比較が不完全観測等でdeferになり得る。
その規則を緩めず、新たな局所探索M_Bに「実行済み探索操作8件で採取したか」という問いを置く。
これはGameAI局所モデルであり、canonical Core H/T1への自動昇格ではない。

## 規則

本人のlinkedな身体結果だけを参照する。探索phaseでmoved/turned/waited/blockedを8件実行して
採取なしならE=1、H+1（上限32）。夜間/帰還/危険対処では加算しない。
採取成功でHと途中件数を0へ戻す。再送は同operationを再計数しない。
姿勢対応不成立・期限切れ等は加算しない。H・途中件数を朝にリセットしない。
夜間休息やSleepだけでは食料確保を満たしたことにしない。

H>=2で、現在観測したmid/farの目印角域（幅45度以下）から最大5方向へ提案。
近傍の地面が取得済み・高低差0.5以内・出力制限なしの方向だけを使う。
角域中心から候補方向まで22.5度以内。未観測方向やWorld座標は使わない。
寄与はfar=2+min(4,H/2)、mid=2+0.35*min(4,H/2)。これは初期使用規則であり学習済み最適値ではない。
各方向方法の既存Hペナルティ、energy/Sleep/body/bundle/trail評価はその後も作用する。
帰還・夜間・方位取得・採取・休憩等の保護条件と、見えているFoodへの接近は優先する。
回転後は既存の実測回転→前方取得確認→一歩の経路を使用する。
候補は相対方向の方法であり、同一物体追跡ではない。日跨ぎ保持するのはHで、
遠方目印の古い方向を無検査に翌日実行しない。長期目標追跡の完成は主張しない。
