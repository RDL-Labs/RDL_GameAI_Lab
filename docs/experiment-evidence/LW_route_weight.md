# 経験による経路候補の相対的な太さ

2026-09-29。`angular-relation-movement-field-v2` / `experience-relative-route-weight-v1`。
関係場モードを有効にした場合だけ適用。旧directional単独方式は変更しない。

## 有限規則

現在の目的に合い、現在観測との角度関係が比較可能で、当日の失敗候補に入っていない経路を対象とする。

- strength = (1 + 0.25 × support) / (1 + H)
- share = strength / 比較可能候補のstrength合計
- field_weight = min(1, strength / 3) × share

supportは従来どおり実配送による方向別支持、上限8。Hは経路の局所的な不成功記録、上限32。Core Hの新しい実装ではない。数値は有限実験の固定規則であり最適値ではない。

新しい候補の成功支持が増えると、同時に比較可能な旧候補のshareは下がる。旧候補の保存支持・出典・Hは競争によって書き換えない。H増加は単独候補でもfield_weightを下げる。未使用時間・経路の年齢は入力にしない。未使用＝失敗とはしない。

関係場モードのH>=2による恒久的な候補除外を取り除く。ただし当日の失敗候補は引き続き除外する。翌日以降、観測条件が合えば弱い候補として再び選べる。Hは日付変更でリセットしない。既存の実配送による成功再支持時にはHが0へ戻る。

選択はstrength順。現在ownerが比較可能な間は保持し、新候補が強まっただけで実行中に切り替えない。次の選択機会で強い候補を優先する。実際の場へ入れるのは選ばれたownerの関係寄与だけで、全経路のベクトルを一斉合成する機能ではない。現行のterrain/直接目標との合成、旋回後一歩、現在Food/塔優先、物理的除外、日48操作は維持する。

比較不能な候補は分母へ入れない。代替候補が見えなくなれば旧候補の相対shareは再び大きくなるが、失敗Hによる絶対的な弱まりは残る。support0の逆順案は未検証候補のままで、成功したとは記録しない。

## 境界

「より良い」はここでは成功支持と局所Hだけ。経路長・所要時間・体力効率の優劣は学習しない。同じ目的内でも起点・終点の厳密な同一性は保証せず、現在比較可能な粗い経路仮説同士の競争である。経路容量16、支持飽和、未使用時の鮮度判定、明示的な経路忘却は変更しない。
