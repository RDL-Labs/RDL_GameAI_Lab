# 声による救助と救助者の行動不能

2026-10-04。[契約](../experiment-contracts/LW_voice_rescue.md)。
軽量Python World、4条件×12秒、各2個体を更新。Luanti/Godotではない。
初期の被救助者reserve=0は実験設定であり、長期飢餓から生成したものではない。

| 条件 | 給食 | 終了時歩行不能 |
| --- | ---: | --- |
| 距離2、救助者reserve=100、食料1 | 1 | なし |
| 同配置、救助者reserve=0.15 | 0 | 救助者と被救助者 |
| 距離9、受信圏外 | 0 | 被救助者 |
| 距離2、途中にsolid遮蔽物 | 0 | 被救助者 |

低reserve条件は救助者が実際に歩行して消耗した後、自身も救援発声へ移る。
成功条件では食料を1個消費し、被救助者が既存身体規則上歩行可能になる。
帰還完了やその後の生存までは検証していない。
