# LW 観察室

現行Julia LWの保存状態から再実行した動きを、ブラウザで見る2DリプレイGUI。
Python、Webサーバー、外部ライブラリは不要。ライブ実行の制御画面ではない。

## 開く

`index.html`をブラウザで開き、`replay.json`を「記録を開く」またはドラッグで読み込む。
実データ入り単独HTMLも生成できる（Node.js使用）：

```text
node gui-p5/lw-observer/bundle.cjs replay.json output.html
```

再生・停止、速度変更、時刻スライダー、前後の記録、個体選択、イベントへの移動に対応。
地図はドラッグで移動、ホイールで拡大。身体、所持品、個人備蓄、目的、H、記録済み候補を表示する。

## 記録生成（実験用）

```text
julia --startup-file=no --threads=1 --project=. experiments/body_macronutrients/export_observer.jl BASE_RUN CHECKPOINT FRESH_OUTPUT [FINAL_DAY]
```

元実験・チェックポイントは保持し、新規出力先へ現行ソースを凍結して観察フックを付ける。
既存状態を現行コードへ明示的に移行する実験用ツールであり、任意の古い状態との互換性は保証しない。
コードハッシュの差と原本SHA256はmigration.jsonへ記録。状態フィールド集合も検査する。
10秒ごとの位置・身体・残量と既存イベント・勾配ログを保存する。
全フレームをメモリにも保持するため、まず1日など短い区間で使う。

## 表示の意味

- 地図・残量は世界側の実状態。個体が見た／知っている情報ではない。
- 点間の移動は表示上の直線補間。10秒間の実際の軌道や障害物回避を再現する保証はない。補間はOFFにできる。
- 身体や在庫は直前の記録値。判断欄も時刻付きの直近ログであり、現在の全思考ではない。
- 候補詳細は既存勾配記録がある判断のみ。未収録の判断は説明しない。
- 景観は概略表示。物理形状・視野・ρの正確な描画ではない。

```text
node tests/test_lw_observer.cjs [replay.json]
```

今回の実行時間は性能比較値として使わない。

## 取引追跡とズーム

取引・援助のイベント選択、前後移動、双方を収める追従カメラ、個体追従、拡大縮小ボタンを追加。
取引IDのない既存ログを推測で同一交渉に結合しない。受諾のtargetが空の場合はmethodの明示対象のみ読む。
双方の同時刻の判断記録を展開できる。発話・ジェスチャー・解釈は存在するフィールドだけ表示し、未収録なら明示する。
24日目データには言語の詳細・身体の向きはないため、吹き出し・向き・翻訳・MB差分は未対応。
操作は模擬DOMで検査。実ブラウザの描画確認は未実施。認知・ρ・実行モデルは変更しない。
