# 日暮れ前の恐怖・3日動作試験

2026-10-26。普通の拠点、豊かな世界特徴、固定個体感度、初日観察、拠点休息報酬・埋め込み休息MBを有効にした条件で、`--night-fear on`を追加。比較元は `embedded_rest_report.md`。入力はnight_fear以外同一。既定値はoff。

## 実装と検査

帰還見積もり＋不確実性の余裕と日没までの時間を比較し、残差から恐怖Hの目標を作る。Hは目標へ徐々に追随し、同じ残差の毎秒加算はしない。恐怖は帰還の確率的な追加要求とhomeのMB候補探索へ接続する。身体維持の食料要求、初日観察、安全対応を保持。詳細は `docs/design/LW_Anticipatory_Night_Fear.md`。

専用検査21、層依存495、LW方策5項目PASS。統合試験の道19、配置13、生活整合16項目PASS。親MB・経路・帰還見積もり・恐怖の保存結果監査もPASS。CIに専用検査を追加したが、ここでの結果はローカル実行。試験スナップショットと最終runtimeのday/integrated/night_fearを照合済み（観測フックのみ除外）。
