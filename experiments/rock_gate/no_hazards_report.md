# 危険OFFの基準試験

`--hazards off`で既存config.hazardsをoffにするrunner指定を追加。既定値は変更しない。危険源の観測と危険回避を無効にし、帰還・食料取得・拠点生活を切り分ける。

3日試験をoutputs/no-hazards-ordinary-3d-20261026で実行。最新の安全地帯・退避候補実装、近場有限食料、日次持ち帰り目標を使用。夜間恐怖は比較のためONのまま。したがって外の危険源による退避はないが、日暮れ前の帰還要求は残る。危険OFFのため拠点退避候補は作動しない。
