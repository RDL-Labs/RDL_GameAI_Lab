# 拠点休息の暫定報酬・3日試験（2026-10-26）

ユーザー指定の「拠点で休むことを高報酬」に対応し、撤去可能な設定経路として実装。`--home-rest-reward on`で有効、既定off。拠点を観測でき距離1.25以内で60操作秒連続してrestを実行した時に報酬5。現行の予測差付き到着報酬0.25〜1.75より高い。実際の回復量とは独立した実験上の固定値。

1個体1日1回まで。同日中の離脱・再入場でも上限を解除しない。休息中断は連続時間をリセットし、拠点外では到着記録との接続を解除。移動を伴って成立した、その訪問の最初の帰還に寄与した方法・保存された成功経路/経験束へ遅延加点する。成功回数は増やさない。対応経路がなければ休息記録だけ残し、架空の経路は作らない。
