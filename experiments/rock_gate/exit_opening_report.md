# 狭い拠点からの初回外出を優先する実験

2026-10-23。帰還の解決と分け、最初の3,000ステップ（LW時計の3,000秒）以内に外へ出られる割合と初回時刻を評価する。入口の幅・岩・光源は変更しない。

## 通常の観測・選択への追加

`rho_profile=coarse|fine` と `rho_openings=on` の場合、目的対象がまだ見えていない探索で次を使う。食料探索・帰還で同じ規則とし、「拠点の出口」の専用座標や方角は個体に渡さない。rho全体は従来どおり既定off、rhoを有効にした場合のopeningsは既定on。`--rho-openings off`で初版と比較できる。

1. 同一観測の障害rayから、両側のhitの間にclearがあり、1以上の奥行き差がある方向を有限の通路仮説として作る。未知・視野の端・全てclearの開放空間は隙間候補にしない。中央方向は実際に観測したrayから選ぶ。隙間の幅・身体の通行可能性は断定しない。
2. 現在の移動評価で近い方向が実行可能な場合だけ歩行候補を追加する。評価質問は既存の `target_observed`。歩いたことだけで目的成功・報酬とはしない。
3. 歩行・走行候補に現在の見通しと反発から有限の観測log priorを与える。見通し方向との整合は最大2.5、反発は最大2の減点。未解決Hで学習側の選択を広げても、現在の視覚情報を同時にほぼ消してしまわないため、温度適用後に加える。

確率は `softmax((既存priority + 学習報酬 - 失敗反発 - 候補Hペナルティ) / 温度 + 観測log prior)`。新しい観測priorがない候補・旧条件では従来式と同じ。有限な候補の選択確率は0にしない。直前に選んだ方向の優遇や方向固定は追加しない。現在の観測priorはHの解消・学習報酬・確定した通行可能性とは別物。

既存の選択後ポテンシャル補正と物理実行可否検査は残す。局所補正が拒否されれば既存の実行可能な離散行動へ戻る。入口が必ず発見できる、通過できるという保証はない。

## 評価方法と初期診断

[exit_probe.jl](exit_probe.jl)がソースsnapshotへ読み取り用observerを追加し、3,000tick後に専用例外で停止する。Worldの拠点中心と半径5を使うのはobserverの初回外出判定だけ。時計・夜の開始時刻・目的判定を変更しない。1日完走・帰還・生活保存則の長期試験ではない。

同一の狭い入口入力で、粗ρの追加前後をseedごとに比較する。各runを初期状態から開始し、先に行ったrunの記憶を引き継がない。sourceとspecは各出力に保存する。

候補追加のみの初期診断（seed 20261005–20261007）では、延べ9体中4体から7体が時間内に外出した。seed 20261006では追加後も2体が未外出。親Hが32なら温度17となり、priority差が弱まるため、最終版では現在の観測priorも追加した。この3seedは調整に使用した条件として扱い、20261008–20261010も追加で確認する。

再現コマンド例（入力は初版の狭い入口spec。出力先は新規）：

```powershell
julia --startup-file=no --project=. experiments/julia_migration/lw_integrated/rho_opening_checks.jl
julia --startup-file=no --project=. experiments/rock_gate/exit_probe.jl outputs/rock-gate-exit-affordance-20261023 experiments/rock_gate/evidence/exit_opening/input.json 20261005,20261006,20261007,20261008,20261009,20261010
```

`rho_opening_checks.jl`は構造・地図56項目、隙間候補18項目、観測priorとH・報酬分離9項目PASS。左右対称性の検査では地面も対称にして比較する。

## 最終版の初回外出

各欄はA / B / Cの初回外出tick。`—`は3,000tickまで未外出であり、失敗時刻0として平均には入れない。

| --- | --- | --- |
| 20261005 | 1147 / 2068 / 507 | 110 / 263 / 291 |
| 20261006 | — / — / — | 213 / 155 / 135 |
| 20261007 | — / — / 1616 | 275 / 112 / 214 |
| 20261008（追加確認） | — / — / 2955 | 153 / 191 / 166 |
| 20261009（追加確認） | — / — / — | 464 / 323 / 281 |
| 20261010（追加確認） | — / — / — | 308 / 78 / 473 |

時間内の外出は **5/18 → 18/18**。改善後の初回外出中央値213.5tick、範囲78–473tick。追加確認した3seedも9体全員が外出。入口形状・初期配置は共通で、seedは選択乱数を変える。異なる地形・開始配置への一般化や必ず出られることを示す結果ではない。

初回外出を主指標にしたため、帰還成功を改善判定に使わない。observerの3,000tick停止は意図した試験終了で、アプリのクラッシュではない。速度計測は初回コンパイルの有無と外出後の行動差を含むため、評価器単独の速度比として扱わない。

確率選択116項目・H報酬/失敗43項目の既存検査もPASS。候補生成と現在の観測priorを追加しても、旧条件の確率・報酬・失敗履歴の性質は維持。

## 通常の1日実行

seed 20261005、粗ρ＋openings onで通常の岩壁実験も1日完走。地形33項目・生活保存則7項目PASS。初回外出はA110 / B263 / C291で短期probeと一致し、observerの早期終了が外出結果を作っていないことを確認した。既存の共有移動場34項目もPASS。

実行時間66.70秒（コンパイル込み）、消費食料6。3体とも外へ出たが、1日中の入場は0回であり帰還は解決していない。外出が容易になったことと帰還性能を区別する。
