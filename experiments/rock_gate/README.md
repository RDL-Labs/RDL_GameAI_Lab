## 現在の配置：拠点内を人工道化

岩の内縁（拠点中心から半径4.2）にセル全体が収まる地面を人工道にする。
既存の塔などの障害物に重なるセルは除外する。入口の外へは延長しない。
広い入口・狭い入口とも同じ内側の配置、寿命3,650日。`run.jl` の既定配置に反映済み。
`--prepare-only` を末尾に付けると、配置検査とwide/narrowの入力保存だけを実行する。
以下では現在の配置と、人工道追加前の過去の3日結果を区別して記録する。

入口東側の内側・外側に、松明を模した橙色の柱を1本ずつ追加した（各半径0.3、高さ2）。
既存の色・方位による目印観測と経路記憶を利用する。「入口」という意味や位置は
個体に直接渡さない。内側・外側の代表位置から見えることと中央の通行を検査する。
現段階では色付きの目印であり、発光・夜間照明・燃料・消火のモデルは含まない。
以前の結果と配置図にはこの柱も含まれていない。

## 配置

- 拠点(0,6)を中心に、半径5の円周上へ15度間隔で岩を並べる。
- 岩の半径0.8、高さ3、gray、solid。登れる低障害ではなく既存の通常障害として追加。
- 南側だけを開ける。狭い入口は岩1個分を省き、対向する岩表面間の最小距離約0.988。
- 比較用の広い入口は岩3個分を省き、最小距離3.4。
- 身体の衝突marginは既存の0.2（幅0.4）。狭い口で身体中心が使える幅は約0.588。
- 初期個体3体は囲いの内側。既存の塔、食料、地形、危険物、身体、記憶、帰還判定は維持。
- 21個の岩の広い入口と23個の岩の狭い入口を、それぞれ新しいWorldで3日運転。

[配置図](layout.svg)は拠点周囲だけを表示。外側の地形や危険物は省略。
隣接する岩は重なり、入口以外に隙間を作らない。実際のsegment_hitと身体marginで
入口中央の往復通行、東側の閉鎖、初期位置の岩非重複を検査する。

## 観測・解釈

1秒tickごとの操作後位置から半径5の境界通過を数え、外向き/内向きの両端座標を保存する。
これは境界通過回数で、独立した採取配送成功回数ではない。短い往復で再計数し得る。
位置とreserveは60tickごとにも保存する。既存return_purposeカウンターと区別する。
観測処理はコピーしたsrcの身体更新後に挿入し、AIへのヒント、隠し座標、入口IDを渡さない。

迷うことや帰還に時間がかかること自体は不具合扱いしない。
物理的に通れること、個体が入口を発見して通ること、帰還・補給できることを分けて見る。
3日で戻らない場合も、その後の帰還不能や永久停止を断定しない。
岩は遮蔽と危険物の見え方も変える。入口幅だけの純粋な移動速度比較ではない。
既存の対個体衝突や混雑モデルを新規追加した実験ではない。
