# 新しい世界特徴をLWへ接続した3日試験

2026-10-26。ゼロ残差修正版、固定感度A=.5/B=1/C=2、初日観察・備蓄4、狭い入口、食料への分岐道。run.jlに --world-features on を追加した。新しい色・寸法・食料量を既存観測/物理/採食へ接続。草の遮蔽は生態系側のみで、本試験には含まない。

入口の岩壁半径・高さ、開始位置、道、AI設定は前回と同一。岩壁の色、背景の木/岩の色と寸法、外部食料の初期量は変更した。備蓄は変換後に追加して固定。総初期食料は88→86（在庫を含む）。情報量だけを変えた対照実験ではなく、新仕様の接続試験。

全個体のMB記憶にgreenが入り、既存brown/orange/gray/ochreに加わった。世界特徴が観測・記憶へ届いたことは確認できた。一方、現在のMB場面表現は色・距離帯・30度刻みの相対方位に圧縮され、高さや幅を独立した識別属性として保持しない。サイズは見通し・見え方を通じて作用する。

覚醒・睡眠・経験束からの経路選択は全員0、経路目的達成も0。Bの再入場1回を経路学習の成功とはしない。場面の細分化は増えたが、再利用が改善した証拠はない。容量による入場拒否は0。no_path、goal_mismatch、no_shared_featuresなどが残るため、記憶の分断だけが原因とも断定できない。

「情報が平坦だから難しい」という仮説を支持・否定するには、食料量と通行形状を固定して特徴のみ変える比較と、同等な場面をまとめる表現側の検証が必要。今回だけで新仕様が有利とは判定しない。
