# 帰還経験が経路候補にならない原因の診断

2026-10-25。対象は共通睡眠ONの10日試験（4bc1668の実装）。政策は変更せず、最初の帰還を含む5日を観測フック付きで再実行した。診断用の座標・向きは外部ログだけに保存し、行動選択やMB状態へ戻していない。

## 1. 観測が途切れる：確認

3個体×86400 tick＝259200観測のうち、MB地図へ使えたのは24602（9.49%）。残りはすべてrelation_sceneの一意な色が2種類未満で、mb_sceneがnothingを返した。視覚全体がないという意味ではない。局所的な特徴は見えていても、現在のMB地図の入力要件を満たさない。

| 個体 | 有効観測 | 有効→無効 | 非空の経路記録が消失 |
| --- | ---: | ---: | ---: |
| A | 9157 / 86400 | 3963 | 761 |
| B | 7835 / 86400 | 3386 | 624 |
| C | 7610 / 86400 | 4370 | 1014 |

非空の記録消失2399回はすべて次観測が無効になったケース。目的変更やstatusもリセット条件として存在するが、この標本で非空の記録を消した直接原因は観測不足だった。

### Cの実際の帰還成功

- 76008秒：入口を内側へ通過した直後。観測はochre/nearの1色だけ、MBキーなし。home目的で保持していた1辺の経路記録が0へ消える。
- 76009–76020秒：同じ1色だけの観測が続く。体は拠点へ進んでいるが、地図用の実行記録は残らない。
- 76021秒：拠点到達、homeのHが32→0。経路は空、結果と対応する有効観測もなく、mb_goal_result!はno_bound_observationで終了する。

これは「成功報酬が小さい」のではなく、成功と結び付ける経験が保存されない問題。5日間の正のH解消9件のうち8件は対応観測なし、1件は観測が対応していても経路0辺だった。まとまり形成の2辺条件を満たす事例はない。

## 2. 同じ場所の再認識：分裂と混同の両方を確認

連続する観測で位置が完全に同じなのに、有効キー同士が変わった回数はA430/B442/C724、合計1596。位置と向きの両方が同じ場合のキー変更は0。向きを変えたときの可視特徴の変化が、場所のキーを分けている。

0.5mのセルに60秒以上離れて再訪した場合、有効キーが複数になるセルはA915/990、B816/890、C977/1031。向きも15度区間で揃えた集計でもA356/625、B407/648、C670/984。ただしセル内の位置・角度は完全一致ではないので、この集計単独で誤認識とは断定しない。

逆に、同じキーが初回位置から5m超離れて観測されたものはA137/B130/C146。最大距離はA37.89m/B41.99m/C39.89m。同じキーを場所IDとして扱うには粗い。これはハッシュの衝突ではなく、色・距離帯・量子化した相対角の特徴表現が同じになる現象として解釈する。自宅内外の両方で使われたキーもA2/C3あり、homeラベルの上書きにも注意が必要。

## 3. 探索の深さ・鮮度・その他の上限：影響を分離

5日再実行で、全8睡眠レビューの128起点/目的要求と、個体・日・目的ごとの最初の覚醒探索23件の地図を保存した。覚醒は全探索ではなく標本である。

同じ保存地図で、現行のコスト探索、分岐/展開/待ち行列制限を外した深さ4探索、鮮度だけを外した探索、深さだけを外した探索、両方を外した探索を比較した。すべて候補0。最初の動作の制限解除、runの辺の許可、診断上だけの無向化、過去に観測したhomeラベルの保持でも0。睡眠128要求中64は目標ラベル自体がなく、104は新鮮な目標ラベルがなかった。この期間・起点では、探索予算を増やすだけで解決しない。

一方、10日目の最終地図の全非目標ノードを起点とした到達可能性は以下。分岐・展開予算・最初の動作制限は外した静的診断であり、実際の候補選択件数ではない。

| 帰還目標への到達可能な起点 | A（380起点） | B（425起点） | C（461起点） |
| --- | ---: | ---: | ---: |
| 深さ4・鮮度1日 | 0 | 0 | 4 |
| 深さ4・鮮度無制限 | 0 | 0 | 42 |
| 深さ無制限・鮮度1日 | 0 | 0 | 4 |
| 深さ・鮮度とも無制限 | 0 | 0 | 313 |

A/Bは目標への接続そのものがない。Cは接続を持つが、古い関係の除外と深さ4が到達範囲を狭める。Cの現行条件でも到達可能な4地点があることは、実際の覚醒/睡眠探索がそこを起点にした証拠ではない。食料目標ラベルは10日末に全員0で、どの緩和でも食料経路0だった。

## 改修の優先順（この調査では政策を変更していない）

1. 1特徴しか見えない区間でも不確実な観測・経験として保持し、欠測で成功の痕跡を即削除しない。未観測の接続は捏造しない。
2. 視点依存の観測キーと場所/関係の記憶を分け、過去の目標観測を現在の非目標観測だけで上書きしない。
3. 接続が保持できた上で、ρによるまとまりと探索深さ・鮮度の扱いを調整する。鮮度無制限は診断条件であり、そのまま本番仕様にはしない。
