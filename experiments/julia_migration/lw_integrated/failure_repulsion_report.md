# 失敗履歴からの候補反発（2026-10-22）

共通確率選択に `repulsion = log1p(failure_H_total)` を追加した。選択点は `(現在評価 + log1p(成功報酬) - repulsion - 一時的候補Hペナルティ) / (1 + 親H/閾値)`。これをsoftmaxで確率へ変換する。

失敗時の親Hが高いほど反発が増す。同じHで繰り返した失敗も累積するが、対数で増加を緩める。成功報酬・失敗回数・失敗Hは別々に保存する。成功体験を削除しない。反発が強い候補にも非ゼロ確率を残し、後の成功報酬で再評価できる。

新しい確定失敗判定は追加せず、既存のmethod_value=falseかつgoal_value=falseの記録を利用。未知・未確認は反発を増やさない。H0の失敗は記録のみで反発量0。結果の再送で二重計上しない。snapshotと選択結果にfailure_repulsionを出力する。

範囲は個体・目的・候補ID。場所別・視覚条件別の記憶ではなく、候補間の近傍も未定義なので、空間の連続ポテンシャル場を追加したものではない。汎用step候補の失敗は同じ目的の別の場所にも影響する。削除される地面候補の反発は候補とともに失われる。現段階の実験用モデルとしてこの制約を明示する。

検証: H報酬19件、失敗記録14件、反発10件、確率選択113件、経路支持3件、計159件PASS。成功保持・H増加に伴う回避・再評価・確率総和・再送・目的分離を確認。

## 狭い入口3日実験

同じ3体・seed 20261005・幅0.988の入口で実行。約193秒（コンパイル込み）、155,520操作。地形33件・生活保存則17件PASS、単体と合わせ計209件PASS。

| A | 1 | 0 | 6 | 97.62 | 32 |
| B | 1 | 1 | 0 | 27.80 | 0 |
| C | 0 | 0 | 0 | 47.60 | 0 |

Aは1日目2981秒に出て、食料を取得。8453秒から帰還目的が継続し、3日終了時も帰還していない。Bは2日目23342秒に出て23344秒に戻ったが、両通過とも探索中であり帰還成功の証拠ではない。Cは外へ出なかった。

反発なしの直前版は全員外向き通過0・食料取得0。今回Aに食料目的の報酬32が生じた。これは同一seedの一試行での差であり、一般的改善の実証ではない。位置に依存しない候補反発や休息候補への選択移行もあるため、多条件での再検証が必要。
