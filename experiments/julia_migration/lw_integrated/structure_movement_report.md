# 連続構造を使う共通の局所移動場

2026-10-22。`continuous_descent=on` の歩行・走行を、候補選択後の一か所で
`steer_structure!` に通す。探索・帰還・踏み跡・目印・関係経路・慣性継続・安全回避に
同じ計算を使う。登攀は着地点と高さの別の身体操作なので対象外。

## 選択と移動の役割

親目的や方法を選ぶ既存の処理は残す。目標接近の候補なら現在見える目標方向、
道・目印ならその現在観測した方位、その他は選んだ方向を局所場の引力にする。
たまたま食料や拠点が見えていても、別途選んだ道・回避方向を上書きしない。
慣性継続は身体の現在の前方向を使う。

## まとまりの寄与

- 同一時刻の観測にある障害物・水面のまとまりを使う。古いモデルは力を出さない。
- 一つのまとまりにつき最も近い観測点から一回寄与させ、視線数による単純な増幅を避ける。
  点間を線や面で埋めず、未観測区間・入口の切れ目を横断する仮想壁を作らない。
- 障害物は近いほど強く避け、水面はその0.35倍の軟らかい抵抗。
  現行Worldの水面は通行可能なので、この変更でも絶対禁止にはしない。
- 影響距離は `2 + 0.05*min(荷物,6) + 0.5*damage + (走行なら0.5)`。
  現段階の仮係数であり、生物としての妥当性や最適値を検証した値ではない。
- 希望方向と逆向きの斥力成分は0.8まで、方向補正は左右45度まで。
  壁との余裕だけで希望する前進を反転させないための制限。
  これはポテンシャルをもとにした制限付き局所場で、単一の大域スカラー関数の
  厳密な勾配降下や、経路発見の保証ではない。
- 身体幅・地面抵抗・体力による実行可否を再検査。不適合なら選択済みの元の方向へ戻す。
  衝突判定の緩和や隠し経路の注入は行わない。

`ground_continuity=off` の場合も共通処理を通るが、まとまりがないため元の障害物観測点を使う。
`continuous_descent=off` は従来の離散移動を維持する。
`ground_effects.<actor>` の `steering_attempts / steering_applied / steering_structured` に
実際の適用回数を記録する（通常の地面効果出力が有効な条件）。
