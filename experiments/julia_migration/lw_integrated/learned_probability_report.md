# 学習評価による確率選択（2026-10-22）

前回選択候補への99%優遇と、直前の移動方向を前方へ引き継ぐ処理を撤去した。LWの食料・帰還・安全の共通ループで確率選択を使う。

`P(i) = softmax((priority_i - min(2, methodH_i/threshold_i)) / T)`

`T = 1 + parentH/parentThreshold`。priorityには現在の知覚・身体条件と既存の経路・経験・睡眠学習の投影が含まれる。ランドマーク経路では、成功裏に食料を運んだ証拠から蓄積したsupportが高いほど評価点が上がる。単に選択した回数は加点しない。Hが増えると偏りが弱まり、代替候補を試しやすくなる。同点なら同確率であり、直前の選択には依存しない。

LLMとの共通点として採用するのは「学習に基づく評価を確率へ変換し、候補をサンプリングする」部分。ニューラルネット化やLLMと同じ学習手順の導入ではない。既存の経路学習・経験評価を利用する。

互換性のため入力のmovement_inertiaと診断出力名は残すが、on/offともLWの確率選択を有効にし、方向継続は行わない。onは旧診断記録を出力するだけで、continuedは0となる。BasicLoop単体の決定的モードは既存の検証用に保持する。

検証: probabilistic_checks.jl 116件PASS。直前選択の非干渉、同点分布、H、再現性、極端な評価差、5000回のサンプリング、実際のadmit_route!による成功支持の増加と選択確率の上昇を確認した。前の3日脱出実験は旧99%方式の結果であり、今回の方式の成績ではない。
