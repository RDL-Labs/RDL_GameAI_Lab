# 局所的な連続構造の共通モデル

後続変更：[共通の局所移動場](structure_movement_report.md)で壁・水面を歩行・走行に接続した。
以下の「まだ追加していない」は、この認識モデル単体を導入した時点の範囲を示す。

2026-10-22。Julia LWの `ground_continuity=on` に接続。
実装は `src/lw/perception/local_structures.jl`。地面15点と障害物7本の視線を入力に、
道の地面・水面・障害物のまとまりを同じ処理で記述する。
物体ID・地図・入口座標をモデルへ渡さず、個体相対座標と実際の身体移動で対応づける。

## 何をまとめるか

- 地面は既存の観測配列上の隣接、障害物は隣接する視線を候補辺とする。
- 同じ種類の観測点で距離2.5以下なら、連続性の仮説として同じ成分にまとめる。
  裸地と踏み跡は `worn_ground` にまとめる。草との境界は残す。
- 各成分は元の点・候補辺・境界を保持する。点間の連続性は未検証であり、
  点の間を埋めたポリゴンや通行可能領域として扱わない。
- 異なるものが見えた隣接点は `observed_transition`、遮蔽は `unobserved`、
  同じ種類でも離れすぎた点は `unresolved_interval` と区別する。
- 同種の点の間に異種の観測があれば `sampled_break` を記録する。
  例：岩の視線の間に遮る物がない視線。ただし `passability=unverified`。
  身体幅に対して通れるか、視線の間に細い障害がないかは未判定。
- 観測範囲外は常に不明。遮蔽を切れ目や不在の証拠に変換しない。

## 更新と利用

身体の移動・回転と観測時刻の対応がある場合のみ前フレームを変換する。
同種の点が2点以上対応し、両方向に一意な場合はモデルIDを維持する。
分裂・結合の場合は古い一体化を退役し、新しい仮説へ更新する。
身体対応がなければリセット。未観測モデルは現在の根拠として使わず、8秒で失効。
種類ごとに最大8モデル（道・水面・障害物、計24）、各点集合は観測点数以内。
`ground_continuity.<actor>.structures` に最新のまとまり・境界・切れ目とモデルを保存する。

既存の道の移動候補には共通モデルによる検査を追加した。元の帯の点が複数成分に
分かれていれば一つの道としてたどる提案を保留する。現在支持された単一成分の
観測点だけを使う。水面や壁は共通モデルで保持するが、川沿い移動や入口通過の
新しい方策はまだ追加していない。

動的ρ、壁全体から作るポテンシャル、全移動のポテンシャル共通化はこの変更に含まない。
固定の観測点から作る有限なまとまりであり、完全な輪郭・川幅・入口幅を復元するものではない。
