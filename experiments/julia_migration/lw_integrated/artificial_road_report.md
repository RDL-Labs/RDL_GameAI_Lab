# 人工道（Julia LW）

2026-10-22。世界設定 `scene.artificial_roads` に配置する。既定のマップには自動追加しない。
`ground_wear=on` が必要。知覚・移動候補への利用には `ground_perception=on` と
`ground_continuity=on` を使う。

```json
"artificial_roads": [
  {"cells": [[0, 0], [0, 1], [0, 2]], "lifetime_days": 3650}
]
```

座標は1単位四方の地面セルの整数インデックス。例えば `[0,1]` は
`0 <= x < 1, 1 <= z < 2` を指す。寿命の既定値はシミュレーション内の3,650日。
建設時の地面効果10から寿命終了時の0まで直線的に減衰する。
未使用の自然の踏み跡は1日の猶予後に1日あたり2減るため、量10なら計6日で消える。
人工道の効果と自然の踏み跡の効果は大きい方を使い、重ねて過大な軽減をしない。

歩きやすさと局所的な地面の見え方は既存の踏み跡と共通。
観測上は裸地から踏み跡、草へと移り変わる。目的地情報や全体の道路図は渡さず、
探索・帰還に共通の移動候補になる。水や岩を通過可能にはしない。
通行は人工道の建設時刻を更新せず、通常の踏み跡だけを追加する。
自然の踏み跡が残っていれば、人工道の寿命後も道として利用できる。

保存・復元では建設時刻と寿命を引き継ぐ。再開時に初期配置し直さない。
古い人工道情報のない地面スナップショットも読み込める。
`recovery=false` は自然の回復と人工道の劣化をともに停止する。
期限切れセルの小さな建設記録は保持するが、地面への効果はゼロになる。
現時点ではマップ配置用であり、個体による建設・補修行動は含まない。

検証: `julia --project=. experiments/julia_migration/lw_integrated/artificial_road_checks.jl`
に出力先を追加すると、人工道を置いた最新LW設定で1日分の統合試験も実行する。

2026-10-22検証結果: 人工道の単体22項目と統合5項目が通過。
既存の地面回復・保存履歴・知覚・連続性・安全選択など80項目も通過。
`outputs/artificial-road-20261022/` に入力と結果を保存。
最新の固定riparian設定に36セルの人工道を置いた1日試験は約47.2秒
（コンパイル込み）で完走。狭い岩の入口との比較試験や長期の帰還改善は未検証。
