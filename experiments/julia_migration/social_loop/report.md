## 2. 実験条件

A/B/Cを互いに接触可能な0 / 0.4 / 0.8の固定位置へ置き、接触距離1.25、遮蔽物なし。
初期携行食料はA=0、B=12、C=12。Bは拒否、Cは所持があれば譲渡する既存の固定応答能力を使う。
要求先は毎回、現在観測と既存の期待・Hから選ぶ。翌日の正解を指定していない。

3つのfixture日について、各日2回まで要求を選択し、夜を実行する。
日中の省略区間を飛ばすため、通常LWの連続した3日運転とは異なる。
毎日Aのreserveを20減らす操作も、空腹条件を作る明示的な実験刺激である。
新しい生理モデル、通常の代謝、探索・帰還の成立は主張しない。

夜はhuman_scale_v1の14,400秒から、個体ごとに1秒ずつ2,880回の身体休息を実行する。
完了した受理結果を加算し、その後に社会期待を更新する。
短夜条件だけ100秒。中断条件では100秒休んだ後、安全対応のwaitを1回挟む。
夜の生成・日中への切替はfixtureが担当し、一般の`review()`による日跨ぎ処理は未移植。

## 3. 選択結果

各セルはその日の2回の要求先。すべてPythonとJuliaで一致した。

| 条件 | 1日目 | 2日目 | 3日目 | Aの食事回数 | 各夜のSleep |
| --- | --- | --- | --- | ---: | --- |
| 完了Sleepで社会期待を更新 | B / B | C / C | C / C | 4 | completed |
| 社会期待の更新を無効化 | B / B | B / C | C / C | 3 | completed |
| Bに要求が聞こえない | B / B | C / C | C / C | 4 | completed |
| 休息100秒 | B / B | B / C | C / C | 3 | pending |
| 途中に安全wait | B / B | B / C | C / C | 3 | pending |

更新ありでは、初夜後のBへの期待は0.25、未経験のCは既定値0.5となるため、2日目の
最初からCを選ぶ。更新なしでは、Bへの3回目の不成立で相手別Hが閾値3へ到達し、
次の要求先がCへ変わる。これはSleep経路と即時H経路の違いであり、別の選択規則を
Juliaだけへ追加した結果ではない。

最後の期待はB=0.25、C=5/6。出典はそれぞれ2件と4件の独立した要求である。
同じSleep周期の再実行で根拠は増えない。B/C自身の社会記録へAの経験をコピーしない。

聞こえない条件の記録は`no_response_observed`、拒否条件は`refuse`として区別する。
現在の期待式はどちらも「givenではなかった」として扱うため、数値と選択は同じになる。
「Bが意図的に見捨てた」と認定した結果ではない。

## 4. Sleepと比較の境界

- 通常夜は2,880秒で完了。次の観測がなくても、最後の受理済み1秒を取り込む。
- 短夜は100秒のままpending。途中の安全waitでは蓄積をリセットし、残り2,779秒でpending。
- 未受理結果は拒否。失敗wait・姿勢不一致では休息蓄積をリセットする。
- 旧日付の結果を当該周期へ加算しない。同じ結果の再受理で加算を増やさない。
- Sleep開始後の社会記録、実行されなかった要求は、その周期の期待形成へ含めない。
- 目的差の確認列は、失敗／比較不能／失敗／成功に対しHが **1 → 1 → 2 → 0**。
- 安全割込みによる未確認は比較不能として扱い、失敗に置換しない。

比較対象は、各要求の選択・受理・目的／方法の状態、各夜の最終Sleep状態、社会モデル、
身体値、携行数・消費数、専用境界ケース。夜内の全中間状態をPythonとJuliaで
逐次差分照合したわけではない。各1秒の休息を実行し、重複受理がfalseであることを
それぞれ検査したうえで、夜終端と中断・完了境界を比較している。

離散値は厳密一致。期待値などの連続量は絶対／相対許容差1e-12。
各条件を初期状態から再実行して一致を確認し、食品収支は携行＋消費=24を維持した。
