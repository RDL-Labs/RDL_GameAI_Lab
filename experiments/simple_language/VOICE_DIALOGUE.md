# 音→注意→経験した語句の照合→返答の局所接続

2026-11-16。通常LWへは未接続、既存の生活実験は変更しない。
voice_dialogue!は全受信者の音を投影し、各自のBasicLoopで注意/作業継続を選ぶ。
注意のスコアは音の強さから作り、受信者の集中費用を引く。
注意を選ぶと本人のyawを粗い音源方向へ変更（ローカルmind内のみ）。
1秒後にも発話が続いており、強度が足りる場合だけ語句を取得する。
発話終了後に過去の全文を取得しない。聴覚OFF・圏外では認知選択自体を行わない。

ObservedVocabularyの既存共起経験で語句→見た目特徴を推測する。
関心は受信者に与えた特徴別の主観値であり、世界の取引利得の正解ではない。
既知なら関心表明、未知/聞き取り不足なら聞き返し、いずれにも沈黙を候補に残す。
候補は共通relational_transition、BasicLoopの確率選択へ接続。
関心表明と聞き返しの定型文・選択費用・注意時間は暫定固定、検査前に宣言。
選択した返答を声量1の音として複数人へ再投影。元の呼びかけ主は受信時に注視中という
固定試験条件。返答の意味解釈、再返答、合意、資源移転は実行しない。
呼びかけを処理しただけではH解消や取引成功報酬を与えない。

## 試験

発信者＋5受信者。全員はじめ非注視、語句モ、声量1、発話3秒。
近距離既知個体は「モとfish-formを同時に見た」3観測を既存学習関数へ与える。
これは作者の固定教材であり、本番で経験なしに魚の意味を与えるものではない。
魚を交換したいという文法・要求方向・数量まで理解した扱いにしない。

| 条件 | 16シード中の注意 | 関心表明 | 聞き返し |
|---|---:|---:|---:|
| 近距離、既知、関心あり | 16 | 14 | 1 |
| 近距離、未知 | 14 | 0 | 8 |
| 近距離、集中費用8 | 0 | 0 | 0 |
| 距離12、音だけ届く | 12 | 0 | 6 |
| 距離40、届かない | 0 | 0 | 0 |

残りは沈黙/作業継続。16シードの結果であり注意/返答確率100%を保証しない。
聞き取れなくても聞き返せる。注意は向いても返答しない場合がある。
語句をナだけ学習した個体はモを既知にしない。既知でも主観関心が負なら
関心表明候補の重みが下がる。短い発話が注意後に終了していれば語句取得なし。

202項目PASS。世界位置・資源を変更しない、予測だけで語彙経験を追加しない、
音の圏外で処理なし、返答音の受信、イベント二重適用防止/同一IDの内容衝突拒否、
取引成功報酬なし、個別の注意・記憶差を確認。結果voice_dialogue_result.json。

## 限界

受信者の視覚での人物同定・関係MB接続、注視中の語句誤認、取引条件の解読、
発話形式/関心/費用の自律学習、声量選択、複数発話の重なり、身体消費は未接続。
声の元IDは世界側の投影にだけ使用し、認識結果へ真の相手IDを返さない。
モデルの処理済みID/履歴の容量管理は短期試験用。通常生活/長期試験は未実施。
