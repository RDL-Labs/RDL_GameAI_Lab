## 全発言の場面MB：共通受信処理の局所試験

`utterance_context.jl` の `receive_utterance_context!` は発言の役割を判定条件にせず、
自由発話・提示・返答・呼びかけを同じ入口で受ける。既存の聴覚/視覚投影で聞こえた文字列と、
その瞬間のitem_visible（open_stores=false）の外見だけを採用。視認できた話者は既存の観測参照で結び、
見えない話者はnothingとする。誰に話すつもりだったかは推定しない。記憶の所有者が聞き手。
既存人物認識のID参照能力・照度1の局所感覚条件を引き継ぐ。新たな正解の人物識別を実装したものではない。

関係状態のutterance_mbに発言×観測話者ノードと場面記録を保持し、共起の支持を蓄積する。
複数の外見には一回の支持を等分。共起は真の指示対象・理解・好意・成功とは別。
通常の語句連想にも同じ外見材料を渡す。日本語の形態素解析はなく、空白のない文は全体が一単位。
既存の援助/取引/好意の評価値を変更しない。既存relation snapshot/Serializationで拡張辞書も保持できる。
重複IDは再学習せず、異なる観測を同一IDで投入した場合はエラー。世界や後の観測と記憶の可変参照を共有しない。

`utterance_context_checks.jl`：専用29項目＋既存世界253項目PASS。4種類の発言で同一の話者ノードへ4回蓄積、
2つの外見の支持は各2、対象推定はambiguous。声のみの話者未確認、非注視・非聴取、保存復元後の重複防止を検査。
集計は`utterance_context_result.json`。
これは共通入口の局所版であり、既存の全送受信経路への差替え・5日実走はまだ行っていない。
局所記録の保持上限/圧縮・睡眠整理は未導入。通常運転への接続時は既存記録予算と揃える。
