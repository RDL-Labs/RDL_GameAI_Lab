## 全発言の場面MB：共通受信処理の局所試験

`utterance_context.jl` の `receive_utterance_context!` は発言の役割を判定条件にせず、

複数の外見には一回の支持を等分。共起は真の指示対象・理解・好意・成功とは別。
通常の語句連想にも同じ外見材料を渡す。日本語の形態素解析はなく、空白のない文は全体が一単位。
既存の援助/取引/好意の評価値を変更しない。既存relation snapshot/Serializationで拡張辞書も保持できる。
重複IDは再学習せず、異なる観測を同一IDで投入した場合はエラー。世界や後の観測と記憶の可変参照を共有しない。
