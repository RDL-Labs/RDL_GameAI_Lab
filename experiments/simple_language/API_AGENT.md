## 暫定固定と境界

- 実食研修は果実、加工ドングリ、塩焼き魚を１日１種。実食結果だけを記録する。
- 身体・食事・移動等は既存モデル。APIは取引の既存判断機会のみ。
- 既存cohortの取引通知による認知再開を、呼びかけON/OFFと独立に接続する。
  v3試行ではこれが抜け、Eへの逆提案２件がAPIへ届かず期限切れ。修正版で再試行。
- 個別食料補充、既知人物、構造化された提案伝達、既存チャネル設定を継続。
  初版Eは語句・ジェスチャーを発信しない設定。後述の自由表現版では上書きする。
  APIの日本語理由は世界へ発話しない。
- API入力はEの身体値、本人在庫、実食の味、実際の視聴覚投影、本人への取引通知、
  自分が保持したメモ、既存候補の操作・相手・数量だけ。相手MB、評価点、確率は渡さない。
- 候補生成には既存MB評価・不利条件除外・上限が残る。候補集合自体が既存モデルの
  判断を含むため、完全に独立したAPI認知モデルとは扱わない。候補表示はmethod辞書順。
- 食品名・操作形式・自分の身体値の意味は教える。味や相手の好み・独自語辞書は教えない。
- １日12回、全24回を上限とし、超過は明示的な継続／拒否へ退避して記録する。
  API中は世界を停止。APIエラー・不正IDでは停止し、MBへの無言の代行や自動再試行なし。
- 観測履歴128件、自己メモ2000文字、出力700token。全API入出力を実験フォルダへ保存。
  メモはモデル生成仮説であり、正しい経験記録と同一視しない。５日実験の再開機能は未対応。

設定は `src/lw/configured_paths/api_trade_agent.jl` に隔離。初期教育・判断機会・
上限・表現生成は将来自律化する。通常コードは変更せず、実験終了で無効になる。
鍵は環境変数のみ、保存しない。APIへ渡す項目に他者内部状態がないことを局所検査する。
資源収支・５体・全員の実食経験は既存cohortの検査を実行する。

## 自由発話・ジェスチャー・日記版

`api_agent_run.jl BASE OUTPUT 5 scarce`。教育3日＋交流2日。
Eは初期果実2個、研修中の試食を毎日1個、その後は補充0。A〜Dは従来どおり。
身体・食事・移動・候補生成は既存モデル。独立援助要求・視覚援助は局所設定でOFF。
取引プロトコル内での片側譲渡は可能。5日では身体の蓄えで生きられる可能性があり、
「取引成立がなければ5日内に必ず死亡する」とは設定も保証もしない。

Eの判断JSONへspeech（自由文字列、空なら沈黙）とgesture（none/present/release/withdraw）を追加。
モデルの選択を取引イベントの固定モ/ユ/ケより優先し、他個体へ既存の視聴覚投影を通して送る。
継続を選んでも発話・動作は出せる。ジェスチャー自体は所有権を動かさない。
他個体へ日本語の意味やEの内面を渡さず、見聞きした表現だけを既存学習へ渡す。
自由会話全般や独自語の文法理解を新設したわけではない。

各日末（教育日も含む）に本人の観測履歴・自分の身体/在庫/取引通知・メモだけで
日記を1回生成し、diary-N.mdへ保存。日記はprivate_diaryとして本人の次回入力へ保持し、
他個体の観測へは出さない。本人の推測や誤記を世界の事実に書き戻さない。
日記の機会は暫定固定、各700token、5日で最大5呼出し。取引判断上限とは別枠。
合計日数は引数、取引API上限は12×交流日数。上限や日記は実験用の明示的設定。

局所検査26項目：入力境界、補充の切替と他個体維持（JSON入力を含む）、自由表現の上書き・再送防止、運用診断の記憶への非混入。
実際に他者が受け取った表現はapi-heard.jsonl、E自身の選択/発話/日記はapi-events.jsonl。

空となり、EのAPI判断自体が0件だった。v4はEに限り空の取引候補でもcontinue候補へ
