# 空腹・縄張り反応の動物単独試験

2026-11-06。人0体、成体兎30＋7日齢幼体5、捕食者2、3日間。
`predator_3d_spec.json` の地形・草・初期妊娠5体を使用し、人の配置を空にする。

## 暫定固定と境界

`src/lw/configured_paths/predator_animal_trial.jl` は実験専用、通常LWへ未接続・既定OFF。
既存視覚・遮蔽・追跡・捕食を再利用し、半日固定休息を食料相当量の収支へ置換。
基準600g相当/日＋移動距離×0.1g、初期900g、容量1800g。600g未満で狩猟、
それ以上では休息する。進行中の飛びかかりは完了させる。
成体捕食900g、幼体は体高比の3乗（最低5%）で縮小。実測の肉重量ではなく仮単位。
摂食は瞬時、容量超過はdiscardedへ。消化・死体・食べ残し再利用なし。
在庫0で死亡し認知・移動停止。捕食者の繁殖なし。

縄張り中心は初期位置(-9,5)/(7,5)、半径20の線形防衛勾配。
相手は視野・距離12・草・岩の遮蔽を通して観測し、相手の縄張り中心は参照しない。
自分の中心の外、または相手の中心接近度が自分より0.1を超えて高い場合は撤退、
それ以外は相手に向き直って威嚇する暫定規則。満腹でも反応する。
威嚇は姿勢モードのみ。発声、傷害戦闘、巡回、中心へ帰還は未実装。
将来は身体需要・相手への恐れ・防衛の経験MBで置換する。学習成果ではない。

全捕食者と兎が移動前の位置を観測。接触処理順はtickごとに交替。
alive共有で重複捕食を防ぐが、完全な同時競合解決ではない。
捕食者が死亡しても観測IDを詰めない。兎の見失った対象の位置は更新しない。
