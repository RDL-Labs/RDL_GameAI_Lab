# 捕食者への人側の共通認知処理の接続

2026-11-06。`animals_only.jl OUTPUT DAYS --cognition [--marking]`、既定OFF。
人の実装をコピーせず、同じ `LW` モジュールの以下を直接呼ぶ。

| 共通処理 | 捕食者での用途 |
|---|---|
| BasicLoop / MethodNode / choose_method! | H・成功経験・失敗反発を含む確率的候補選択 |
| resolve_prediction! | 狩猟・休息・対面結果の予測との差、H、報酬の更新 |
| action_trial / step! / close! | 固定した区間見積もり、実費、終端状態、保存再開 |
| mb_travel_seconds | 記憶した地点への粗い所要時間見積もり |
| acquisition_value/result!/finish! | 移動先候補の費用・局所残差 |
| resolve_method! | 地点への到着結果を局所方法MBだけへ反映 |

新しい認知アダプターは `src/ecology/lw_grazing/predator_cognition.jl`。
種固有の係数・試験用ショートカットは `configured_paths/predator_cognition_parameters.jl`。
候補は狩猟、休息、経験した採食/休息地点への移動、見えている相手への威嚇/撤退。
候補生成と評価は身体アダプター、選択・学習の本体は共通コードである。
狩猟中の視覚、追跡、飛びかかり、接触は既存の動物側FSMを再利用する。

## 残す仮定と未接続部分

- 自己位置を正確に記憶する仮定。未知の獲物の現在位置・相手の私的状態を記憶へ渡さない。
- 採食地点は実際の捕食、休息地点は休息区間を完了し終了時に相手が見えなかった場合のみ登録。
  安全の保証ではなく、その時の局所経験。8mの地点区画、最大16件、古い経験から除く。
- 移動到着は局所方法Hだけを更新し、身体維持の親Hを解消しない。食料取得とも記録しない。
- 狩猟/休息600tick、対面60tick、威嚇後600tick待機は暫定固定。
  移動見積もりは人側の粗い時間関数を使用し、捕食者の移動速度への較正は未実施。
- 狩猟の期待効用は狩猟区間の実効用平均へ更新する。所要時間の学習モデル全体は未接続。
- 休息の効用0.2は仮値。疲労・睡眠生理は未導入。満腹時でも確率的に狩る可能性がある。
- マーキングONでは世界の痕跡と観測を維持し、対面時の候補評価に観測した自他の匂いを使用。
  旧固定の匂い回避/帰路選択は上書きしない。経験地点への移動は共通の候補選択を通す。
- 人の地形MBグラフ、ρによる場面照合、睡眠整理、日次持ち帰り、取引、加工は移植していない。
  人の認知全体が同等に接続されたという意味ではない。
- 処理区間は候補選択時に固定し、完了/未達/死亡中断で閉じる。途中の常時割込みは未接続。

## 強い匂いで慎重になる3日比較（2026-11-07）

同じ100兎・2捕食者・栄養1.5倍・seedで、匂いOFF／旧匂い／慎重匂いを比較。

慎重版は信号0.6以上で探索速度0.22→0.08、嗅いだセル方向へ視線を向ける。
既存視覚は毎tickなので回数は増やさず、視距離も変えない。嗅いだ位置は次tickに注視へ渡す。
