# 個体数と処理時間の例外調査（2026-11-10）

population_runtime_audit.jlで保存済みdaily.jsonlを解析。現在の360日試験は2408日までのスナップショット。各実行の初日を除外。日ごとのelapsed差を時間とし、前日末と当日末の生存数平均を個体数の近似とする。同一実行内で個体数±5の他日（最低5日）の時間中央値と比較。
日内の正確な平均個体数ではない。elapsed差には前日の保存等も含まれ、CPUプロファイルではない。OS負荷、保存サイズ、年齢構成等を統制していない。
