# 草容量に応じた分散初期配置（2026-11-09）

旧西20/東80は比較用legacyとして維持。crossing_longrunの新規既定をdistributedへ変更。
第13引数で指定可能。継続の保存個体は再配置しない。

暫定固定の初期条件。16単位区画を川の東西で分割し、通行可能な草セルの容量合計に
比例する人数目標を計算。大きい家族から目標との差が大きい区画へ割り当てる。
区画内では既配置グループから離れたセルを選ぶ。同点は専用乱数seedで再現可能。
親子は同居、独立グループは別セル。川岸3単位以内は初期候補から除く。
草容量は再生供給の尺度で、現在残量とは別。初期残量・身体状態・乱数履歴を作り直さない。
真の容量・通行可能性は配置のみに使用し、個体の認知へ渡さない。

完全な比例配分にはしない。出生/授乳家族による局所密集は残る。
