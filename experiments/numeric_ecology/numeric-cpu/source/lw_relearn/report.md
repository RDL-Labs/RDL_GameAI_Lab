## Remaining boundary

The mechanism can retain later evidence and inspect a narrower candidate, but
the unchanged finite World did not supply enough post-invalidation attempts.
Longer time alone is not evidence that new learning will occur. A separately
declared renewable/multi-site scenario could test the full living replacement
cycle while keeping the original negative result. General schema generation,
repeat replacement cycles and canonical reconstruction remain unimplemented.

Full-suite and speed benchmarks were not run. The86.4s integration test duration
includes four four-day scenarios and checks; it is not a performance claim.
