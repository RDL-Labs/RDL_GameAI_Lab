# 種別の視野と独立した視線の実験

30体の兎＋捕食者1体、3日、seed 20261005〜20261009で5組比較。動き補正は両条件でON。既存motion-vision-cpuを残した独立コピー。

全方向条件と、以下の視野・視線制御をまとめて加えた条件を比較する。視野角だけの効果を分離した実験ではない。

- 兎：視線中心330度で通常検出距離、後方30度は死角。
- 捕食者：前方120度で通常距離、その外側の左右60度ずつは距離30%、後方120度は死角。
- 視線は移動方向とは別の角度。1 tick最大30度で向きを変える。
- 20 tick以内の観測記憶がある場合は最後の観測位置を向く。現在見えない相手の実位置を視線制御へ渡さない。
- 記憶がなければ移動方向を中心に周期的に見回す。兎は左右30度、捕食者は左右90度。開始時の兎の視線は既存の初期headingと同じ。
- 草の遮蔽、岩の遮蔽、動き補正、攻撃・回復・半日休息、静止警戒等は前版のまま。
- 追跡中でも視野外は新たに視認できない。記憶位置への追跡は期限まで継続。

角度・回転速度はゲーム実験用の仮値で、実在種の解剖学的測定値ではない。体と頭の可動範囲制約、眼球、画像認識、聴覚は未実装。睡眠や死亡時の視線更新停止も未実装（死亡個体は知覚判定から除外）。

## 結果

| seed | 全方向 捕食/生存 | 種別視野 捕食/生存 | 種別視野 エネルギー切れ死亡 |
|---|---|---|---:|
| 20261005 | 4 / 26 | 4 / 26 | 0 |
| 20261006 | 2 / 28 | 6 / 24 | 0 |
| 20261007 | 2 / 28 | 2 / 28 | 0 |
| 20261008 | 4 / 26 | 4 / 26 | 0 |
| 20261009 | 3 / 27 | 4 / 24 | 2 |

平均捕食数は3.0→4.0体。全方向条件のエネルギー切れ死亡は全試行0。種別視野は1試行で2体発生。視野を制限すれば必ず捕食が減る、という結果ではなかった。接近方向・発見タイミング・見回し・その後の経路も変化するため、今回の集計だけで捕食増の原因は断定しない。5 seedの小規模実験。

コンパイル後の計測は全方向0.117〜0.141秒、種別視野0.282〜0.353秒/3日。Julia起動・読み込み・テストは除外。全方向→種別視野の順固定。同一プロセス内の簡易計測であり厳密な性能ベンチマークではない。
