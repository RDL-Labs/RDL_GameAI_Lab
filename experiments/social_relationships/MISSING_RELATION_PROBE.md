# 欠けた関係を埋める入手判断・局所試験（2026-11-26）

`missing_relation_probe.jl`。通常LW未接続の設計プローブ、17検査PASS。
料理・好み・既知の入手先は実験用に与えた初期MBであり、実ログから学習したものではない。
Relation(inputs, outputs, requires, cost, confidence)で調理・交換・採取を表現する。
火は再利用する条件、魚・塩は消費する材料。同じ遷移評価関数を使う。

現在の所持から記憶された調理関係を最大3段たどり、実現できる食事の主観価値を見積もる。
入手候補による所持変更後にも同じ見積もりを行う。
入手利得 = 成立見込み × (変更後の到達価値 − 現在の到達価値) − 費用。
失敗時は現状態を保持するという局所仮定。直接の材料価値と料理価値を重ねて加算しない。
継続より改善せず追加費用だけがある候補は一般的な優越比較で落とす。
残った候補はsoftmaxで確率化。報告のselectedは最大確率候補であり、乱数試行の頻度ではない。
同品目の交換を排除する名前・IDの条件はない。

| 条件 | 最大確率の候補 |
|---|---|
| 魚・火・果実があり塩なし | 果実を渡して塩を得る → 塩焼き → 食べる |
| 塩あり | 現在の材料で調理する（追加交換なし） |
| 魚なし／火なし | 追加の塩取得を選ばない |
| 塩焼きの関係を知らない | 追加の塩取得を選ばない |
| 食事欲求なし | 追加の塩取得を選ばない |
| 既知の交換先なし | 塩採取 |
| 交換成立見込み0.9から0.1へ低下 | 塩採取 |
| 塩2個を要する別レシピ、所持1個 | 塩1個→2個の交換は候補に残る |

塩不足時の交換利得1.25、採取0.70。同量交換は材料充足が変わらず−0.10。
数値は抽象価値・費用の試験用設定で、実栄養・実時間への校正は未実施。

## 限界と次の接続

この試験は本人に与えた関係だけによる小規模な到達価値比較。
実LWのMB照合、動的な身体欲求、過去経験からのレシピ獲得、相手の同意、H更新、睡眠学習は未接続。
入手候補は既知の機会リストとして列挙しており、欲求からの逆向き探索による候補生成は未実装。
魚も塩も欠ける場合の複数入手計画は扱わない。料理の関係はたどるが入手は1手の評価。
関係投資や相手の援助動機も今回は評価しない。同量交換でも社会的成果が予測される場合は別問題。
味・残量・品質の知覚が誤る可能性を禁止したものではなく、今回は入力を確定値とした。
通常LWへつなぐ際は同じ型で所持・能力・場所の不足を表し、既存の観測MBと見積もりを入力にする。
実際の取引・生活の改善を示す試験ではない。
