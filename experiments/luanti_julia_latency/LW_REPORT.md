# 同一LW環境のLuanti通信比較

2026-10-21。`run_lw.ps1`、Julia 1.13.1、Luanti 5.17.0、Windows。

## 比較範囲

保存済み `experiments/julia_migration/lw_integrated/search_review_spec.json` の
川沿い地形・seed20261005・人型3個体・身体・混合危険物・地面抵抗/履歴・
経路/記憶・親候補幅・社会応答・Sleepの設定を使用。変更は日数30→1だけ。
Worldの時刻や1日長を縮めない。17,280ステップ、51,840個体操作。

**World、観測、判断、物理、食料台帳の権限はすべて既存Julia LWに残す。**
Luantiは空の専用WorldからHTTPで次の1ステップを要求し、完了応答を受ける。
地形をLuantiのボクセルへ移植した実験でも、Luantiの視覚/衝突/描画負荷の測定でもない。
「同じLW負荷へLuantiの通信を加えたらどうなるか」を切り分ける中間試験。

3個体を1リクエストで更新し、未完了リクエストは最大1件。完了後の次のglobalstepで
送信する。このバックプレッシャーにより、旧6体・250ms固定観測の待ち行列増加は再現しない。
専用server stepは10ms。生存中の実時間に追随する方式ではなく、可能な速さで進行する。

## 検査と計測

1. 元のsrcをoutputs内へコピー。day.jlへtick前後の待機・計測フックのみ追加。
2. 同じモジュール・設定でLW単独実行。毎tickの位置、身体、在庫、資源、操作数、行動計画をハッシュ化。
3. Worldを新規初期化し、Luanti要求ごとに同じtickを実行。全tickのハッシュを照合。
4. 最終的な完全なresult/summaryも `isequal` で比較する。

LW計算時間はtick開始から日次処理まで。比較用ハッシュ/JSON作成とHTTP処理は含めない。
往復時間はLuanti送信からcallbackまでであり、ハッシュ照合、応答JSON、通信、callback待ちを含む。
両方とも統計から外したtickはない。baselineは先に実行するため初回コンパイルを含む。
liveは同じプロセスの後続実行。両者の時間比を言語の速度差や通信による高速化とは扱わない。

結果はoutputs内のsummary.json、全応答はworld/latency.json、全tick照合と計算時間はparity.json。
sourceコピーとspec.jsonも保存する。検証はこの1日・1seedの範囲であり、長期履歴肥大化の検証ではない。

## 実測結果

成功run: `outputs/luanti-lw-20261021-225037/`。
全17,280tickの照合PASS、最終完全result/summary一致。通信失敗なし。
Luanti運転経過214.320秒（約3分34秒）。準備・baseline実行は含まない。

|計測|中央値 ms|p95 ms|最大 ms|合計秒|
|---|---:|---:|---:|---:|
|LW単独tick計算（初回コンパイル込み）|1.5361|2.6060|3230.7422|40.422|
|Luanti経由・LW tick計算|2.1319|3.0643|74.7225|42.280|
|Luanti送信→受信callback|10.739|21.434|601.510|213.458|

最大RTTは最終tick17,280（そのtick計算は約2.73ms）。Juliaの協調タスクでは
最終tick応答の受け渡し後、完全result生成と一致検査が送信処理より先に進み得る。
終了処理・応答直列化・通信待ちの個別計測はなく、601ms全体をLW判断時間とは扱わない。
初回RTTは約95.92ms。通常途中の大きい例はtick11,494でRTT約94.42ms、
tick計算約74.29ms。GC等の原因は未分離。

開始食料124 = 地面112 + 共有6 + 消費6。全員各17,280操作。
夜間SleepはCがcompleted、A/Bがpending。採取モデル参照は全員null。
したがって設定は学習有効でも、長期学習モデル蓄積後の負荷を代表しない。

この短期・同一設定では、LWの計算負荷を載せても通信は成立した。
一方、callback待ちと一往復ごとの同期による追加時間が目立つ。
描画/地形/物理のLuanti移植、並列個体リクエスト、30日後の履歴負荷については未測定。
旧Python/Luanti観測約2.05秒とは処理範囲もスケジューリングも異なり、改善倍率を算出しない。
