# 拠点の個人倉庫・3日試験

2026-10-29。Julia 1.13.1 / Windows / Julia・OpenBLAS各1スレッド。

## 変更と条件

果実・ドングリ・兎のシナリオ生成を`stores="personal"`既定へ変更した。既存の個人備蓄を使い、入出庫・空腹時の判断は本人の在庫だけを扱う。保管・譲渡の本体ロジックは追加せず、集計に個人別倉庫残量を表示する。共有条件は生成時の第2引数`shared`で再現できる。

人3体＋兎30体、3日。果実1080個＋近隣原料192個＋各人の原料1個、有限・補充なし。拠点内開始、初期reserve70、消化ON、腐敗・狩猟OFF。初日見学・日次荷下ろし等は維持。入力JSONを比較し、[以前の共有3日試験](../acorn_food/report.md)から変わった入力は`config.stores`だけと確認した。共有途中データの分配は行わず、新規初期状態から実行した。

倉庫は拠点内の本人専用の保管枠であり、個別の箱の座標・容量制限はない。他人の倉庫からは取り出せない。本人の手持ちを依頼に応じて渡すことは可能で、受け手の所持品・倉庫へ移る。倉庫から直接の自動譲渡、盗みはない。地面へ落とした食料は他者も回収できる。[仕様](../../docs/design/LW_Typed_Food_Processing.md)。

## 結果

| --- | ---: | ---: | ---: | ---: | ---: |
| A | 0 | 2 | 7（7 / 0） | 4 | 86.54 |
| B | 0 | 3 | 8（7 / 1） | 4 | 87.72 |
| C | 0 | 3 | 8（7 / 1） | 4 | 85.72 |

人3体・兎30体とも生存。人は3日末に全員拠点範囲内。共有在庫は全日0。14個を加工し、12個を摂食した。生原料の摂食は0。果実はこの3日間には食べていない。

実際の取り出しはAが2回。Aの倉庫から使い、B・Cの備蓄を共有として使わない。手渡しはA3回/B3回/C1回で、従来の依頼・譲渡は継続した。個人所有にしたこと自体で譲渡を禁止していない。

全食料の収支は1275＝地面1240＋個人倉庫23＋摂食12。原料は195＝地面160＋倉庫21＋加工14、加工食は14＝摂食12＋倉庫2。各個体の総数と種類別倉庫も一致。

共有条件では倉庫合計22個、個人条件では23個。加工14・摂食12・各4食は同じ。個人倉庫を導入した短期の生活は成立したが、今回の食料が豊富な条件だけでは、備蓄の偏り・援助・不足時の差は評価できない。所有概念を学習したのではなく、世界側の保管アクセス制約を使っている。
